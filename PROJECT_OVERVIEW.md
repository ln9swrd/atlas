# Atlas Project Overview

## 1. Project Summary

* Project Name: Atlas DevOS
* Current Status: Architecture baseline established
* Purpose: AI-centered development operating system for structured project execution
* Core Validation Project: Excelion
* Intelligence Layer: Sera
* Production Framework: Forge

Atlas is designed to coordinate AI assistance, production workflows, and project execution through a repeatable development system.

---

# 2. Atlas Ecosystem Overview

Atlas consists of three major layers:

```text id="v8b4s2"
Atlas DevOS

├── Sera
│   AI Intelligence Layer
│
├── Forge
│   Production Automation Framework
│
└── Excelion
    Game/IP Production Project
```

---

# 3. Core Components

## Atlas DevOS

Role:

Development operating system.

Responsibilities:

* Runtime context management
* Project state management
* Execution coordination
* Rule-based prioritization
* Evidence-based review

Core concepts:

* RuntimeContext
* Registry
* Resolver
* Priority Engine
* Runner

---

## Sera

Role:

AI design and planning intelligence layer.

Responsibilities:

* Architecture discussion
* Requirement analysis
* Planning assistance
* Design review
* Development support

Sera provides intelligence but does not replace execution validation.

---

## Forge

Role:

Production automation framework.

Responsibilities:

* Asset workflow automation
* Blender integration
* Unreal integration
* MCP communication
* Validation pipeline
* Evidence recording
* AI-assisted production

Forge is designed as a reusable framework.

Excelion is the first project used to validate Forge.

---

## Excelion

Role:

Primary product project.

Goal:

Develop the Excelion mecha IP and game experience.

Responsibilities:

* Game design
* Mecha development
* Gameplay systems
* Prototype validation

Excelion provides real production requirements for Atlas and Forge.

---

The current strategy is:

```text id="sjh8xk"
Sera

Forge
```

# 6. Development Principles

Atlas follows:

## Evidence First

Important decisions and execution results require evidence.

## Separation of Responsibility

Each layer has a clear role.

```text id="x9h7yc"
Atlas

Context and Execution


Sera

Intelligence and Planning


Forge

Production Automation


Excelion

Product Creation
```

## Incremental Expansion

New capabilities are added only after existing workflows are validated.
