# Release Notes

## Atlas DevOS v1.0 Foundation

This milestone captures the first stable foundation of Atlas as a development operating system.

### Included in this foundation
- Constitution for Atlas operating principles
- Vision for long-term goals
- Project and agent registries
- Runtime state management through ATLAS_STATE.json
- Event logging through logs/atlas_events.jsonl
- Runner-based execution flow

### Intent
Atlas is now positioned as a stable platform for supporting real project work, especially Exelion, rather than as a collection of loosely connected scripts.
