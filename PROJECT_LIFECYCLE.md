# Project Lifecycle

Atlas uses a shared lifecycle model for all projects so their status and development phase are easy to compare.

## Lifecycle Stages

1. Idea
2. Planning
3. Prototype
4. Active Development
5. Validation
6. Release
7. Maintenance
8. Archive

## Usage Guidance
- Use the lifecycle stage in the project charter as the current phase.
- Use the project registry status field for the high-level state.
- Move projects forward only when the relevant evidence and milestones justify the transition.
