# Runtime Project Artifact Archive

This directory contains tracked images that were previously stored in the MENOS Godot project root but are not referenced by Runtime source files.

- `verification/`: desktop/GUI verification captures and temporary contact sheets.
- `asset_research/`: road-candidate reference images used during visual asset exploration.

These files were moved, not deleted. The pre-existing `_ui_baseline_temp.png` and its modified `.import` sidecar were intentionally left untouched to preserve the existing working-tree change. Godot cache/build folders remain generated/ignored and were not deleted.
