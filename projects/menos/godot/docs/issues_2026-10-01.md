# MENOS — 2026-10-01 문제 및 확인 사항

## 1. 콘텐츠 에디터 최대화 시 공간 활용 문제

- 문제: 콘텐츠 에디터를 최대화했을 때 좌우에 넓은 어두운 영역이 남아 실제 편집 공간을 충분히 사용하지 못하는 현상이 제기됨.
- 요구: 녹색 배경을 만드는 것이 아니라 창 최대화 시 콘텐츠 에디터가 가능한 넓게 공간을 사용해야 함.
- 상태: NOT VERIFIED.

## 2. Map Editor와 Runtime의 맵 표현 불일치

- 문제: Map Editor에서 `map_01`을 열면 Northbridge Sector 01과 동일하게 보이지만 게임 플레이에서는 투명 배경 이미지와 고저차 표현 문제가 발생함.
- 원인: Editor는 `asset_catalog.json`의 `source_rect_px`를 사용해 전체 자산 영역을 렌더링하지만, 기존 Runtime TileMap 경로는 128x128 Atlas 셀 기준으로 단일 셀을 선택해 렌더링함.
- 결과: 4x4 등 여러 타일에 걸친 지형 이미지의 전체 형상과 고저차 표현이 Runtime에서 손실됨.
- 조치: Runtime에 catalog asset의 `source_rect_px`와 `footprint_tiles`를 이용해 전체 이미지를 직접 그리는 경로를 추가함.
- 상태: 코드 변경 및 diff 확인 완료. 실제 PIE는 NOT VERIFIED.

## 3. 투명 배경으로 인한 바닥 경계/그리드 현상

- 문제: 바닥 타일이 없는 영역의 투명 픽셀을 통해 배경이 드러나면서 미세한 그리드 또는 자산 경계처럼 보임.
- 확인: Editor는 연속적인 바닥/배경 영역을 가지고 있으나 Runtime은 투명 자산 뒤로 별도 배경색이 노출됨.
- 판정: 배경색을 맞추는 것은 근본 해결책이 아님. 맵 자체에 바닥 타일을 배치해야 함.
- 상태: 배경색 변경을 최종 해결책으로 채택하지 않음.

## 4. 맵 Ground / Vegetation 레이어 구성 오류

- 문제: `Ground`에 실제 바닥을 깔고 `Vegetation`에 다른 이미지/오버레이를 올리는 레이어 구조가 제대로 구성되지 않음.
- 확인: `asset.tile.ground.basic_meadow`는 1x1 Ground 자산이며 `res://assets/menos/maps/ground_basic_32.svg`를 사용함.
- 현재 데이터 문제: `map_01.json` Ground에는 36x24 전체를 채우는 Basic Meadow가 일부 반영되었지만 기존 Terrain Atlas 자산 54개가 Ground에 남아 있고 Vegetation은 비어 있음.
- 판정: 실제 자산 이미지와 분류를 확인한 뒤 레이어를 재구성해야 함. 임의 이동 금지.
- 상태: HOLD / 추가 조사 필요.

## 5. Northbridge Sector 01 재구성 문제

- 문제: Northbridge 재구성에서 Terrain Atlas를 Ground에 배치하고 Vegetation을 비워 둔 결과, 맵 레이어 의미가 잘못되었을 가능성이 확인됨.
- 관련 구조: Map Editor는 자산 그룹을 Ground, Vegetation, RoadComposition 등으로 분류하고 그룹에 따라 활성 레이어를 결정함.
- 판정: 자산 분류와 실제 이미지 내용을 확인한 뒤 재구성해야 함.
- 상태: HOLD / EDITOR VERIFIED 아님.

## 6. Stage Editor / Map Editor 역할 구분

- Map Editor: 지형, 장애물, 이동 영역, Spawn/Goal 영역, Tower Placement Point, Robot Position Point, 맵 크기/구조.
- Stage Editor: 미션 목표, 초기 유닛/타워, 적/웨이브, 클리어/실패 조건, 보상/제한, 사용할 Map.
- 현재 Runtime은 `tower_slots`를 초기 타워 데이터로 사용하고 있어 완전한 Stage Editor 분리는 아직 완료되지 않음.
- 상태: ARCHITECTURE PROPOSAL.

## 7. 콘텐츠 에디터 배포 빌드 문제

- 문제: 최초 생성한 `MENOS_ContentEditor.exe`가 콘텐츠 에디터가 아니라 게임을 실행함.
- 원인: `project.godot`의 `run/main_scene`가 `res://ui/title_screen.tscn`을 가리킴.
- 조치: Export 직전에 `run/main_scene`을 `res://editor/content_editor.tscn`으로 임시 변경하여 Windows Release Export 후 원래 설정으로 복구함.
- 생성 경로: `build\MENOS_ContentEditor.exe`
- 상태: BUILD VERIFIED — Export 성공. 실제 EXE GUI 실행은 NOT VERIFIED.
