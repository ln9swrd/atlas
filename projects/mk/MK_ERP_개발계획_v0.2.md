# MK ERP 개발계획 v0.2

## 1. 목적
Master가 확정한 Canon과 업무 요구사항을 실제 Windows Stand Alone ERP로 구현한다.
목적 달성에 필요한 최소 기능과 검증을 우선한다.

## 2. Canon 우선
- 설정값과 변경 가능한 업무 기준은 저장소에서 조회한다.
- 업무값을 소스 코드에 하드코딩하지 않는다.
- 소스 코드와 문서는 UTF-8이다.
- 업무 데이터의 실제 삭제는 없다.
- 초기재고는 Transaction으로 등록한다.
- 입출고는 독립 원장이다.
- MK Lot/거래처 Lot은 사용자가 직접 입력한다.
- Lot 관계는 N:M이며 동일 거래처+동일 Lot 중복을 허용한다.
- 단가는 자동조회 후 수동 수정 가능하다.
- 문서번호는 규칙에 따라 자동 생성한다.
- 백업은 주 1회 Full Backup이다.
- 중요 변경은 감사 이력으로 추적한다.

## 3. 기술 기반
Windows Desktop / C# / WPF / .NET 8 계열
SQLite / EF Core + SQLite / MVVM
Presentation → Application → Domain → Infrastructure → SQLite

## 4. 안전한 작업 원칙
작업 전 HEAD, Branch, Working Tree, 관련 파일의 기존 변경을 확인한다.
기존 변경사항을 임의로 되돌리거나 덮어쓰지 않는다.
변경 후 Diff를 확인한다.
삭제, 대규모 변경, Asset 변환은 별도 승인이 필요한 경우 중단한다.
각 단계는 목적 달성 후 STOP한다.
