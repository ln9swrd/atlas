# 급여명세 생성기

## 실행

개발 환경에서는 다음 명령으로 실행합니다.

```bash
python payroll_app.py
```

UI에서 근태 XLS 입력 파일과 급여명세를 저장할 출력 폴더를 선택하고 시급을 입력한 뒤 `급여명세 생성`을 누릅니다.

직원 목록은 입력 XLS의 직원 카드에서 매번 자동으로 읽습니다. 따라서 직원이 추가되거나 삭제되어도 프로그램에 직원을 따로 등록할 필요가 없습니다.

출력 파일명은 `급여명세_입력파일명.xlsx`입니다. 프로그램 UI에서는 프로젝트 기준 급여명세만 생성됩니다. 전월 근태 XLS를 선택하면 입력 파일의 연도·월을 기준으로 해당 월의 법정공휴일을 인터넷에서 조회해 적용합니다.

## 배포판 만들기

Windows에서 `build_payroll_windows.bat`를 실행하면 `dist/PayrollStatement.exe`가 생성됩니다. Python 설치 시 `tkinter`가 포함된 기본 설치를 사용해야 합니다.

Linux/macOS에서는 다음 명령으로 해당 운영체제용 실행 파일을 만들 수 있습니다.

```bash
./build_payroll.sh
```

PyInstaller는 실행 파일을 만든 운영체제용 배포판만 생성하므로, Windows `.exe`는 Windows에서 빌드해야 합니다. 법정공휴일 조회에 인터넷 연결이 필요하며, 조회에 실패하면 급여 누락을 막기 위해 생성이 중단됩니다.
