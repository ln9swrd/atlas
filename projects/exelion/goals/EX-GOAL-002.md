## Mission
Establish the combat action foundation for the Brave mecha character by developing weapon assets, motion rigging, and Unreal Engine Animation Blueprint (ABP) integration.

## Objectives
1. Create primary weapon asset (Rifle/Sword) in Blender and perform UV mapping.
2. Rig Brave lower/upper body joints and create core motion clips (Idle, Run, Attack).
3. Set up Unreal Engine Animation Blueprint (ABP), Character Controller, and Weapon Sockets.
4. Validate playable motion and action camera placement in Unreal Engine DEV_HOME environment.
