| 축 | 다듬은 한 줄 |
|----|----------------|
| **벽** | 앞이 막혀 있다. 뚫는 게 아니라 부수는 것이다. |
| **게이지** | 막히면 쌓인다. 쌓이면 돌아온다. |
| **예고** | 반격은 소리 없이 오지 않는다. 창이 보인다. |

## 흐름 (4파트) — 전투 디테일 반영

### Part 1 — 입구 (비트1)

- 게이트 입구. **아이기스** 전면.
- 가로 넓은 실루엣 · 벽 자세 · 이동 최소.
- 오만 없음 · 기능만. 대사 최소 또는 무음.
- 유나: 가드 게이지 감지.
- 레이: 돌파 축 지정.
- **첫 정면 타격** → 손이 막힘 · 진동·무게 증가 = 게이지 충전 체감.
- 목표: 격파 = 문 개방. 섬멸 아님.

### Part 2 — 가드 (비트2 · P1)

- P1: GuardIdle · TelegraphedCounter.
- 정면만 치면 게이지만 차고 반격이 돌아온다.
- **예고 신호**: 방패면 가장자리 빛 · 자세 반 박 기울 · 조종간·발밑 진동.
- 유나 1회 (“예고”) 가능.
- 리아: 정면 고집 금지 · 예고 읽고 회피/측면.
- 팀 엄호·관측으로 **창 확보** 후 타격 → 게이지 소모.
- 창 실패 시 반격 직격 · 손상·손 떨림 가능.
- 긴장 축: 게이지 차는 속도 · 보이는 창.

### Part 3 — 붕괴 (비트3 · P2)

- 게이지 임계 → 방패면 한 칸 무너짐 → P2 진입.
- P2: CounterWindowWider · HeavyCounter.
- 예고 짧아짐 · 반격 범위·속도 상승. 팀 관측 필수.
- 약점 창에 집념 타격. 필살 1회 이하.
- 대가 가능 (손상·부상).
- 광기: 열어 두되 끌어가지 않음.
- 게이지 완전 붕괴 → BriefStagger.

### Part 4 — 개방 (비트4)

- 경직 → 기동 정지.
- **문이 열렸을 뿐이었다.**
- 네메시스 반응 **없음** · 흔들림 없음.
- 게이트 심부 진입 가능 · 최종 영역 신호.
- 안도 없음. 다음은 내부.

## 전투 디테일 (참조)

### 게이지 규칙 (소설용)

| 상태 | 체감 | 결과 |
|------|------|------|
| 정면 타격/접근 | 손 막힘 · 진동·무게 | 게이지 충전 |
| 예고 발생 | 빛·자세·진동이 **먼저** | 반격 직전 창 |
| 예고 중/직후 타격 | 손 들어감 · 방패 흔들림 | 게이지 소모 |
| 게이지 임계 | 방패면 한 칸 무너짐 | P2 또는 Stagger |
| 완전 붕괴 | 경직 → 정지 | OpenPath (문 열림) |

숫자 바 서술 금지. **손·진동·자세**로만 전달.

### 예고 신호

| 신호 | 표현 | 반응 |
|------|------|------|
| 빛 | 방패면 가장자리 발광 | 창 준비 |
| 자세 | 벽 자세 반 박 앞 기울 | 회피/측면 |
| 진동 | 조종간·발밑 떨림 | 타이밍 |
| 통신 | 유나 1회 | 확인 |

### 팀 역할

| 역할 | 행동 |
|------|------|
| 리아 | 중심 · 예고 읽기 · 창에만 타격 |
| 유나 | 게이지·예고 관측 · 통신 1~2회 |
| 레이 | 축·“창” 지시 · 침묵 허가 |
| 지원 | 엄호·측면으로 창 확보 |

리아 혼자 전 맵을 막지 않는다. **창은 팀이 연다.**

### 실패·대가

| 상황 | 결과 |
|------|------|
| 예고 무시·정면 고집 | 반격 직격 · 손상·손 떨림 |
| 창 소실 | 게이지 재충전 · 시간 압박 |
| 반격 누적 과다 | 경로 일시 봉쇄 |
| 최종 대가 | 부상·손상 가능 · 개방 후에도 안도 없음 |

### 연출 금지

- 오만 Selector · 「급이 아니다」 · 네메시스 원격 복제
- 손 완전 숨김 · 등급 판정 대사
- 장문 전술 설명 · 영웅 연설
- 게이지를 체력바 숫자로만 서술
- 아이기스 사연·감정 균열
