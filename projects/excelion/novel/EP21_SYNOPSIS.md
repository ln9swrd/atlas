## 긴장 축 (본문 필수)

| 축 | 다듬은 한 줄 |
|----|----------------|
| **벽** | 앞이 막혀 있다. 뚫는 게 아니라 부수는 것이다. |
| **게이지** | 막히면 쌓인다. 쌓이면 돌아온다. |
| **예고** | 반격은 소리 없이 오지 않는다. 창이 보인다. |
| **대가** | 문을 열어도, 그 너머는 더 무겁다. |
| **무반응** | 방패가 쓰러져도, 위계는 움직이지 않는다. |

긴장 = 큰 소리가 아니라 **게이지가 차는 속도**.

> 본문에 그대로 넣거나, 손·게이지·통신으로만 바꿔 쓴다. 강의체 금지.

| 위치 | 문장 |
|------|------|
| Part1 | 가로로 넓은 서명이 먼저 왔다. |

| Part2 | 막히면 쌓였다. 쌓이면 돌아왔다. |
| Part2 | 예고가 보였다. 창이 열렸다. |
| Part3 | 방패가 한 칸 무너졌다. |
| Part3 | 손이 먼저 움직였다. |

## 흐름 (4파트)

### Part 1 — 입구

- 게이트 입구. **아이기스** 전면.
- 가로 넓은 실루엣 · 벽 자세.
- 오만 없음 · 기능만. 대사 최소 또는 무음.
- 유나: 가드 게이지 감지.
- 레이: 돌파 축 지정.
- 목표: 격파 = 문 개방. 섬멸 아님.

### Part 2 — 가드

- P1: GuardIdle · TelegraphedCounter.
- 막히면 게이지 충전 → 예고 있는 반격.
- 리아: 정면 돌파 금지 · 예고 창 이용.
- 팀: 관측·엄호로 창 확보.
- 긴장 축: 게이지 차는 속도 · 반격 타이밍.

### Part 3 — 붕괴

- 게이지 브레이크 · BriefStagger.
- P2 가능: CounterWindowWider · HeavyCounter.
- 약점 창에 집념 돌파.
- 대가는 가능 (손상·부상).
- 방패 내구 임계 → 기동 정지.

### Part 4 — 개방

- 아이기스 정지. 길이 열림.
- **문이 열렸을 뿐이었다.**
- 네메시스 반응 **없음** · 흔들림 없음.
- 게이트 심부 진입 가능.
- 최종 영역 신호.
- 안도 없음. 다음은 내부.

## 전투 디테일 (구체화)

### 1. 형태 · 승리/실패

| 항목 | 고정 |
|------|------|
| 형태 | 단독 보스 · 가드·반격 게이지 |
| 적 | **아이기스** 1기 |
| 페이즈 | P1 Guard → P2 WiderCounter |
| 클리어 | 가드 게이지 완전 붕괴 · 기동 정지 = **문 개방** |
| 실패 | 반격 누적 과다 · 창 소실 · 경로 봉쇄 |
| 섬멸 | 아님 (문이 열리면 전투 종료) |

### 2. 게이지 규칙 (소설용)

| 상태 | 체감 | 결과 |
|------|------|------|
| 정면 타격/접근 | 손이 막힘 · 진동·무게 증가 | 게이지 충전 |
| 예고 발생 | 빛·자세·짧은 진동이 **먼저** | 반격 직전 창 |
| 예고 중/직후 타격 | 손이 들어감 · 방패 흔들림 | 게이지 소모 |
| 게이지 임계 | 방패면이 한 칸 무너짐 | P2 또는 BriefStagger |
| 완전 붕괴 | 경직 → 정지 | OpenPath (문 열림) |

숫자 바 서술 금지. **손·진동·자세**로만 전달.

### 3. 페이즈 상세

**P1 — Guard**

```
AEGIS P1
├─ GuardIdle           : 가로 벽 · 정면 거부 · 이동 최소
├─ GuardGauge 충전     : 플레이어 정면 타격/접근 시 쌓임
├─ TelegraphedCounter  : 예고(빛·자세·진동) → 반격
└─ 약점 창             : 예고 중 짧은 개방 · 반격 직후 1박
```

- 정면만 치면 게이지만 차고 반격이 돌아온다.
- 예고를 읽고 회피·측면·팀 엄호로 **창을 연 뒤** 타격.
- 창 타격 = 게이지 소모. 이 반복이 P1의 리듬.

**P2 — WiderCounter** (게이지 2단계 또는 내구 임계)

```
AEGIS P2
├─ CounterWindowWider  : 반격 범위·속도 상승
├─ HeavyCounter        : 예고 짧아짐 · 타격 강화
├─ BriefStagger        : 완전 붕괴 시 짧은 경직
└─ OpenPath            : 경직 후 기동 정지 = 문 열림
```

- 예고가 짧아진다. 팀 관측 없이 혼자 읽기 어렵다.
- 오만 연출·대사 없음. 기능만 강화.
- 최종 경직 → 정지 → 경로 개방.

### 4. 예고 신호 (보이는 것)

| 신호 | 표현 | 플레이어 반응 |
|------|------|----------------|
| 빛 | 방패면 가장자리 희미한 발광 | 창 준비 |
| 자세 | 벽 자세가 반 박 앞으로 기울 | 회피/측면 |
| 진동 | 조종간·발밑 짧은 떨림 | 타이밍 읽기 |
| 통신 | 유나 1회 (“예고”) | 확인 |

소리 없이 오지 않는다. **몸이 먼저 안다.**

### 5. 장면 리듬 (권장 4비트)

```
비트1  입구 · 벽 인식 · 첫 정면 타격 → 막힘·게이지 체감
비트2  예고 1~2회 · 창 확보 실패/성공 · 게이지 소모 시작
비트3  P2 진입 · 예고 짧아짐 · 팀 관측 필수 · 대가 가능
비트4  최종 창 · 집념 타격 · 경직 → 정지 → 문 열림
```

- 각 비트는 손으로 보이게. 설명 문장 최소.
- 필살/초필: 비트4에서 1회 이하.
- 광기: 열어 두되 끌어가지 않음.

### 6. 플레이어·팀 역할

| 역할 | 행동 | 본문 비트 |
|------|------|-----------|
| 리아 | 중심 · 예고 읽기 · 창에만 타격 · 정면 고집 금지 | 전 구간 |
| 유나 | 게이지·예고 타이밍 관측 · 통신 1~2회 | 비트2~3 |
| 레이 | 축·우선순위 · “창” 지시 · 침묵 허가 | 비트1·3 |
| 지원 | 엄호·측면 압박으로 예고 창 확보 | 비트2~4 |

리아 혼자 전 맵을 막지 않는다. **창은 팀이 연다.**

### 7. 체감 포인트 (본문 필수)

1. **게이지**  
   막히면 쌓인다 → 손 느려짐·진동. 숫자 설명 금지.

2. **예고 창**  
   빛·자세·진동이 먼저. “반격한다” 직접 서술 대신 **보이는 창**.

3. **손**  
   창이 열리면 손이 먼저 움직인다. 말보다 손.

4. **개방**  
   기동 정지 = 문이 열림. 승리 선언 없음. “그뿐이었다.”

5. **무반응**  
   방패가 쓰러져도 네메시스는 움직이지 않는다.

### 8. 실패·대가

| 상황 | 결과 |
|------|------|
| 예고 무시·정면 고집 | 반격 직격 · 기체 손상·손 떨림 |
| 창 소실 (팀 엄호 실패) | 게이지 재충전 · 시간 압박 |
| 반격 누적 과다 | 경로 일시 봉쇄 · 재시도 여지 |
| 최종 대가 | 부상·손상 가능 · 개방 후에도 안도 없음 |

### 9. 연출 금지 (전투)

- 오만 Selector · 「급이 아니다」 · 네메시스 원격 복제
- 손 완전 숨김 · 등급 판정 대사
- 장문 전술 설명 · 영웅 연설
- 게이지를 체력바 숫자로만 서술
- 아이기스 사연·감정 균열
