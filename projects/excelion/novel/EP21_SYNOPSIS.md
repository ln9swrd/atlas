## 긴장 축 (본문 필수)

| 축 | 다듬은 한 줄 |
|----|----------------|
| **벽** | 앞이 막혀 있다. 뚫는 게 아니라 부수는 것이다. |
| **게이지** | 막히면 쌓인다. 쌓이면 돌아온다. |
| **예고** | 반격은 소리 없이 오지 않는다. 창이 보인다. |
| **대가** | 문을 열어도, 그 너머는 더 무겁다. |
| **무반응** | 방패가 쓰러져도, 위계는 움직이지 않는다. |

긴장 = 큰 소리가 아니라 **게이지가 차는 속도**.

## 흐름 (4파트)

### Part 1 — 입구

- 게이트 입구. **아이기스** 전면.
- 가로 넓은 실루엣 · 벽 자세.
- 오만 없음 · 기능만. 대사 최소 또는 무음.
- 유나: 가드 게이지 감지.
- 레이: 돌파 축 지정.
- 목표: 격파 = 문 개방. 섬멸 아님.

### Part 2 — 가드

- P1: GuardIdle · TelegraphedCounter.
- 막히면 게이지 충전 → 예고 있는 반격.
- 리아: 정면 돌파 금지 · 예고 창 이용.
- 팀: 관측·엄호로 창 확보.
- 긴장 축: 게이지 차는 속도 · 반격 타이밍.

### Part 3 — 붕괴

- 게이지 브레이크 · BriefStagger.
- P2 가능: CounterWindowWider · HeavyCounter.
- 약점 창에 집념 돌파.
- 대가는 가능 (손상·부상).
- 방패 내구 임계 → 기동 정지.

### Part 4 — 개방

- 아이기스 정지. 길이 열림.
- **문이 열렸을 뿐이었다.**
- 네메시스 반응 **없음** · 흔들림 없음.
- 게이트 심부 진입 가능.
- 최종 영역 신호.
- 안도 없음. 다음은 내부.

## 전투 디테일

### 형태 · 승리 조건

| 항목 | 고정 |
|------|------|
| 형태 | 단독 보스 · 가드·반격 게이지 |
| 적 | **아이기스** 1기 |
| 페이즈 | P1 Guard → P2 WiderCounter |
| 클리어 | 가드 게이지 붕괴 · 기동 정지 = **문 개방** |
| 실패 | 반격 누적 과다 · 창 소실 · 경로 봉쇄 |
| 섬멸 목표 | 아님 (문이 열리면 끝) |

### 페이즈 상세

**P1 — Guard**

```
AEGIS P1
├─ GuardIdle        : 가로 벽 자세 · 정면 거부
├─ GuardGauge 충전  : 플레이어 타격/접근 시 쌓임
├─ TelegraphedCounter : 예고(빛·자세·짧은 진동) 후 반격
└─ 약점 창          : 반격 직후 · 예고 중 짧은 개방
```

- 정면 연속 타격 → 게이지만 채움 · 반격 유도.
- 예고가 보이면 회피/측면/팀 엄호로 창 확보.
- 창에 집념 타격 → 게이지 소모.

**P2 — WiderCounter** (게이지 2단계 또는 내구 임계)

```
AEGIS P2
├─ CounterWindowWider : 반격 범위·속도 상승
├─ HeavyCounter       : 예고 짧아짐 · 타격 강화
├─ BriefStagger       : 게이지 완전 붕괴 시 짧은 경직
└─ OpenPath           : 경직 후 기동 정지 = 문 열림
```

- P2 진입 후에도 오만 연출 없음.
- 약점 창이 더 짧아짐 · 팀 관측 필수.
- 최종 경직 → 정지 → 경로 개방.

### 플레이어·팀 역할

| 역할 | 행동 |
|------|------|
| 리아 | 중심 · 예고 읽기 · 창에만 타격 · 정면 고집 금지 |
| 유나 | 게이지 수치·예고 타이밍 관측 · 통신 1~2회 |
| 레이 | 축·우선순위 · “창” 지시 · 침묵 허가 |
| 지원 | 엄호·측면 압박으로 예고 창 확보 |

리아 혼자 전 맵을 막지 않는다. 창은 팀이 연다.

### 체감 포인트 (본문 필수)

1. **게이지 체감**  
   막히면 쌓인다 → 손이 느려지거나 진동으로 전달. 숫자 설명 금지.

2. **예고 창**  
   소리·빛·자세로 먼저 온다. “반격한다” 직접 서술 대신 **보이는 창**.

3. **손**  
   창이 열리면 손이 먼저 움직인다. 필살 과시 1회 이하.

4. **개방 감각**  
   기동 정지 = 문이 열림. 승리 선언 없음. “그뿐이었다.”

### 연출 금지 (전투)

- 오만 Selector · 「급이 아니다」 · 네메시스 원격 복제
- 손 완전 숨김 · 등급 판정 대사
- 장문 전술 설명 · 영웅 연설
- 게이지를 “체력바”처럼 숫자로만 서술 (몸으로 전달)
