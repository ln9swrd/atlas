## 1. 전체 골격

```
한계·손·원경 (직전)
  → 갈림 제시 (닫기/시간)
  → 손 선택 · 즉시 반응
  → 네메시스 한 줄 · 시선 불변
  → 전선·시간 잔존 · 침묵 · 손 · 회수 문장
```

C1 로직: **갈림 → 손 확정 → 즉시 결과 → 여운(회수)**.

## 4. 정보 순서

1. 한계(전제) → 손 잔존  
2. 원경·시선(벽)  
3. 갈림 대사  
4. 격파≠길 / 선택=길  
5. 손 행동 → 즉시 공간 반응  
6. 네메시스 한 줄·불변  
7. 잔존(전선·시간) → 침묵 → 손 → **회수 문장**

설명이 아니라 **손 → 결과 → 여운**.

---

## 5. 모티프 변주

| 모티프 | 변주 |
|--------|------|
| 손 | 아직 있다 → 봤다 → 먼저 움직였다 → 놓치지 않았다 → 조종간에 있었다 |
| 남다 | 시간/전선 남음 → 선택은 남았다 |
| 시선 | 바뀌지 않음 → 그대로 → 정면으로 받지 않음 |
| 끝 | 둘 다 끝 아님 → 끝난 뒤에도 |

회수 문장이 「남다」 모티프의 최종 변주.

| 3 | Part3 | 「이것은 시작에 불과하다.」 |

강세 간격이 짧고, 종지가 가장 짧고 단정.

## 7. C1 정합

| 조건 | 본문 |
|------|------|
| 갈림 제시 | 닫거나 / 시간을 벌거나 |
| 손·한마디로 확정 | 손이 먼저 움직였다 (연설 없음) |
| 즉시 결과 | 말이 있기 전에 공간이 반응했다 |
| 회수 문장 | 끝난 뒤에도 선택은 남았다 |

---

## 8. 결론

구조는 **단문·쌍 문장·손 모티프·남다 변주**.  
Part1 전제 → Part2 선택 행동 → Part3 벽의 한 줄 → Part4 여운·회수.  
C1·S1 결말 원칙(여지·비구원)과 맞다. 추가 다듬기 필수는 없음.
