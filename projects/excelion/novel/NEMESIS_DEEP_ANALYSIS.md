# 네메시스 심층 분석

---

## 0. 한 줄

네메시스는 **적이 아니라 등급표**다.  
리아를 이기려 하지 않고, **아직 몇 칸인지**만 본다. 시선은 끝까지 위에서 아래로만 간다.

---

## 1. 존재 정의

| 층 | 내용 |
|----|------|
| 역할 | S1 최종 보스 · 인물+기체 · 여성형 |
| 개념 | 중력 · 위계 · 절대 힘 |
| 심리 핵 | 오만 = 감정 과시가 아니라 **판정 권한의 자연스러움** |
| 대 리아 | 적 / 라이벌 / 대칭 인물 **아님** · 미등급 변수 |

핵심 전환: 아슈르(폐기) → 네메시스. 최종 유일 벽. 세스·크레일·아이기스는 도구·대행.

---

## 2. 철학 구조

```
위계 = 세계의 형태
  → 승패 < 등급
  → 손 = 이미 디센트(처리 모드)
  → 침묵·거리·시선 = 위계의 언어
```

| 믿음 | 결과 |
|------|------|
| 위계 밖 소음은 정리 대상 | 동기 설명 불필요 |
| 이겨도 등급이 안 오르면 의미 없음 | “이겼다” 서사에 흔들리지 않음 |
| 판정만 남긴다 | 분노·조급·공포 없음 |

내면은 **평가문**만 남긴다. 장문·회상·동질화 설교 금지.

---

## 3. 리아와의 비대칭

| 축 | 리아 | 네메시스 |
|----|------|----------|
| 동력 | 선택 · 손 · 밀어붙임 | 판정 · 등급 · 침묵 |
| 성장 | 전선→팀→돌입→한계→여지 | 등급표 한 칸 (시선 방향 불변) |
| 패배/위기 | 대가·손 유지 | 예상 · 손 더하지 않을 수 있음 |
| 최종 | 선택은 남았다 | 시작에 불과하다 |

대립은 **선악**이 아니라 **선택하는 자 vs 등급을 매기는 자**.  
대칭 라이벌로 읽히면 실패.

---

## 4. 도구 계층 (위계의 손)

```
네메시스 (위계 자체)
  └─ 아이기스 (입구 방패 · 대행 · 오만 0)
  └─ 세스 / 크레일 (ELITE 도구 · 역할 모듈)
  └─ ORD 잔당 (양산)
```

- 세스 패배 = 변수 처리 / 다음 단계. 애석·분노 없음.  
- 아이기스 격파 후에도 네메시스 **흔들림 없음** (EP21).  
- 도구가 부서져도 위계는 남아 있다 → 「시작에 불과하다」와 정합.

## 5. S1 존재감 곡선 (후반 강조)

| 구간 | 형태 | 기능 |
|------|------|------|
| EP4–7 | 이름·시선·원격 일격 | 벽의 존재 증명 |
| EP9 | 「아직 급이 아니다」 | **유일** 전면 판정 대사 |
| EP10–12 | 압박·후퇴·오점 | 재평가 · 시선 유지 |
| EP14–17 | 거의 공백 / 도구만 | 리아 측 성장 공간 |
| EP18 | 원경 · 한 칸 | 등급 재확인 (C5) |
| EP19–21 | 배경 · 무반응 | 돌입·관문 중 흔들리지 않음 |
| EP22 | 대기 · 내려다봄 | 내부의 끝 |
| EP23 | P1–P2 · 침묵 | 한계까지 밀어붙이는 상대 (C6) |
| EP24 | 「시작에 불과하다」 | 오만 종지 · 여지와 대비 (C1) |

후반 전략: **말을 줄이고 시선·거리·공간으로만 존재**.  
「급이 아니다」 재사용 금지. 최종 한 줄만 남김.

## 6. 전투·공간 언어

| 요소 | 의미 |
|------|------|
| 중력 | 공격이 아니라 **서 있을 자리 삭제** |
| 원격 | 강함의 기본 자세 |
| 디센트 | 가까이 옴 = 처리 모드 (감정 폭발 아님) |
| 손 약함 | 중력이 손을 대체 · 난무 금지 |
| 실루엣 | 세로·높은 중심·여성형 |

수치 자리: 최종 HP **120** · 페이즈 3. 세스 48 / 아이기스 80–96 위 층.

본문(EP23) 체감: 발이 늦음 · 공간이 발을 읽음 · 원경 시선 불변 · 한계에도 손 유지(리아).

## 7. 대사·침묵 설계

| 규칙 | 내용 |
|------|------|
| 천장 | 한 화 한 줄 |
| 고정 | EP9 「아직 급이 아니다」 / 최종 「이것은 시작에 불과하다」 |
| 침묵 | 위계를 만드는 주 채널 |
| 금지 | 동기 장문 · 리아 호칭 · 동질화 · 광기 대체 |

침묵이 길수록 오만이 커진다. 말이 많아지면 세스급 “역할자”로 추락.

---

## 8. 드라마 기능 (S1)

1. **성장의 자** — 리아의 한 칸·밀어붙임·선택이 보이게 하는 배경 척도  
2. **안도 차단** — 문 개방·도구 격파 후에도 흔들리지 않음  
3. **결말 비구원** — 「시작에 불과」 vs 「선택은 남았다」 이중 종지  
4. **위계 세계관 체현** — 설명 없이 거리·시선·중력으로만 전달

S1을 “보스 토벌 완료”로 닫지 않고 **여지**로 닫는 장치의 중심.

## 11. 결론

네메시스의 심층은 **캐릭터성 = 위계 자체**.  
감정이 없는 것이 아니라, **감정 대신 판정만 남는 존재**.  
리아가 “선택”으로 닫을 때, 네메시스는 “등급은 끝나지 않았다”로 남는다.  
둘 다 옳고 그름이 아니라, **S1 이후를 여는 이중 여운**이다.
