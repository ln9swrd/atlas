# 서사 구조론 기초

> 2026-08-07 · Excelion 적용용 요약

**상태: 기초 고정 · 강의용 장문 금지 원칙과 병행**

---

## 0. 한 줄

서사 = **누가, 무엇을 원해, 무엇이 막고, 무엇을 선택해, 무엇이 달라졌는가.**

설명보다 **행동·전투·감정**이 그 답을 보여 줘야 한다.

---

## 1. 최소 단위 (신·비트)

| 요소 | 질문 |
|------|------|
| **목표** | 이 장면의 30초 목표는? |
| **장애** | 무엇이 막나? (적·시간·몸·선택) |
| **행동** | 인물이 손으로 무엇을 하나? |
| **변화** | 끝에서 관계·정보·전선 중 무엇이 달라졌나? |
| **다음** | 왜 다음이 궁금한가? |

하나라도 없으면 그 비트는 약하다.

---

## 2. 에피소드 구조 (1화)

```
시작  목표 제시 (몸이 먼저)
  ↓
중간  장애 강화 · 시도 · 대가
  ↓
끝    부분 해소 + 새 질문 (가져갈 문장)
```

| 구간 | 역할 |
|------|------|
| 개막 | 목표·전장·손 | 
| 중반 | 전투·갈등·정보 파편 |
| 종반 | 클리어 조건 달성 · 여운 · 훅 |

Excelion: 매 화 **가져갈 문장 1** · 다음 화 훅 1.

---

## 3. 시즌 구조 (S1 · 24화)

고전 3막을 Excelion 성장 축에 대응.

| 막 | 대략 | 기능 |
|----|------|------|
| **1막** | EP1–8 | 세계·규칙·동료 · 첫 계단(세스) · **상실(카이)** |
| **2막** | EP9–17 | 벽(네메시스) · 팀 · 위계 · **기원·선택 가능** |
| **3막** | EP18–24 | 등급 · 돌입 · 레이드 · **최종 선택** |

성장 한 줄 (`REBUILD`):

```
생존자 → 계단(세스) → 상실 → 벽(네메시스) → 이해·팀 → 기원 → 등급 → 선택
```

중반 전환점: 상실(EP8) · 전면 벽(EP9) · 게이트/기원(EP13–17) 중 **선택이 바뀌는 지점**.

---

## 4. 갈등 종류 (섞되 한 화에 주력 1)

| 종류 | 예 |
|------|-----|
| 대인 | 세스·크레일·네메시스 |
| 대환경 | 통로·신호·게이트 |
| 대자아 | 광기 · 손 · “무엇을 선택하는가” |
| 대체계 | 위계·역할 모듈·ORD |

한 화에 주력 갈등 1 + 보조 1. 전부 동시에 설명하지 않음.

---

## 5. 정보 공개 (떡밥)

```
심기 → 방치(짧게) → 회수(행동으로)
```

- **심기:** 파편·시선·한 줄 (강의 금지)
- **회수:** 전투·손·선택으로만 의미 확정
- 회수 없이 심기만 쌓이면 실패

Excelion 예: BRAVE 기원 파편(EP17) → 돌입 후보 확정(회수) → EP18 등급(다음 심기).

---

## 6. 캐릭터 arc (주인공)

| 단계 | 질문 |
|------|------|
| 결핍 | 무엇이 없나? (생존·자격·이해) |
| 욕망 | 무엇을 하나? (막는다·연다·고른다) |
| 대가 | 무엇을 잃나? (카이·손·전선) |
| 선택 | 같은 상황에서 **다른 손**을 쓰나? |
| 변화 | 등급·관계·전선이 어떻게 바뀌나? |

“강해졌다”는 arc가 아니다. **선택과 대가**가 arc다.

---

## 7. 소년만화 리듬 (프로젝트 고정)

| 체크 | 기준 |
|------|------|
| 30초 목표 | 개막 직후 목표가 보이는가 |
| 다음 화 | 훅이 있는가 |
| 행동 우선 | 설명 < 손·전투·감정 |
| 계단과 벽 | 세스=계단 · 네메시스=벽 혼동 없음 |
| 가져갈 문장 | 1화 1문장 |

분량보다 **리듬**. 짧아도 재미 없으면 실패.

## 9. Excelion에 바로 쓰는 질문지

본문·시놉 쓰기 전:

1. 이 화의 **목표 1**은?
2. **장애 1**은?
3. 리아의 **손**은 무엇을 하나?
4. 끝에 **무엇이 달라지나?**
5. **가져갈 문장**은?
6. 다음 화 **훅**은?

6개 중 4개 이상 비면 구조 재작업.
