# C1–C6 유형별 구현 로직

> 2026-08-07 · M2b  
> 근거: `CLIMAX_TYPE_SPEC.md` · `EP_CLIMAX_DESIGN.md`  
> 목적: 본문 작성 시 **어떤 순서로, 무엇을 검사하고, 언제 피크를 찍는지** 고정

---

## 0. 공통 진입 로직

```
START
  → 이 화의 주력 코드 확인 (EP 매핑)
  → 목표 1 · 가져갈 문장 로드
  → 비트1 진입
  → 각 비트 종료 시 게이트 검사
  → 피크 비트에서 가져갈 문장 회수
  → 훅 → END
```

**공통 게이트 (매 비트 후)**
| 검사 | 실패 시 |
|------|---------|
| 손이 보이는가 | 설명 문장 삭제 · 손/진동으로 교체 |
| 연설·강의가 들어갔는가 | 삭제 |
| 목표가 아직 열려 있는가 | 비트 유지 · 피크 미도달 |

## 1. C1 선택 — 구현 로직

```
C1_Root
├─ 갈림 제시? (도망/돌입, 닫기/벌기)
│   └─ NO → 수치·침묵·통신으로 갈림 심기
├─ 압박 충분? (시간·보급·균열)
│   └─ NO → 압박 비트 추가 (말 없이 숫자)
├─ 선택 입력
│   └─ 손 먼저 → 한마디 이하 → 즉시 결과
├─ 결과 발생?
│   └─ NO → 경보·출격·경로 변경 강제
└─ 가져갈 문장 회수 → 훅
```

| 노드 | 구현 |
|------|------|
| 갈림 제시 | 회의·수치·침묵. 장문 토론 금지 |
| 압박 | 화면 숫자·발밑·통신 끊김 |
| 선택 입력 | 손이 조종간에. 말 ≤1문장 |
| 즉시 결과 | 말이 끝나기 전 경보/출격 |
| 회수 | “~하기로 했다” 계열 몸 문장 |

**종료 조건:** 선택 + 즉시 결과 + 훅 1

---

## 2. C2 격파 — 구현 로직

```
C2_Root
├─ 대상 인식 (실루엣·서명·게이지)
├─ 첫 접촉 → 막힘/충전 체감?
│   └─ NO → 정면 타격 1회 강제 (막힘 연출)
├─ 예고 발생?
│   └─ YES → 창 확보 시도 (팀 역할)
│   └─ 창 실패 → 대가(손상) → 재시도
├─ 약점 창 타격 → 게이지/내구 소모
├─ 임계?
│   └─ NO → 예고 루프
│   └─ YES → 붕괴·정지
├─ 목표 달성 (문 열림/전선 유지)
└─ 안도 없는 훅 · 가져갈 문장 회수
```

| 노드 | 구현 |
|------|------|
| 대상 인식 | 가로 서명·벽 자세·기능만 (오만 0) |
| 막힘 체감 | 손 진동·무게. 숫자 바 금지 |
| 예고 | 빛·자세·진동 **먼저** |
| 창 확보 | 리아 단독 금지 · 팀 엄호/관측 |
| 붕괴 | 경직→정지. 승리 연설 없음 |
| 회수 | “문이 열렸을 뿐” / “혼자 막을 수 있는 벽이 아니었다” |

**종료 조건:** 대상 정지 + 목표 달성 + 안도 없음

## 3. C3 인식 — 구현 로직

```
C3_Root
├─ 파편/이상 감지 (발밑·손·화면 순서)
├─ 이전 방식으로 시도?
│   └─ YES → 막힘 · “그게 아니었다” 씨앗
├─ 확정 단서 (잔해·시선·짧은 통신)
│   └─ 설명 문장? → 삭제 · 손/시선으로 교체
├─ 질문 축 이동?
│   └─ NO → 확정 비트 보강
│   └─ YES → 가져갈 문장 회수
└─ 훅 (다음 전선/신호)
```

| 노드 | 구현 |
|------|------|
| 감지 순서 | 발밑 → 손 → 화면 (역순 금지) |
| 이전 방식 시도 | 한 전선 영웅 / 숭배 가정 등 |
| 확정 단서 | 잔해 한 줄 · 시선 · 통신 1회 |
| 질문 축 | “왜” → “무엇을 선택하는가” |
| 회수 | “저들은 역할이었다” 계열 |

**종료 조건:** 인식 확정 + 질문 축 이동 + 훅

## 4. C4 적응 — 구현 로직

```
C4_Root
├─ 진입 · 이상 감지 (물리·통신)
├─ 기존 방식 사용?
│   └─ YES → 실패 · 몸이 대신 버팀
├─ 공명·손만으로 경로 유지?
│   └─ NO → 소규모 적/함정으로 압박 유지
├─ 설명 문장 유입?
│   └─ YES → 삭제
├─ 버팀 확정
└─ 훅 (대기하는 시선)
```

| 노드 | 구현 |
|------|------|
| 이상 감지 | 발·손·통신 끊김. 강의 0 |
| 기존 방식 실패 | 한 번 보여주고 버림 |
| 버팀 | BRAVE 공명 · 손 · 발 |
| 회수 | “설명 없이, 몸이 먼저 버텼다” |

**종료 조건:** 몸이 경로를 유지 + 설명 없음 + 훅

## 5. C5 한 칸 — 구현 로직

```
C5_Root
├─ 무게·등급 체감 (발 늦음·손 무게)
├─ 막힘 → 옆으로 꺾기?
│   └─ NO → 정면 고집 금지 · 꺾기 강제
├─ 원경 시선?
│   └─ YES → 정면 받지 않음 · 경로 위 한 점만
├─ 승패 판정 문장?
│   └─ YES → 삭제
├─ 경로 확보 · 1칸 전진
└─ 가져갈 문장 회수 · 훅
```

| 노드 | 구현 |
|------|------|
| 체감 | 발목·조종간. 「급이 아니다」 금지 |
| 꺾기 | 승패 재지 않음 · 멈추지 않음 |
| 시선 | 원경 · 내려봄 · 말 없음 |
| 회수 | “한 칸만 움직였다” |

**종료 조건:** 1칸 전진 + 승패 없음 + 훅

---

## 6. C6 한계 — 구현 로직

```
C6_Root
├─ P1 압박 (거리·등급·손 약함)
├─ P2 암시 (오만 유지)
├─ 한계 신호 (진동·경고·손 떨림)
│   └─ 손 놓침?
│       └─ YES → 다시 쥠 (필수)
├─ 비참·포기 문장?
│   └─ YES → 삭제
├─ 밀어붙임 확정
└─ 가져갈 문장 회수 · 마지막 선택 직전 훅
```

| 노드 | 구현 |
|------|------|
| P1–P2 | 공간 등급 · 오만 유지 · 새 장문 대사 없음 |
| 한계 신호 | 손 떨림·미끄러짐·경고음 |
| 다시 쥠 | 한계 = 포기 아님 |
| 카이 습관 | 최대 1회 |
| 회수 | “이기고 지는 게 아니라, 밀어붙였다” |

**종료 조건:** 한계 도달 + 손 유지 + 다음 선택 훅

## 7. 본문 작성 순서 (공통)

```
1. EP 코드 확인
2. 목표 1 · 가져갈 문장 고정
3. 비트1~4 초안 (손 우선)
4. 게이트 검사 (손·연설·목표)
5. 피크 비트에서 문장 회수
6. 훅 1줄
7. 유형별 본문 직전 질문 통과
```
