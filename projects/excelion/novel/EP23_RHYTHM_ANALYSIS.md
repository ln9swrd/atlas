# EP23 「판정」 문장 리듬 분석

> 2026-08-07 · 대상: `ep23.md` (다듬기 후)

---

## 1. 전체 템포

| Part | 템포 | 한 줄 |
|------|------|--------|
| 1 거리 | 느림 · 절단 | 공간·실루엣·침묵이 먼저 |
| 2 P1 | 중 · 반복 | 발→막힘→전진 루프 |
| 3 P2 | 중·단 | 조임 → 축 압박 → 손 회복 |
| 4 한계 | 짧음 · 확정 | 경고 → 손 유지 → 회수 문장 |

전체: **단문 우세**. 호흡은 줄바꿈으로 자른다.

---

## 2. 문장 길이 분포 (본문)

| 유형 | 예 | 기능 |
|------|-----|------|
| 초단 (3~8자급) | 네메시스는 멀었다. / 또 막혔다. | 타격·정지 |
| 단문 | 공간이 그 발을 읽었다. | 원인·결과 1회 |
| 병렬 단문 | 손이 떨렸다. 그래도 놓지 않았다. | 대비·의지 |
| 조각 | 세로로 긴 실루엣. 높은 중심. | 시각 인서트 |
| 한 호흡 쌍 | 여기는 이기는 곳이 아니었다. 밀어붙이는 곳이었다. | 정의 전환 |

장문·복문 연쇄 거의 없음. 리듬 = **끊고 이어 붙이기**.

## 3. Part별 리듬 패턴

### Part 1
```
무게 → 거리 → 실루엣 조각 → 손 없음 → 침묵
→ 발 지연 → 자리 좁음 → 대사 2 → 승패 거부
```
박자: 느린 4/4. 행동보다 **관측**.

### Part 2
```
발 1 → 공간 반응 → 발목 선 → 꺾기 / 막힘 → 전진
→ 손 쥠 → 광기·필살 억제 → 이기지 않음 / 밀어붙임
→ 시선 불변
```
박자: 짧은 시도–거부 반복. **전진이 한 박 늦게** 온다.

### Part 3
```
조임 → 밀도 조각 → 오만·무대사 → 침묵=위계
→ 축 압박 → 끊고 넘기고 밀기 → 미끄러짐 / 재쥠
→ 카이 반 박 → 그뿐
```
박자: 중간에서 **삼연타**(끊고, 넘기고, 다시 밀었다) 후 손 비트.

### Part 4
```
경고 → 한계 → 떨림 / 유지 → 이기지 않음 / 밀어붙임
→ 원경 불변 → 대사 2 → 선택 남음 → 손 유지 → 회수
```
박자: 가장 짧음. 회수 문장이 **종지**. 여운은 다음 화.

## 4. 강세 위치

| 강세 | 위치 | 문장 |
|------|------|------|
| 1 | Part2 중반 | 여기는 이기는 곳이 아니었다. 밀어붙이는 곳이었다. |
| 2 | Part3 손 | 손이 한 번 미끄러졌다. 다시 쥐었다. |
| 3 | Part4 회수 | 이기고 지는 게 아니라, 밀어붙였다. |

강세가 뒤로 갈수록 **짧아지고 단정**해짐. C6(한계)에 맞음.

---

## 5. 반복·변주

| 모티프 | 변주 |
|--------|------|
| 손 | 세게 쥠 → 미끄러짐/재쥠 → 떨림/놓지 않음 → 떼지 않음 |
| 시선/원경 | 바뀌지 않음 · 다가오지 않음 · 여전히 원경 |
| 밀어붙임 | Part2 정의 → Part4 확정(가져갈 문장) |
| 승패 거부 | 재지 않았다 → 이기는 곳 아님 → 이기고 지는 게 아님 |

반복은 **메아리**이지 복붙이 아님. 회수 문장이 최종 변주.

## 6. 약점·유지

| 항목 | 판단 |
|------|------|
| Part1 조각 문장 | 시각 인서트로 유효 · 유지 |
| 「디센트 암시」 | 다소 개념어 · 본문 밀도상 허용, 원하면 체감 한 줄로 교체 가능 |
| 카이 습관 | 반 박·그뿐 · 남발 없음 · 유지 |
| 회수 문장 2회 근접 | Part4 내 예고+종지 · 의도적 메아리 · 유지 |

## 7. 결론

리듬은 **절단 단문 + 쌍 문장 강세 + 손 모티프 변주**.  
Part1 관측 → Part2–3 시도 → Part4 한계·회수로 템포가 줄며 닫힌다.  
C6 구현과 정합. 추가 다듬기는 「디센트 암시」 체감화 정도만 선택.
