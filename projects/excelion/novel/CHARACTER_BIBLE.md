# 1. 리아 (RIA)

## 기본

| 항목 | 내용 |
|------|------|
| 역할 | 주인공 · BRAVE 파일럿 |
| 나이 | **16세** |
| 초기 | 생존자 · 정비 지원 · 비전투원 |
| 최종 | BRAVE 정식 파일럿 · 게이트를 닫아 시간을 번 존재 |

## 외형

- 작은 체구 · 민첩 · 기술자 느낌
- 검은 단발 · 깊은 회색 눈 · 작업 흔적 손 · 정비 재킷

이미지: "전사가 되기 전부터 기계를 이해했던 소녀"

## 성격

초기: 현실적 · 조심 · 자신감 부족  
장점: 포기 안 함 · 관찰 · 기계 감각  
약점: 자기 가치 낮게 봄 · 영웅 부담

## BRAVE 관계

초기: 고장난 기체와 이해하는 사람  
중반: 이해하기 시작  
후반: 서로 보완 · 공명으로 진화

## 성장 (24화 목표)

| 구간 | 위치 |
|------|------|
| EP01~06 | 시험 파일럿 |
| EP07~12 | 정식 후보 · 세스 경험 |
| EP13~18 | 진정한 파일럿 |
| EP19~24 | 계승자 · 선택 |

# 4. 네메시스 (Nemesis) — 최종 보스

| 항목 | 내용 |
|------|------|
| 역할 | **S1 최종 보스** |
| 성별 | **여성형** |
| 개념 | 중력 · 우주적 힘 · 절대 힘 |
| 핵심 | 리아를 적이 아니라 **아직 안 된 것**으로 봄 · 등급을 매김 |

외형: 높은 중심 · 긴 실루엣 · 손 안 보임 · 위계  
대사: EP9「아직 급이 아니다」 · 최종「이것은 시작에 불과하다」

### 심화 요약

- 위계가 세계. 승패 < 등급.
- 분노·조급·친근 없음. 판정만.
- 세스 = 도구에 가깝다 (숭배 없음).
- 리아 성장 = 등급표 한 칸. 시선 방향은 불변.
- 후퇴 = 재평가. 패배 후에도 오만 유지.

상세: `state/NEMESIS_ARROGANCE_FIXED.md` · `design/enemy/NEMESIS_MECHA_SPEC.md`

**아슈르는 최종보스로 사용하지 않는다.**
