## 1. 공통 규칙

1. 한 화 **주력 유형 1** (EP17만 보조 1 허용)
2. 피크 = **손·전투·선택**으로만 표현
3. 가져갈 문장 = 그 유형의 회수 문장
4. 연속 동일 유형 권장 금지 (C2 연속 시 리듬 주의)
5. 설명·연설·강의로 피크 만들지 않음

## 2. 유형별 설계 세부

### C1 선택

**정의**  
갈림길에서 리아가 하나를 고른다. 연설 없음. 손·한마디로 확정.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 선택 직후 경보·출격·경로 변경이 **즉시** |
| 금지 | 장문 토론 · 영웅 선언 · 선택 후 여유 |
| EP | 19, 24 |
| 문장 형태 | “~하기로 했다.” / “선택은 남았다.” |

**비트 구조**
```
비트1  갈림 제시 (도망/돌입, 닫기/벌기) — 수치·침묵으로
비트2  압박 강화 (시간·보급·균열) — 말보다 숫자
비트3  선택 — 손·한마디 · 말이 끝나기 전 결과
비트4  즉시 결과 · 훅
```

**몸 큐**
- 손이 조종간/레버에 먼저 간다
- 시선이 모인다 · 연설을 기다리는 눈 없음
- 선택 직후 경보·진동·통신 끊김

**실패 패턴**
- 선택 전 장문 회의
- 선택 후 여유 있는 대사
- “내가 가겠다” 영웅 톤

**본문 직전 질문**  
선택 직후 즉시 결과가 오는가? 연설이 없는가?

---

### C2 격파

**정의**  
대상(보스·벽)이 기동 정지하거나 무너진다. 섬멸이 아니라 **목표 달성**.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 약점 창·팀 역할·게이지 붕괴가 **손**으로 보임 |
| 금지 | 사연·오만 복제 · 혼자 전 맵 처리 · 승리 연설 |
| EP | 15, 20, 21 |
| 문장 형태 | “혼자 막을 수 있는 벽이 아니었다.” / “문이 열렸을 뿐이었다.” |

**비트 구조**
```
비트1  대상 인식 · 첫 접촉 · 막힘/게이지 체감
비트2  예고·창·역할 분담 · 실패 가능
비트3  약점 창 집념 · 팀 합류 · 대가 가능
비트4  붕괴·정지 · 목표 달성 · 안도 없는 훅
```

**몸 큐**
- 예고: 빛·자세·진동이 먼저
- 창이 열리면 손이 먼저 움직인다
- 팀 통신 1~2회 (관측·축)
- 격파 후 승리 선언 없음

**실패 패턴**
- 리아 혼자 전 맵 처리
- 보스 사연·감정 균열
- 게이지를 숫자 바로만 서술

**본문 직전 질문**  
약점 창·팀 역할이 손으로 보이는가? 혼자 막지 않는가?

---

### C3 인식

**정의**  
“무엇인가”가 설명 없이 확정된다. 잔해·시선·손의 반응으로만.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 질문이 바뀌거나, 이전 오해가 행동으로 깨짐 |
| 금지 | 장문 분석 · 세계관 강의 · NPC 설명 독백 |
| EP | 14, 16, 17 |
| 문장 형태 | “저들은 역할이었다.” / “한 전선으로는 모자라다.” |

**비트 구조**
```
비트1  파편·잔해·전선 확대 — 몸이 먼저 이상 감지
비트2  시도·접촉 — 이전 방식으로 막힘
비트3  확정 — 손·시선·짧은 통신으로 “그게 아니었다”
비트4  질문이 바뀜 · 다음 훅
```

**몸 큐**
- 발밑·손·화면 순서 (발밑이 먼저)
- 분석은 파편·한 줄·시선만
- “왜 싸우는가” → “무엇을 선택하는가”처럼 질문 축 이동

**실패 패턴**
- 회의실 장문 브리핑
- “알고 보니 ~였다” 서술 강의
- 인식 후 즉시 완전 이해 과시

**본문 직전 질문**  
설명이 아니라 잔해·손·시선으로 확정되는가?

---

### C4 적응

**정의**  
규칙이 다른 공간에서 몸이 먼저 버틴다. 이해는 나중에.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 통신·물리 이상이 와도 BRAVE 공명·손만으로 경로 유지 |
| 금지 | “여기는 ~한 공간이다” 강의 · 즉시 완전 적응 과시 |
| EP | 22 |
| 문장 형태 | “설명 없이, 몸이 먼저 버텼다.” |

**비트 구조**
```
비트1  진입 · 이상 감지 (발·손·통신)
비트2  기존 방식 실패 · 몸이 버팀
비트3  공명·손으로 경로 유지 · 소규모 적/함정
비트4  버텼다 · 다음(대기하는 시선) 훅
```

**몸 큐**
- 발이 먼저 안다
- 통신이 끊겨도 손은 움직인다
- 설명 문장 0에 가깝게

**실패 패턴**
- 공간 규칙 장문 설명
- “적응했다” 직접 서술
- 보스급 연출로 채움

**본문 직전 질문**  
강의 없이 몸이 버티는가?

---

### C5 한 칸

**정의**  
이기고 지는 전투가 아니다. 멈추지 않고 1칸 움직이는 것이 피크.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 공간 무게·원경 시선 아래에서도 경로가 열림 |
| 금지 | 승패 판정 · 장기전 · 「급이 아니다」 반복 |
| EP | 18 |
| 문장 형태 | “한 칸만 움직였다.” |

**비트 구조**
```
비트1  무게·등급 체감 · 발이 늦어짐
비트2  막힘 · 옆으로 꺾기 · 멈추지 않음
비트3  원경 시선 · 한 점으로만 받음
비트4  경로 확보 · 한 칸 · 훅
```

**몸 큐**
- 발목이 무겁다 · 손이 조종간을 세게 쥔다
- 승패를 재지 않는다
- 시선은 정면이 아니라 경로 위 한 점

**실패 패턴**
- 보스전처럼 페이즈 장기화
- 「급이 아니다」 재사용
- “이겼다/졌다” 판정 문장

**본문 직전 질문**  
승패가 아니라 1칸 전진이 피크인가?

---

### C6 한계

**정의**  
밀어붙이다 기체·손·시간이 한계에 닿는다. 다음 선택의 직전.

| 항목 | 내용 |
|------|------|
| 피크 조건 | 출력·내구·통신 중 하나가 끊기기 직전. 그래도 손은 놓치지 않음 |
| 금지 | 완전 패배 연출 · 비참 · 포기 선언 |
| EP | 23 |
| 문장 형태 | “이기고 지는 게 아니라, 밀어붙였다.” |

**비트 구조**
```
비트1  P1 압박 · 거리·등급 · 손 약함
비트2  P2 암시 · 오만 유지 · 밀어붙임
비트3  한계 신호 (진동·경고·손 떨림)
비트4  그래도 손 · 마지막 선택 직전 훅
```

**몸 큐**
- 손이 떨리거나 미끄러져도 다시 쥔다
- 비참·절규 없음

**실패 패턴**
- 패배 연출·절망 독백
- 한계 = 포기
- 네메시스 오만 붕괴

**본문 직전 질문**  
한계에 닿아도 손을 놓지 않는가? 비참 없는가?
