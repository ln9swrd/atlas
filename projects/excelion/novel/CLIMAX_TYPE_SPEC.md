## 0. 제안 요약

기존 8유형을 **6유형**으로 정리한다.  
겹치는 것(인식·전환 / 인식)을 합치고, “팀 격파/전면”을 하나로 묶는다.

| 코드 | 유형명 | 한 줄 |
|------|--------|--------|
| **C1** | 선택 | 손·말로 **고른다**. 결과가 즉시 따라온다. |
| **C2** | 격파 | 보스/벽을 **손과 팀**으로 무너뜨린다. |
| **C3** | 인식 | 정보가 **행동·잔해·손**으로 확정된다. |
| **C4** | 적응 | 규칙이 바뀐 공간에서 **몸이 버틴다**. |
| **C5** | 한 칸 | 승패가 아니라 **전진 1칸**이 피크다. |
| **C6** | 한계 | 밀어붙이다 **기체가/손이 한계**에 닿는다. |

## 1. 유형 정의

### C1 선택

| 항목 | 내용 |
|------|------|
| 정의 | 갈림길에서 리아가 **하나를 고른다**. 연설 없음. 손·한마디로 확정. |
| 피크 조건 | 선택 직후 경보·출격·경로 변경이 **즉시** 온다. |
| 금지 | 장문 토론 · 영웅 선언 · 선택 후 여유 |
| EP 예 | 19(돌입), 24(게이트 닫기/시간 벌기) |
| 가져갈 문장 형태 | “~하기로 했다.” / “선택은 남았다.” |

### C2 격파

| 항목 | 내용 |
|------|------|
| 정의 | 대상(보스·벽)이 **기동 정지**하거나 무너진다. 섬멸이 아니라 **목표 달성**. |
| 피크 조건 | 약점 창·팀 역할·게이지 붕괴가 **손**으로 보인다. |
| 금지 | 사연·오만 복제 · 혼자 전 맵 처리 · 승리 연설 |
| EP 예 | 15(크레일), 20(레이드 총압 돌파), 21(아이기스) |
| 가져갈 문장 형태 | “혼자 막을 수 있는 벽이 아니었다.” / “문이 열렸을 뿐이었다.” |

### C3 인식

| 항목 | 내용 |
|------|------|
| 정의 | “무엇인가”가 **설명 없이** 확정된다. 잔해·시선·손의 반응으로만. |
| 피크 조건 | 질문이 바뀌거나, 이전 오해가 행동으로 깨진다. |
| 금지 | 장문 분석 · 세계관 강의 · NPC 설명 독백 |
| EP 예 | 14(여러 전선), 16(역할 모듈) |
| 가져갈 문장 형태 | “저들은 역할이었다.” / “한 전선으로는 모자라다.” |

### C4 적응

| 항목 | 내용 |
|------|------|
| 정의 | 규칙이 다른 공간에서 **몸이 먼저** 버틴다. 이해는 나중에. |
| 피크 조건 | 통신·물리 이상이 와도 BRAVE 공명·손만으로 경로가 유지된다. |
| 금지 | “여기는 ~한 공간이다” 강의 · 즉시 완전 적응 과시 |
| EP 예 | 22(내부) |
| 가져갈 문장 형태 | “설명 없이, 몸이 먼저 버텼다.” |

### C5 한 칸

| 항목 | 내용 |
|------|------|
| 정의 | 이기고 지는 전투가 아니다. **멈추지 않고 1칸** 움직이는 것이 피크. |
| 피크 조건 | 공간 무게·원경 시선 아래에서도 경로가 열린다. |
| 금지 | 승패 판정 · 장기전 · 「급이 아니다」 반복 |
| EP 예 | 18(등급) |
| 가져갈 문장 형태 | “한 칸만 움직였다.” |

### C6 한계

| 항목 | 내용 |
|------|------|
| 정의 | 밀어붙이다 **기체·손·시간이 한계**에 닿는다. 다음 선택의 직전. |
| 피크 조건 | 출력·내구·통신 중 하나가 끊기기 직전. 그래도 손은 놓치지 않는다. |
| 금지 | 완전 패배 연출 · 비참 · 포기 선언 |
| EP 예 | 23(판정) |
| 가져갈 문장 형태 | “이기고 지는 게 아니라, 밀어붙였다.” |

## 3. 사용 규칙

1. **한 화 주력 유형 1** (EP17만 보조 1 허용)
2. 피크는 반드시 **손·전투·선택**으로 표현
3. 가져갈 문장 = 그 유형의 회수 문장
4. 연속 동일 유형 금지 권장 (C2 연속 시 리듬 붕괴)
5. C1·C6은 시즌 후반에 배치 (이미 반영됨)
