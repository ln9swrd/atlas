## 0. 한 줄

후반 11화 = **전선 확대 → 팀·도구 이해 → 돌입 → 방패·내부 → 판정 → 선택(여지)**.

성장 축: 한 전선 영웅 → 우선순위·팀 → 돌입 선택 → 밀어붙임 → **끝난 뒤에도 선택**.

---

## 1. 3단 배치

| 단 | EP | 기능 |
|----|-----|------|
| **확대·이해** | 14–17 | 전선·팀·역할·기원 |
| **돌입·관문** | 18–21 | 등급·선택·레이드·방패 |
| **심부·결말** | 22–24 | 적응·판정·선택(여지) |

고전 3막이 아니라 **압박 밀도**로 나뉨. 보스 격파만으로 단을 나누지 않음.

## 2. 클라이맥스 코드 분포

| 코드 | EP | 역할 |
|------|-----|------|
| C3 인식 | 14, 16, 17 | 전선·역할·해금 |
| C2 격파 | 15, 20, 21 | 크레일·레이드·아이기스 |
| C5 한 칸 | 18 | 승패 아닌 전진 |
| C1 선택 | 19, 24 | 돌입 · 최종 여지 |
| C4 적응 | 22 | 몸 버팀 |
| C6 한계 | 23 | 밀어붙임 · 선택 직전 |

**C2가 15·20·21에 모이되**, 사이에 C3·C5·C1이 끼어 리듬 붕괴를 막음.  
종결은 **C6 → C1** (한계 다음 선택). 격파로 시즌을 닫지 않음.

## 3. 목표·가져갈 문장 사슬

```
14 한 전선으로는 모자라다
15 혼자 막을 수 있는 벽이 아니었다
16 저들은 역할이었다
17 선택 가능한 기체였다
18 한 칸만 움직였다
19 돌입하기로 했다
20 혼자 전 맵을 막지 않는다
21 문이 열렸을 뿐이었다
22 몸이 먼저 버텼다
23 밀어붙였다
24 선택은 남았다
```

사슬 성격: **규모 인식 → 팀 → 위계 이해 → 자격 → 생존 전진 → 돌입 → 팀 중심 → 개방(안도 없음) → 적응 → 한계 → 여지**.

종결 문장이 “이겼다”가 아니라 **“남았다”**인 점이 S1 고정 원칙과 일치.

## 4. 갈등 주력 (화당 1)

| EP | 주력 갈등 |
|----|-----------|
| 14–16 | 대환경·대체계 (전선·역할) |
| 15·20·21 | 대인(도구·방패) + 팀 |
| 17 | 대자아·기원 (손·해금) |
| 18–19 | 대환경·대자아 (등급·돌입) |
| 22–23 | 대환경·대자아 (내부·한계) |
| 24 | 대자아 선택 (게이트/시간) |

네메시스는 **최종 유일 벽**. 15·21은 도구·대행, 23–24만 본 판정·여지.

| 심기 | 회수 |
|------|------|
| 크레일 예고(14) | 격파(15) |
| 역할 모듈(16) | 이후 도구 재투입·무감정 처리 |

| 한계(23) | 24 선택 전제 |

회수는 **행동·전투·손**. 강의 회수 없음.

## 6. 네메시스 존재감 곡선

```
14–17  거의 없음 / 도구 소진 무반응
18     원경·한 칸
19–21  배경 · 격파 후 무반응(21)
22     대기 · 내려다봄
23     P1–P2 · 침묵 위계
24     「시작에 불과하다」 · 시선 불변
```

오만은 **후반으로 갈수록 말이 아니라 침묵·시선·한 줄**로 압축.

## 7. 구조상 강점

1. 클라이맥스 유형이 격파에 편중되지 않음  
2. 19·24 선택 대칭 (돌입 / 닫기·시간)  
3. 21 “문이 열렸을 뿐” → 22–24 안도 없는 심부  
4. 종결이 구원이 아니라 **여지**
