## 원칙

성장 = 강해지는 정도가 아니다.  
**욕망이 바뀌고, 선택의 무게가 바뀌는 것**이다.

각 구간마다 다음을 명시한다.

1. 핵심 욕망 (한 줄)
2. 대표 선택/행동 장면 (최소 1개)
3. 아직 하지 않는 것 (금지어·금지 태도)
4. 다음 구간으로 넘어가는 계기

## EP01~06 — 「나는 살아남고 싶다」

### 욕망
거대한 사명 X. 오늘 살아남는 것. 뒤에 있는 사람을 버리지 않는 것.

### 상태
- 정비 지원 · 비전투원에서 출발
- 영웅 되고 싶지 않음
- BRAVE와 공명 = 선택받은 의식이 아니라 **그 자리에 있던 결과**
- 광기 0→2 진입 (손 떨림 → 경련·코피)

### 필수 행동/선택 장면

| EP | 장면 |
|----|------|
| 01 | BRAVE에 올라타기로 **스스로 선택** (시스템이 고른 것이 아님을 행동으로) |
| 02 | 첫 필살 — 살아남기 위한 공격 |
| 03 | 한 명 구출 — 버리기 싫어서 |
| 04 | 대안 공명 실패 목격 후 **내리지 않기로 함** |
| 05 | 레이 하차 명령에도 재탑승 |
| 06 | 세스전 — 계산을 버리고 집념으로 파고듦 |

### 하지 않는 것
- "세계를 구한다" 선언
- 사명감 연설
- 세스를 동등한 적으로 인정하는 태도 (아직은 벽)

### 다음 구간 계기
세스를 이겼지만 전망이 없다. 네메시스 원경. 승리가 쌓여도 끝이 보이지 않는다.

---

## EP07~12 — 「내가 할 수 있는 일을 하고 싶다」

### 욕망
카이 희생 이후. 책임. 헛되게 하지 않겠다. 혼자 감당하려는 경향.

### 상태
- EP08 상실 → 광기 3
- EP09 네메시스 「아직 급이 아니다」
- 잔상(카이 습관) 1회씩 EP9~11
- EP12 유나·레이 합류 — 혼자서는 안 된다는 것을 받아들임

### 필수 행동/선택 장면

| EP | 장면 |
|----|------|
| 07 | 원격 일격 벽에 부딪혀도 **다시 탄다** |
| 08 | 과부하 직전에도 조종간을 놓지 않음 → 카이 희생 목격 → 「…헛되게 안 해」 |
| 09 | 빈 주파수에 「콜.」 → 그래도 전진 |
| 10 | 광기를 **고의로 연다** (수용) |
| 11 | 전조(엑셀리온) — "여기서 끝내자" |
| 12 | 끌려가지 않고 **붙잡는다**. 합류를 거부하지 않음 |

### 하지 않는 것
- 카이 슬로건 남발 ("카이를 위해" 반복)
- 열혈 구호로 상실을 덮음
- 유나·레이를 구원자로 연출

### 다음 구간 계기
혼자서는 달까지 못 간다. 팀이 필요하다는 것을 몸으로 안다.

---

## EP13~18 — 「내가 선택한 사람들을 지키고 싶다」

### 욕망
돌파하는 영웅에서 **팀의 일부**. 서로 다른 사람들이 서로를 필요로 함.

### 상태
- EP13 엑셀리온 · 시간 벌기
- EP14~ 전쟁 확대 · 크레일 · 기원 · 등급 재확인
- 리아 = 돌파 / 유나 = 관측 / 레이 = 지휘·숫자 / 정비팀 = 유지

### 필수 행동/선택 장면

| EP | 장면 |
|----|------|
| 13 | 리아가 **끌어낸** 엑셀리온. 「시간을 벌었다」 |
| 14 | 한 전선 영웅이 아니라 여러 맵을 처리해야 하는 존재로 전환 |
| 15 | 팀 전투 — 혼자 막지 않음 |
| 16 | "저들은 왜"가 아니라 **"우리는 무엇을 선택하는가"** |
| 17 | BRAVE 기원 이해 — 선택 가능한 공명 |
| 18 | 등급표 한 칸. 멈추지 않음 |

### 하지 않는 것
- 혼자 전 맵을 막는 연출
- 팀원을 배경으로만 쓰는 것
- 새로운 철학 장문

### 다음 구간 계기
게이트가 흔들린다. 최종 선택 직전. 남길 수 있는 것이 무엇인지 묻기 시작.

---

## EP19~24 — 「내가 선택할 수 있는 미래를 남기고 싶다」

### 욕망
완전 구원 X. **다시 선택할 여지**를 남기는 것. EP01의 질문이 행동으로 답해짐.

### 상태
- 아이기스 · 내부 · 네메시스 최종
- 네메시스 「이것은 시작에 불과하다」
- 리아 「여기까지야」「시간을 벌었다」 계열의 최종 선택

### 필수 행동/선택 장면

| EP | 장면 |
|----|------|
| 19 | 도망 vs 돌입 — **돌입 선택** (연설 최소화) |
| 21 | 아이기스 격파 = 길이 열릴 뿐 |
| 23 | 승패가 아니라 선택으로 밀어붙임 |
| 24 | 게이트를 닫거나 시간을 버는 **행동**. 세계 완전 구원 선언 금지 |

### 하지 않는 것
- 새로운 설정·철학 설명
- 네메시스 오만 붕괴 연출
- "특별한 사람이 영웅이 된다" 메시지

### 회수 대상 (P9와 연결)
- EP01 첫 개인 목표(살아남고 싶다 / 버리지 않겠다)
- 카이 습관
- 세스 가치관 대립
- BRAVE 공명 = 선택
- 팀의 의미
- 선택이라는 주제
