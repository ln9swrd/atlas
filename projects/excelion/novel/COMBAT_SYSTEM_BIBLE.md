## 최우선 원칙

- **재미 있는 소년만화** · 전투가 먼저
- 30초 안에 목표 보이게
- 메인 수치·스킬: `state/BOSS_STATS` · `BOSS_WEAPON_SKILLS`

---

# 0. 전투 구성

```
기체 성능 + 파일럿 + 전장 + 전술 + 감정 = 승패
```

---

# 1. 전투 표현 (소설)

필수:
1. **크기** — 발걸음 충격 · 건물 비교 · 장갑 · 무장 규모
2. **기체 구조** — 어느 부위가 움직이는지
3. **파일럿** — 조작 · 판단 · 공포 · 집중

예: "20m급 기체의 팔이 회전하며 수 톤의 블레이드가 공기를 찢었다."

---

# 2. BRAVE

스타일: 근접 고속 · 돌파 · 회피 · 반격 · 일격  
대시: 순간 전장을 지움  
주무장: 전완 블레이드  
필살: 공명 동기화 (BRAVE BREAK 가칭)  
약점: 장기전 · 파일럿 부담 · 공명 실패

---

# 3. 네메시스 (최종 보스)

스타일: 공간·중력 제어 · 전장 지배  
능력: 이동 제한 · 탄도 왜곡 · 봉쇄 · 판결 일격  
표현: 파편 부유 · 공간 압축 · 손 안 댐  
페이즈: 관찰 → 재등급 → 한계 (상세 `BOSS_WEAPON_SKILLS` SK-N)  
약점: 집념 돌파 · 엑셀리온

**아슈르 보스 시스템 = 사용하지 않음 (네메시스로 교체)**

---

# 4. 세스

스타일: 분석형 엘리트 · 차단·처리  
P1 분석 → P2 압박 → 격파 가능  
"강해서가 아니라 읽어서 이긴다"  
상세: `SETH_BATTLE_FIXED` · SK-S

---

# 5. 전장

| 장소 | 특징 |
|------|------|
| 폐허 도시 | 시야 제한 · 민간 보호 |
| 군사 기지 | 포격 · 제한 공간 |
| 달 뒷면 | 저중력 · 3D 전투 |
| 차원 공간 | 법칙 변화 · 불안정 |

---

# 6. 보스전 리듬 (소년만화)

1. 첫 만남 — 벽 · 공포
2. 재대결 — 대응법 · 성장
3. 최종 — 돌파 · 선택
