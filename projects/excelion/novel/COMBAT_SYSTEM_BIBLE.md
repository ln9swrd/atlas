# EXCELION COMBAT SYSTEM BIBLE V1

# 0. 전투 설계 철학

Excelion의 전투는 단순한 화력 대결이 아니다.

각 기체는 고유한 전투 철학을 가지고 있으며,
파일럿의 선택이 전투 결과를 변화시킨다.

전투 구성 요소:

```
기체 성능
+
파일럿 능력
+
전장 환경
+
전술 판단
+
감정 변화
=
승패
```

---

# 1. 전투 표현 원칙

소설 전투에서는 반드시 다음 요소를 표현한다.

## 1) 크기

거대 로봇 전투는 인간 전투와 다르다.

표현 요소:

* 발걸음의 충격
* 건물과 비교되는 크기
* 장갑 두께
* 무장의 규모

예:

"검이 휘둘러졌다"

가 아니라:

"20m급 기체의 팔이 회전하며 수 톤의 블레이드가 공기를 찢었다."

---

## 2) 기체 구조

공격마다:

* 어느 부위가 움직이는지
* 어떤 시스템이 작동하는지
* 왜 가능한지

설명한다.

---

## 3) 파일럿 조작

전투는 기계 혼자 하지 않는다.

표현:

* 조작 입력
* 반응 속도
* 판단
* 공포
* 집중

---
