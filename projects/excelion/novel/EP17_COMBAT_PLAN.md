# EP17 전투 장면 구체화 방안

> 2026-08-07 · M2b  
> 전제: `EP17_SYNOPSIS_DRAFT.md` · 전투 비중 **중** · 보스 없음

---

## 1. 목적 (한 줄)

해금된 출력을 **몸으로 확인**하고, 경로를 열어 게이트 돌입 준비를 마친다.

격파 과시·보스 감정화 금지.

---

## 2. 전투 타입

| 항목 | 고정 |
|------|------|
| 형태 | 맵 클리어 · 소규모 압박 |
| 적 | ORD 잔당 (GRUNT 위주 · 중형 1~2기 가능) |
| 보스 | **없음** |
| 승리 조건 | 경로 확보 / 신호 안정 |
| 실패 조건 | 경로 봉쇄 · 신호 붕괴 |

---

## 3. 체감 포인트 (필수)

1. **출력 해금 전후 차이**  
   - 이전: 손이 버거움 · 한 줄 끊기 힘듦  
   - 이후: 같은 손·같은 동선인데 **한 박 빨라지고 끊김이 선명**

2. **손 감정**  
   - 설명 대신 조종간·손끝·시야 가장자리로만 표현  
   - “코어가 반응했다” 금지 → **리아가 끌어냈다** 체감만

3. **팀 최소 비트**  
   - 유나: 관측 1~2회  
   - 레이: 숫자/우선순위 1회  
   - 리아 혼자 전 맵 삼키지 않음

---

## 4. 장면 리듬 (권장 3비트)

```
비트1  압박 시작 · 이전 출력으로는 막힘 체감
비트2  해금 출력 투입 · 돌파·끊기 선명
비트3  경로 열림 · 신호 안정 · 짧은 여운
```

- 각 비트 목표 30초 안에 보이게
- 필살/초필: 아껴 쓰거나 1회만 (과시 금지)
- 광기: 열어 두되 끌어가지 않음

---

## 5. 연출 금지

- 보스급 실루엣·사연·대사
- 장문 전술 설명
- 영웅 연설·승리 선언
- 카이 잔상 남발 (최대 1회)
- “강해졌다” 직접 서술 → **손과 동선으로만**

---

## 6. 본문 연결 위치

- Part 2(정비팀·해금) 직후 → Part 3(전투)
- 전투 종료 직후 → Part 4(돌입 후보 = 리아)

전투가 해금의 **증거**가 되고, 돌입 승인의 **근거**가 되게 한다.

---
