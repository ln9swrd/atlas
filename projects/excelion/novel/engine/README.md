## 3. AI 집필 계약 (하드 룰)

```
1. 스토리 최우선. 소년만화: 성장 + 열혈 + 광기.
2. 새 설정 최소화. 심은 것만 회수 (03_FORESHADOW).
3. 리아 성장 = 욕망·선택의 변화 (강해지기만 X).
4. 카이: 습관 H1–H3 · 슬로건 금지 · 잔상 EP9–11만.
5. 세스: 계단 · 재감정 금지 · 「보고, 끝」.
6. 네메시스: 여성형 · 등급 · 오만 유지 · 장문 금지
   · EP9「아직 급이 아니다」 · 최종「시작에 불과하다」.
7. 아슈르 최종보스/EP01 잔재 사용 금지.
8. 이름: 카이 (카일 금지).
9. 시간: 붕괴 후 7년.
10. 생활/유머: 1화 0–2 · EP08–11·보스전 개그 금지.
11. 몸이 먼저. 설명 강의 금지.
12. 매 화 클라이맥스 1 · CLIMAX 유형 준수.
```

## 4. 권장 집필 순서 (1화)

1. 해당 EP 스펙·ARC 구간 확인  
2. CLIMAX 유형 선택 (C1–C6)  
3. 가져갈 문장 1개  
4. 필수 비트·금지 비트 체크리스트  
5. 초고 → 습관/잔상/이름/보스 톤 검사  
6. 생활감 0–2 삽입 여부 판단  
7. 회수 표에 해당 F가 있으면 행동으로 회수
