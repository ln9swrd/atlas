# EP14–24 에피소드별 클라이맥스 설계

> 2026-08-07 · M2b  
> 근거: `EP14_24_SYNOPSIS` · `NARRATIVE_STRUCTURE_BASICS` · `CLIMAX_TYPE_SPEC`  
> 원칙: **몸이 먼저** · 매 화 클라이맥스 1 · 가져갈 문장과 일치

---

## 0. 정의

클라이맥스 = 그 화의 **목표 1**이 **손·전투·선택**으로 확정되는 순간.

- 설명·연설·강의로 오지 않는다.
- 보스 격파만이 클라이맥스가 아니다.
- 끝 비트에서 **가져갈 문장**이 몸으로 회수된다.

## 3. 회차별 설계

### EP14 「전선이 열린다」 · C3

| 항목 | 내용 |
|------|------|
| 피크 | 연합 회의 후, 리아가 우선순위를 **손으로** 고르는 순간 |
| 표현 | 한 맵이 아니라 여러 맵. 손이 한 축만 보지 않는다. |
| 가져갈 문장 회수 | 한 전선으로는 모자라다. |
| 훅 | 다음 목표 = 균열 지대 |

### EP15 「팀」 · C2

| 항목 | 내용 |
|------|------|
| 피크 | 크레일 방패면이 무너지고, 거점·전선이 **유지**되는 순간 |
| 표현 | 돌파·엄호·관측이 동시에 들어간다. 혼자였으면 막혔다. |
| 가져갈 문장 회수 | 혼자 막을 수 있는 벽이 아니었다. |
| 훅 | 전선 일시 안정 · 대가 |

### EP16 「위계의 손」 · C3

| 항목 | 내용 |
|------|------|
| 피크 | 잔해·분석 중, “숭배”가 아니라 **역할 모듈**임이 몸으로 읽히는 순간 |
| 표현 | 세스·크레일 = 같은 층. 질문이 “왜”에서 “무엇을 선택하는가”로 바뀐다. |
| 가져갈 문장 회수 | 저들은 역할이었다. |
| 훅 | 게이트 내부 신호 증가 |

### EP17 「이름 없는 기원」 · C3 (+C2)

| 항목 | 내용 |
|------|------|
| 피크 | 해금된 출력이 **손·동선**으로 확인되고, 돌입 후보가 리아로 고정 |
| 표현 | 같은 손인데 한 박 빠르다. 설명 없이 경로가 열린다. |
| 가져갈 문장 회수 | 영웅기가 아니라, 선택 가능한 기체였다. |
| 훅 | 게이트 돌입 후보 = 리아 |

### EP18 「등급」 · C5

| 항목 | 내용 |
|------|------|
| 피크 | 데크레·원경 네메시스 아래에서도 **경로를 확보**하고 한 칸 움직이는 순간 |
| 표현 | 승패를 재지 않는다. 멈추지 않는다. 한 칸. |
| 가져갈 문장 회수 | 한 칸만 움직였다. |
| 훅 | 아이기스 반응 · 입구 신호 |

### EP19 「붕괴 예고」 · C1

| 항목 | 내용 |
|------|------|
| 피크 | 도망 vs 돌입 분열 속에서, 리아가 **돌입**을 고르고 손이 조종간에 가는 순간 |
| 표현 | 말이 끝나기 전 경보. 연설 없음. 손만. |
| 가져갈 문장 회수 | 도망칠 시간을 골랐다. 돌입하기로 했다. |
| 훅 | 창 열림 · 앞은 방패 |

### EP20 「레이드」 · C2

| 항목 | 내용 |
|------|------|
| 피크 | 다파 총압 속에서 리아가 **중심만** 지키고, 팀이 나머지를 받는 순간 |
| 표현 | 혼자 전 맵을 덮지 않는다. 축만 막는다. |
| 가져갈 문장 회수 | 중심이되, 혼자 전 맵을 막지 않는다. |
| 훅 | 전선 일시 안정 · 게이트 내부 진입 가능 |

### EP21 「방패」 · C2

| 항목 | 내용 |
|------|------|
| 피크 | 가드 게이지 붕괴 · 경직 · **문이 열리는** 순간 |
| 표현 | 예고 창에 손이 먼저 들어간다. 문이 열렸을 뿐. 네메시스 무반응. |
| 가져갈 문장 회수 | 문이 열렸을 뿐이었다. |
| 훅 | 게이트 심부 · 최종 영역 |

### EP22 「내부」 · C4

| 항목 | 내용 |
|------|------|
| 피크 | 물리·통신이 이상해도 **BRAVE 공명만으로** 몸이 버티는 순간 |
| 표현 | 설명 없음. 발이 먼저 안다. 손이 버틴다. |
| 가져갈 문장 회수 | 설명 없이, 몸이 먼저 버텼다. |
| 훅 | 네메시스 대기 · 내려다보는 구도 |

### EP23 「판정」 · C6

| 항목 | 내용 |
|------|------|
| 피크 | 네메시스 P1–P2 아래에서도 **선택으로 밀어붙이는** 순간 · 기체 한계 |
| 표현 | 이기고 지는 게 아니다. 밀어붙인다. |
| 가져갈 문장 회수 | 이기고 지는 게 아니라, 밀어붙였다. |
| 훅 | 기체 한계 · 마지막 선택 직전 |

### EP24 「선택」 · C1

| 항목 | 내용 |
|------|------|
| 피크 | 네메시스 격파 여부보다 **게이트를 닫거나 시간을 버는 선택**이 확정되는 순간 |
| 표현 | 「이것은 시작에 불과하다.」 오만 유지. 완전 구원 없음. 짧은 침묵. 손. |
| 가져갈 문장 회수 | 끝난 뒤에도, 선택은 남았다. |
| 훅 | 여운 · S1 종료 |
