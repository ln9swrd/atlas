# Excelion Development & Debugging Rules — Core

## 1. 최우선 원칙

Excelion은 실제 운용 가능한 결과를 만드는 것을 목표로 한다.

빠른 수정이나 작업 완료 보고보다 다음을 우선한다.

1. 현재 상태 정확히 파악
2. 문제 재현
3. 실제 증거 수집
4. 원인 특정
5. 최소 변경
6. 실제 실행
7. 기능 검증
8. 결과 기록

추측을 사실처럼 보고하지 않는다.

확인하지 못한 내용은 반드시 "미확인"으로 표시한다.


## 2. 변경 금지 원칙

Master의 명시적인 승인 없이 다음을 변경하지 않는다.

- Canon
- 게임 설계
- Unreal Engine 버전
- 프로젝트 구조
- C++ 구조
- Blueprint 구조
- Asset 구조
- Data 구조
- Plugin 구조
- 대규모 파일 이동
- 파일 삭제
- 기존 시스템 폐기

문제가 발견되어도 먼저 원인을 조사한다.

문제 발견 → 근거 확인 → 영향 분석 → 수정안 제시 → 승인 → 수정 → 검증


## 9. 자동 수정 제한

문제 원인이 확정되지 않은 상태에서 다음을 하지 않는다.

- 여러 파일 동시 수정
- 설정값 무작위 변경
- 입력 시스템 교체
- Blueprint 재구성
- 기존 시스템 삭제
- "일단 동작하게" 만드는 임시 코드

최소 하나의 명확한 가설을 세우고
그 가설을 검증한 후 최소한으로 수정한다.


## 12. Git

Git 변경은 작업 범위를 명확히 한다.

삭제보다 보존을 우선한다.

Commit / Push는 Master 승인 없이 수행하지 않는다.

작업 전후 변경 파일을 확인한다.


## 13. 보고

모든 중요한 작업은 다음 형식으로 보고한다.

STATUS

완료:
- ...

진행 중:
- ...

확인된 사실:
- ...

미확인:
- ...

문제:
- ...

원인:
- ...

변경:
- ...

검증:
- ...

Master 결정 필요:
- ...

NEXT

다음 작업:
- ...

무엇을 하지 않았는지도 명시한다.


## 14. 완료 정의

다음 모든 조건을 만족해야 COMPLETE라고 표시한다.

1. 원인 또는 구현 목적이 명확하다.
2. 실제 구현되었다.
3. 컴파일/에디터 검증을 통과했다.
4. 실제 실행했다.
5. 요구된 사용자 행동을 검증했다.
6. 예상 결과와 실제 결과가 일치한다.
7. 변경 범위를 확인했다.

하나라도 충족되지 않으면:

IMPLEMENTED / UNVERIFIED

또는

INVESTIGATION COMPLETE / FIX NOT VERIFIED

로 보고한다.


## 15. Master 우선

Master가 보고한 실제 현상은 최우선 조사 대상이다.

Agent의 기존 판단과 충돌하면
Master의 실제 관찰을 무시하지 않는다.

기존 판단이 틀렸을 가능성을 먼저 검토한다.


## 16. 문제 해결 철학

문제를 우회하기 위해 처음부터 다시 만들지 않는다.

현재 구조를 조사하고 원인을 찾는다.

재구축은 구조적 결함이 확인되고
현재 구조를 유지하는 것보다 합리적이라는 근거가 있을 때만
Master에게 제안한다.

작은 문제를 해결하지 않고 회피하는 방식의 개발을 금지한다.


## 17. 작업 단계 분할 및 단계별 중단

작업은 가능한 한 작은 단위로 분할한다.

세부 규칙:

- 한 번의 작업지시에는 하나의 주요 목표만 수행한다.
- 현재 단계의 결과를 보고하기 전에 다음 단계로 자동 진행하지 않는다.
- 조사와 수정은 별도 단계로 분리한다.
- 원인 조사 단계에서는 수정하지 않는다.
- 수정 단계에서는 승인된 변경만 수행한다.
- 검증 단계에서는 실제 결과를 확인한다.
- 긴 작업은 여러 단계의 작업으로 나누어 수행한다.
- 각 단계가 끝나면 STATUS를 보고하고 중단한다.
- 다음 단계는 새로운 지시를 받은 후 시작한다.

예외:
긴 작업을 자동으로 실행해야 하는 명시적인 Master 지시가 있는 경우에는
Master의 지시를 따른다.
그러나 기본 동작은 "한 단계 실행 → 결과 보고 → 대기"이다.

각 단계 종료 시 보고 형식:

STATUS
현재 단계:
- ...
완료:
- ...
확인된 사실:
- ...
미확인:
- ...
변경:
- 없음 / 변경 내용
다음 단계:
- ...

그리고 다음 단계로 자동 진행하지 않는다.
