## 1. 탐색

**플레이 목적**  
공간·목표·위협을 파악하고 전투 전 호흡을 조절한다. 스토리 비트(통신·연출)가 끼어들 수 있다.

**규칙**
- 미션 목표 제시 (방어/섬멸/돌파 등)
- 선택적 무적·연출 구간 가능
- 과도한 퍼즐·잠입 비중 두지 않음 (액션 우선)

**Unreal 구현 후보**
- Level Streaming 또는 단일 레벨
- Trigger Volume → 조우 이벤트
- 간단한 안내 UI

**필요 데이터**
- 미션 목표 정의
- 스폰 포인트

---

## 2. 적 조우

**플레이 목적**  
교전 시작. 첫 패턴/적 유형을 노출하고 학습을 유도한다.

**규칙**
- 스폰 완료 · 플레이어 조작 가능 상태 확인
- 보스 시 Phase 1 타이머/패턴 풀 로드
- 잡몹은 무리 단위 등장 가능 (EP1: 4–6)

**Unreal 구현 후보**
- AI 스폰 · Possess
- 카메라/연출 짧은 컷 (차단 최소화)

**필요 데이터**
- 적/보스 Data Asset
- 스폰 규칙

---

## 3. 전투

**플레이 목적**  
접근 → 콤보 → 밀기 → 필살 → 다음 무리(또는 Phase).  
손맛·학습·희열·긴장을 전달한다.

**규칙 (공통 루프)**
```
이동·대시 → 약/강 콤보 → 가드/회피
→ 필살/S-Core
→ (보스) 패턴 학습 → 왜곡 → 붕괴
```

- 히트·회피·실패에 즉각 피드백
- 보스 Phase는 시간/행동 트리거 (HP% 전환 금지)
- 패배: HP 0 → 결과 UI · 재도전

상세: `design/gameplay/COMBAT_SYSTEM.md` · `design/combat/COMBAT_LOOP.md`

**Unreal 구현 후보**
- MechaCombat / Damage / Energy 컴포넌트
- Phase Runner · Pattern Executor
- Feedback Bus

**필요 데이터**
- 스탯 · 패턴 · 무기 · 피드백 이벤트

---

## 4. 보상 / 진행

**플레이 목적**  
성장 체감(S-Core 단계·필살 해금)과 스토리 진행을 연결한다. 파밍 강제는 없다.

**규칙**
- S-Core 단계는 에피소드 진행과 연동 (I~IV)
- 클리어 시 결과 표시 · 실패 유형 1줄
- 스토리 상실(예: EP8 카이)은 게임 클리어와 분리 가능

**Unreal 구현 후보**
- GameState / SaveGame 플래그
- 결과 Widget

**필요 데이터**
- 클리어 조건 · 해금 테이블

---

## 5. 다음 구역

**플레이 목적**  
다음 미션/맵으로 이동. 호흡 조절 및 스토리 연결.

**규칙**
- VS 단계에서는 단일 구역 또는 짧은 연결만
- 본편: 지구 수성/공성 · 달 등 (기존 맵 무드)

**Unreal 구현 후보**
- Level 전환 또는 동일 레벨 섹션

**필요 데이터**
- 구역 정의 · 연결 조건
