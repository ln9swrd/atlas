---

## 0. 적용 범위

| 적용 | 비적용(언어 종속 금지) |
|------|------------------------|
| ORD 4종 · CREIL · AEGIS · SETH · ORACLE · VOID · KYLE · **RACE** | NEMESIS · BRAVE/EXCELION |

CANON(전투·EP·Loop) 유지. VISUAL는 본 문서 + 3TONE.

---

## 1. 리부트 이유

실루엣·청회 반복 · 역할↔형태 약 · 흑실루엣 식별 실패 위험.
군사·건축 비유 제거 → **슈퍼로봇 과장·개성**으로 재정의.

생성 순서: 역할 → 행동 → 물리 → **실루엣** → 구조 → 무장 → **3톤**.

---

## 2. RULE + 3TONE

| # | 규칙 |
|---|------|
| 01 | 실루엣 우선 · 후보 ≥3 |
| 02 | 역할→형태 |
| 03 | 형태 문장 1개 |
| 04 | 직선만 쓰지 않음 |
| 05 | 기능적 비대칭 |
| **06** | **3톤 · 저표면 디테일 · 제한 패널** |
| 07 | **슈퍼로봇 과장 허용** · 건담식 리얼리즘 금지 |

Test A–E 필수.

---

## 3. 공통 언어

프레임 결합 1–2 · ORDER 마크 · 센서광 거동.  
**≠ 동일 실루엣.** 진영 = **오더** (군대 아님).

---

## 4. Shape Statement

| 기체 | 문장 |
|------|------|
| GRUNT | 떼로 덮치는 하층 투기 기계 |
| MID | 길게 뻗어 전장을 가리키는 지배 몸 |
| GUN | 포신을 몸의 축으로 삼은 사격 괴물 |
| HEAVY | 몸통이 스스로 걸어다니는 압도 괴체 |
| CREIL | 가로로 밀어붙이는 거대한 면압 몸 |
| AEGIS | 수직으로 솟아 버티는 수호의 기둥 몸 |
| SETH | 정제된 완성형 지배 기체 |
| ORACLE | 공간을 눌러 덮는 원격의 눈 |
| VOID | 갈라진 틈에서 스며 나오는 잔영 몸 |
| KYLE | 세스보다 날카롭고 크레일보다 가벼운 돌격 몸 |
| **RACE** | **게이트를 물어뜯는 돌진 괴체** |

---

## 5. 색 (3톤)

| 기체 | Tone1 방향 |
|------|------------|
| GRUNT | 산화철·황토·흙 |
| MID | 아이보리·백 |
| GUN | 딥블루·청록 |
| HEAVY | 적갈·흑철 |
| CREIL | 백·청 |
| AEGIS | 보라·흑 / 버건디 |
| SETH | 금속 백 + 금 포인트 |
| ORACLE | 냉백·심청 · 센서 과다 |
| VOID | 저채도 흑·회 · 일그러진 엣지 |
| KYLE | 청회·은 · 날카로운 포인트 |
| RACE | 적갈·암청 · 돌진 광 |

BRAVE 호박을 ORDER 주조에 쓰지 않음.

---

## 6. 차별 키

- CREIL 가로 면압 vs AEGIS 수직 기둥
- ORACLE 원격·눈 · VOID 잔영·불완전
- KYLE 날카로운 돌격 · **RACE 게이트 물어뜯기·돌진**
