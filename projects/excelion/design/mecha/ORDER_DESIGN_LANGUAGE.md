# ORDER_DESIGN_LANGUAGE — 진영 비주얼 리부트

> 2026-08-09 · PHASE 1  
> 공통 표면 규칙: **`design/MECHA_3TONE_LOW_DETAIL.md`** (전 진영)

**상태: LOCK (진영 기준)**

---

## 0. 적용 범위

| 적용 | 비적용(언어 종속 금지) |
|------|------------------------|
| ORD 4종 · CREIL · AEGIS · SETH | NEMESIS · BRAVE/EXCELION |

CANON(전투·EP·Loop) 유지. VISUAL는 본 문서 + 3TONE.

---

## 1. 리부트 이유

실루엣·청회 반복 · 역할↔형태 약 · 흑실루엣 식별 실패 위험.
군사·건축 비유(벽·탑·요새·탱커·원거리) 제거 → **슈퍼로봇 과장·개성**으로 재정의.

생성 순서: 역할 → 행동 → 물리 → **실루엣** → 구조 → 무장 → **3톤**.

---

## 2. RULE + 3TONE

| # | 규칙 |
|---|------|
| 01 | 실루엣 우선 · 후보 ≥3 |
| 02 | 역할→형태 |
| 03 | 형태 문장 1개 |
| 04 | 직선만 쓰지 않음 |
| 05 | 기능적 비대칭 |
| **06** | **3톤 · 저표면 디테일 · 제한 패널** (`MECHA_3TONE_LOW_DETAIL`) |
| 07 | **슈퍼로봇 과장 허용** · 건담식 리얼리즘 금지 |

Test A–E (흑실루엣·무채·무장제거·3초·소화면) 필수.

---

## 3. 공통 언어 (소량)

프레임 결합 1–2 · ORDER 마크 · 센서광 거동 · 목적·역할 철학.  
**≠ 동일 실루엣.**  
진영 = **오더** (군대 아님).

---

## 4. Shape Statement (신)

| 기체 | 문장 |
|------|------|
| GRUNT | 떼로 덮치는 하층 투기 기계 |
| MID | 길게 뻗어 전장을 가리키는 지배 몸 |
| GUN | 포신을 몸의 축으로 삼은 사격 괴물 |
| HEAVY | 몸통이 스스로 걸어다니는 압도 괴체 |
| CREIL | 가로로 밀어붙이는 거대한 면의 몸 |
| AEGIS | 수직으로 솟아 버티는 수호의 기둥 몸 |
| SETH | 정제된 완성형 지배 기체 |

---

## 5. 색 (3톤으로 확정)

주색 후보 → 실루엣 후 **Tone1/2/3 확정**.

| 기체 | Tone1 방향 |
|------|------------|
| GRUNT | 산화철·황토·흙 |
| MID | 아이보리·백 |
| GUN | 딥블루·청록 |
| HEAVY | 적갈·흑철 |
| CREIL | 백·청 |
| AEGIS | 보라·흑 / 버건디 계열 가능 |
| SETH | 금속 백 + 금 포인트 |

공통 20–30%만 공유. BRAVE 호박을 ORDER 주조에 쓰지 않음.

---

## 6. CREIL vs AEGIS

가로 면의 밀어붙임 vs 수직 기둥으로 버티기. 유사 시 실패.

---

## 7. 물리 요구 · 절차

GRUNT~SETH 물리 요구는 계획서 유지.  
절차: Statement → 실루엣 3–5 → Test → 3톤 → 구조 → 삼면도.

**실루엣 전 최종 삼면도 금지.**

```
CURRENT: ORDER language + 3TONE 연동 LOCK · 슈퍼로봇 과장 톤
NEXT: ORD-GRUNT 실루엣 3안
```
