## 4. Shape Statement

| 기체 | 문장 |
|------|------|
| GRUNT | 떼로 덮치는 하층 투기 기계 |
| MID | 길게 뻗어 전장을 가리키는 지배 몸 |
| GUN | 포신을 몸의 축으로 삼은 사격 괴물 |
| HEAVY | 몸통이 스스로 걸어다니는 압도 괴체 |
| CREIL | 가로로 밀어붙이는 거대한 면압 몸 |
| AEGIS | 수직으로 솟아 버티는 수호의 기둥 몸 |
| SETH | 정제된 완성형 지배 기체 |
| **ARGOS** | 공간을 눌러 덮는 원격의 눈 |
| **EREBOS** | 갈라진 틈에서 스며 나오는 잔영 몸 |
| **KERBEROS** | 게이트를 물어뜯는 돌진 괴체 |
| **PHOBOS** | 세스보다 날카롭고 크레일보다 가벼운 돌격 몸 |
| **ADRASTE** | 열린 창을 피할 수 없게 닫는 몸 |
| **DEIMOS** | 전선을 찢고 지나가는 돌파 몸 |

## 6. 차별

- ARGOS 원격 눈 ≠ ADRASTE 창 닫힘
- EREBOS 잔영 ≠ KERBEROS 돌진 문지기
- PHOBOS 돌격 ≠ DEIMOS 전선 돌파 (쌍이되 실루엣 분리)
- AEGIS 수직 기둥 ≠ CREIL 가로 면압
