---

## 1. 리부트 이유 (고정)

- 실루엣 중복 (넓은 어깨·블록 흉·슬릿 반복)
- 청회/흑회 색 반복
- 역할↔형태 연결 약함
- 흑실루엣 식별 실패 위험
- “기본 로봇+장비” 파생 위험

→ 부분 수정이 아니라 **생성 순서 변경**: 역할 → 행동 → 물리 → 실루엣 → 구조 → 무장.

---

## 2. 규칙 (RULE)

| # | 규칙 |
|---|------|
| 01 | **실루엣 우선** — 삼면도 전 기체당 실루엣 후보 ≥3 |
| 02 | **역할→형태** — 전투 역할이 형태를 결정 |
| 03 | **형태 문장 1개** — 기체당 한 문장으로 읽혀야 함 |
| 04 | **직선만 쓰지 않음** — 곡·원통·노출 프레임·케이블·분절 허용 |
| 05 | **기능적 비대칭** — GUN/CREIL/AEGIS 등 대칭 기본값 아님 |

### 검증 테스트 (필수)

| Test | 실패 시 |
|------|--------|
| A 흑실루엣 구별 | 폐기 |
| B 무채색 구별 | 형태 재설계 |
| C 무장 제거 후 역할 | 구조 재설계 |
| D 3초 역할 설명 | 재설계 |
| E 소화면·전투거리 구별 | 실루엣 강화 |

## 3. 공통 언어 (실루엣 동일 ≠)

공유는 **1~2개만**:

1. 프레임/결합 요소 (커넥터·볼트 언어 소량)
2. ORDER 식별 마크 위치 규칙
3. 센서광 거동 (점등 리듬 · 색은 기체별)
4. 전투철학: 목적·숫자·역할 모듈 (서사 과잉 개성 금지)

**공통 언어 = 동일 실루엣이 아님.**

## 5. 색 체계 리부트

**폐기:** 전 기체 청회/흑회 동일 반복.

원칙: **진영 공통 20–30% + 기체 주색 70–80%**

| 기체 | 주색 방향 (후보) |
|------|------------------|
| GRUNT | 산화철 · 황토 · 흙 |
| MID | 아이보리 · 백색 |
| GUN | 딥블루 · 청록 |
| HEAVY | 적갈 · 흑철 |
| CREIL | 백색 · 청 계열 |
| AEGIS | 짙은 보라 · 흑 |
| SETH | 금속 백색 + 금점 |

공통: ORDER 마크 · 센서광 · 일부 프레임만.  
**최종 색 = 실루엣 확정 후.**

BRAVE 호박 `#E8A020` 아군 accent — ORDER 주조에 쓰지 않음 (기존 금지 유지).

## 6. CREIL vs AEGIS (강제)

| 축 | CREIL | AEGIS |
|----|-------|-------|
| 핵심 | 물리 봉쇄 | 방어 시스템 |
| 실루엣 | **수평** | **수직** |
| 중심 | 전면 | 중앙·상부 |
| 방어 | 장벽·장갑 | 필드·다단 |
| 이동 | 밀어붙임 | 위치 확보 |
| 형태 | 장벽 | 탑·기둥 |

비슷하면 **설계 실패**.

## 7. 기체별 물리 요구 (실루엣 입력)

### GRUNT
낮은 중심 · 짧은 목 · 넓은 골반 · 짧고 두꺼운 팔 · 강한 하체 · 넓은 발 · 장비 일체화  
→ 사람형 조종 로봇 인상 약화.

### MID
긴 팔다리 · 높은 상체 · 좁은 허리 · 높은 시야 · 통신/센서 · 기동  
→ 타 기체를 움직이게 하는 존재.

### GUN
한쪽 어깨 극대화 · 긴 포신 · 반대쪽 센서/안정 · 긴 후면 · 좁은 전면 · 관측 두부  
→ 비대칭 사격 플랫폼.

### HEAVY
극대 상체 · 짧은 목 · 묻힌 머리 · 짧은 팔 · 두꺼운 하체 · 거대 발 · 냉각/추진 노출  
→ 몸통이 걷는다.

### CREIL
방패=구조 · 전면 질량 · 측면 깊은 장벽 · 후면 안정 · 팔=보조 · 인간형 관절 비중↓

### AEGIS
높은 상체 · 중심축 · 다단 방어 · 높은 센서 · 안정 하체 · CREIL과 수직/수평 대립

### SETH
정제 인간형 · 긴 팔다리 · 장비 최소 · 권위 자세 · 안정 균형 · ORD 단순 확대 금지
