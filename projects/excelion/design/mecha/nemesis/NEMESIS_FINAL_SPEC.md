## 03 Design Philosophy

- 오만 = **실루엣·거리·침묵**으로 드러냄
- 중력 = 공격이 아니라 **공간의 등급**
- 손 약함/숨김 · 원격일수록 강함 · 다가오면 디센트
- 광기·난무·비참 붕괴 금지
- ≠ 강한 세스 · ≠ 작은 네메시스 없음(본체가 유일 최종)

## 15 Defensive Systems

- 거리 유지가 방어
- 직접 가드보다 **공간 왜곡·무효 구역**
- 패배해도 실루엣·시선 유지

## 16 Special Systems

### 중력 = 위계

- 짓누르기 ≠ 목적 · **발판 소거**
- 중력 변화 = 감정 폭발이 아니라 **재평가 신호**

### 디센트

- 근접·위협 상승 시 “처리 모드”
- 손이 보이기 시작 = 이미 아래로 내려온 것

## 17 Combat Role

**최종 벽 · 등급 시험.**  
30초 메시지: “멀리서 눌린다 · 다가가면 처리 모드 · 이겨도 시선은 내려다본다.”

## 18 Combat Loop (페이즈)

### Phase 관측/원격 (EP7 유형 · 조우 초반)

```
거리 유지 → 중력 압박 → 원격 일격 → 플레이어 생존 체크
손 없음 · 오만 침묵
```

### Phase 전면 압박 (EP9–12 · EP23 P1)

```
공간 등급 변동 → 이동 경로 제한 → 짧은 판정 공격
→ 플레이어 돌파 시 재배치·재평가 (후퇴≠패배 인정)
```

### Phase 디센트 (EP23 P2 · EP24)

```
근접 허용 증가 → 손/처리 제스처 → 고밀도 판정
→ HP 0이어도 자세·시선 유지 → 「시작에 불과하다」
```

광기 난무·체력 바만 깎는 환형 패턴 남발 금지.
