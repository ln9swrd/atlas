# 3D Modeling Topology Guide

> 2026-08-07 · Nemesis / Seth 기준  
> 근거: `NEMESIS_MECHA_SPEC` · `SETH_MECHA_SPEC` · `seth/FORM` · `mecha/threeview/SKILL`

**상태: TEXT-LOCK 후보**

---

## 공통 원칙

1. **실루엣 우선**  
   폴리곤 밀도보다 실루엣 키워드가 먼저다.  
   - 네메시스: 길이 · 높은 중심 · 손 약함  
   - 세스: 단정 · 각 · 차단 · 손 보임

2. **Hard Surface 기준**  
   - Edge flow는 패널 라인과 구조 라인을 따른다.  
   - 불필요한 Subdivision을 피하고, Support Edge로 샤프한 각을 유지한다.  
   - 반다이 로봇혼 / 센티넬 수준의 패널 밀도를 목표로 한다.

3. **Ortho 삼면도 기준**  
   Front / Side / Back 비율이 완전히 일치해야 한다.  
   모델링 시작 전 삼면도를 레퍼런스 플레인에 고정한다.

## 1. 네메시스기 Topology

**목표 실루엣**  
세로로 김 · 높은 중심 · 얇은 허리 · 손 약함 · 부유감

| 부위 | Topology 가이드 |
|------|-----------------|
| **전체 비율** | 전고를 기준으로 상체 비중을 크게. 다리는 가늘고 길게. |
| **두부** | 단순 헬멧 볼륨. 얼굴면은 평면~약한 쐐기. 슬릿은 inset + support loop. |
| **몸통** | 긴 상체 + 얇은 허리. 세로 패널 흐름 유지. 가로 분할은 최소화. |
| **팔·손** | 팔은 가늘게. 손은 실루엣에서 약하게 처리 (글러브/패널로 통합 가능). 손가락 디테일 과다 금지. |
| **다리** | 가늘고 긴 원통 + 약간의 각도. 접지감보다 부유감 우선. |
| **배면** | 긴 패널·망토형 요소는 별도 오브젝트 또는 두꺼운 plane + solidify. |
| **Edge Flow** | 수직 라인 위주. 허리에서 자연스럽게 수렴. |

**주의**
- 근육질 볼륨 금지
- 손 강조 금지
- 왕관·뿔 과다 금지
- 세스와 같은 넓은 어깨·굵은 사지 금지

## 2. 세스기 Topology

**목표 실루엣**  
≈30m · 근육질 전사 · 넓은 어깨 · 차단벽 흉갑 · 손 보임

| 부위 | Topology 가이드 |
|------|-----------------|
| **전체 비율** | BRAVE 대비 +20%. 역삼각형 (넓은 견 → 상대적 허리 → 안정 골반). |
| **두부** | 단정 헬멧. 슬릿 1~2개. 뿔·왕관 0. 평면적 얼굴면. |
| **견·흉** | 넓은 견갑 + 두꺼운 흉갑. 가로 차단면이 잘 읽히도록 큰 패널. |
| **팔·손** | 굵은 상완·전완. **손은 반드시 보임**. 3~5지. 제압 제스처 가능 비율. |
| **다리** | 굵은 대퇴 · 큰 무릎 블록 · 넓은 족부. “막아선다” 접지감. |
| **배면** | 민등. 배팩·망토·익형 금지. |
| **Edge Flow** | 가로 차단선 + 근골 볼륨을 살리는 흐름. 어깨·흉에서 질량감 유지. |

**주의**
- 긴 고중심·여성형 곡선 금지
- 손 숨김 금지
- 왕관·망토·수직 위계 장식 금지
- 네메시스와 실루엣 겹침 금지

---

## 3. 공통 Topology 규칙

| 항목 | 권장 |
|------|------|
| Quads | 기본은 Quad. 불가피한 경우만 Triangle |
| Support Edge | 샤프한 패널 모서리에 필수 |
| Panel Lines | 실제 패널 두께를 가진 inset 또는 separate mesh |
| UV | 패널 단위로 정리. 대칭 활용 |
| Scale | Real-world scale 기준 (세스 ≈30m, 네메시스는 존재감 우선) |
| Naming | `NEMESIS_`, `SETH_` 접두사 + 부위 |
| Pivot | 발바닥 중앙 또는 골반 중심 (연출 의도 따라) |

---

## 4. 작업 순서 권장

1. 삼면도 레퍼런스 배치 (Front / Side / Back)
2. Primary Blockout (실루엣만)
3. Secondary Forms (견·흉·팔·다리 볼륨)
4. Panel Separation + Support Edges
5. Detail Pass (슬릿, 관절, 소형 기구)
6. 실루엣 검증 (네메시스 ≠ 세스)
7. UV / Material ID 분리

---

## 5. 검증 체크리스트

**네메시스**
- [ ] 세로로 길고 중심이 높은가
- [ ] 손이 약하거나 숨겨져 있는가
- [ ] 세스와 즉시 구분되는가

**세스**
- [ ] 근육질 전사 + 차단벽 흉갑인가
- [ ] 손이 분명히 보이는가
- [ ] 왕관·망토·위계 장식이 없는가
