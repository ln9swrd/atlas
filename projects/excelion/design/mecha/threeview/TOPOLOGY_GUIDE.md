## 공통 원칙

1. **SUPER ROBOT FIRST**  
   건담/리얼로봇 하드서피스 일색 금지. 영웅·괴체 실루엣 우선.

2. **실루엣 우선**  
   폴리곤 밀도보다 실루엣 키워드가 먼저.  
   - 네메시스: 길이 · 높은 중심 · 손 약함  
   - 콜로서스(세스): 단정 · 질량 · 차단 · 손 보임

3. **곡면 + 큰 덩어리**  
   - 흉·견·사지 외곽에 곡선·완만 곡면 허용·권장.  
   - Edge flow는 **큰 형태**를 따르고, 패널 라인은 보조.

4. **패널은 보조**  
   - Support Edge로 샤프함을 유지하되 패널 과밀 금지.  
   - 로봇혼/센티넬 **피니시** ≠ 프라 디테일 스팸.

5. **Ortho 삼면도**  
   Front / Side / Back 비율 일치. 레퍼런스 플레인 고정.

## 1. 네메시스기 Topology

**목표 실루엣**  
세로로 김 · 높은 중심 · 얇은 허리 · 손 약함 · 부유감 · **슈퍼로봇 최종 보스**

| 부위 | Topology 가이드 |
|------|-----------------|
| **전체 비율** | 전고 기준 상체 비중 큼. 다리는 길되 완전 골격 축소 금지. |
| **두부** | 캐릭터성 있는 헬멧 볼륨. 슬릿 inset + support. |
| **몸통** | 긴 상체 + 얇은 허리 · 큰 곡면 허용 · 가로 과분할 금지. |
| **팔·손** | 팔은 가늘게. 손은 실루엣에서 약하게. 손가락 과다 금지. |
| **다리** | 긴 원통 + 각도 · 부유감 우선. |
| **배면** | 긴 패널·망토형 요소는 별도 또는 solidify. |
| **Edge Flow** | 수직 + 큰 곡면 흐름. |

**주의**
- 근육질 벌크 금지 · 손 강조 금지 · 왕관·뿔 과다 금지
- 콜로서스와 넓은 어깨·굵은 사지 겹침 금지
- 건담식 패널 난립 금지

---

## 2. 콜로서스(세스) Topology

**목표 실루엣**  
≈30m · 전사형 슈퍼로봇 · 넓은 어깨 · 차단벽 흉갑 · 손 보임

| 부위 | Topology 가이드 |
|------|-----------------|
| **전체 비율** | BRAVE 대비 +20%. 역삼각형 질량. |
| **두부** | 단정 헬멧 · 슬릿 1~2 · 캐릭터성. |
| **견·흉** | 넓은 견갑 + 두꺼운 흉갑 · **큰 곡면/블록**. |
| **팔·손** | 굵은 상완·전완 · **손 보임**. |
| **다리** | 굵은 대퇴 · 큰 무릎 · 넓은 족부. |
| **배면** | 민등 · 배팩·망토 금지. |
| **Edge Flow** | 가로 차단 + 질량 볼륨. |

**주의**
- 네메시스형 고중심 장신 겹침 금지
- 손 숨김 · 왕관·망토 금지
- 리얼로봇 군용 디테일 과밀 금지

## 3. 공통 Topology 규칙

| 항목 | 권장 |
|------|------|
| Quads | 기본 Quad |
| Support Edge | 큰 모서리 · 과한 패널 루프 지양 |
| Panel Lines | 보조 inset · 형태 지배 금지 |
| UV | 큰 장갑 단위 |
| Scale | 실세계 m 스케일 |
| Naming | 기체 접두 + 부위 |

## 4. 작업 순서

1. 삼면도 레퍼런스
2. Primary Blockout (**실루엣·슈퍼로봇 덩어리**)
3. Secondary Forms (곡면·견·흉·사지)
4. Panel Separation (최소)
5. Detail Pass (슬릿·관절만)
6. 실루엣 검증 (네메시스 ≠ 콜로서스 ≠ BRAVE)
7. UV / Material ID
