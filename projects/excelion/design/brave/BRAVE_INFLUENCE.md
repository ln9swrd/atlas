## 1. 한 줄

BRAVE = **여성형 슈퍼로봇**.  
진(眞)겟타로보에 **가까운 기세·진화·개방감**을 가지되, 마징가 시리즈의 **아이콘 명확성**을 참고하고, **드론·핀 패널**로 현대적 기동·전개 층을 더한다. 카피가 아니라 **문법만** 흡수한다.

---

## 2. 정체성 고정

| 항목 | 내용 |
|------|------|
| 성별 인상 | **여성 슈퍼로봇** · 허리 잘록 · 긴 다리 · 과무장·성인 히로인 과장 금지 |
| 계열 | 슈퍼로봇 (리얼로봇 양산감 아님) |
| 진겟타와의 관계 | **유사** — 기세·돌파·형태 전개(EP13) · **동일 기체 아님** |
| 마징가와의 관계 | 아이콘·한 방의 명확함 · 로켓펀치/브레스트 파이어 **직카피 금지** |
| S1 형태 | EP1–12 **동일** · 성장 = S-Core·광기 연출 · EP13만 엑셀리온 1단계 |

---

## 3. 진겟타로보에서 가져올 것 / 말 것

### 가져올 것 (기세·구조)

| 요소 | BRAVE 반영 |
|------|------------|
| **돌파·개방** | 광기·S-Core·EP13 엑셀리온 = “열린다/풀린다” 연출 |
| **기세** | 전투 시 전진·직선적 의지 (실루엣은 여성형 유지) |
| **합체/진화 서사** | 별 기체 교체가 아니라 **같은 몸의 전개** (엑셀리온) |
| **이빨·공격성** | 형태 카피 없음 · 기동·연출·accent 점등으로만 |
| **흑/대비** | 팔레트는 FRAME 고정 · 대비감은 secondary·명암으로 |

### 가져오면 안 되는 것

- 겟타 라인 직카피 (어깨 각, 얼굴 이빨, 특정 합체 실루엣)
- 남성형 bulk · 과각 어깨
- 상시 거대 날개·배팩으로 EP1–12 실루엣 변경
- “진겟타 여성 색칠” 수준의 카피

---

## 4. 마징가 시리즈에서 가져올 것 / 말 것

### 가져올 것

| 요소 | BRAVE 반영 |
|------|------------|
| **아이콘 명확성** | 멀리서도 “주인공기” · 여백+코어 accent |
| **한 방의 서명** | 필살/브레스트 캐논 계열 = **코어·흉부의 빛과 발사** (브레스트 파이어 직카피 아님) |
| **펀치·타격** | 로켓펀치 직카피 금지 · **분리 타격/드론·판넬 사출**로 현대적 해석 가능 |
| **영웅성** | 슈퍼로봇으로서의 정면 돌파 톤 |

### 가져오면 안 되는 것

- 마징가 얼굴·Pilder·특정 흉부 문양 카피
- 로켓펀치 분리 팔 상시 노출로 실루엣 파괴
- 1970s 토이 과장 비율

## 5. 드론 · 핀 패널 (신규 반영 개념)

### 5.1 드론

| 항목 | 규칙 |
|------|------|
| 역할 | 지원·견제·시야 · **BRAVE를 가리지 않음** |
| 크기 | 소형 · 손/머리 대비 메모 (`weapon/brave-drone`) |
| 수 | 소수 · 주연급 독립 드론 금지 |
| 색 | BRAVE 계열 · accent 소량 |
| 합체 | 복잡한 변형 합체 금지 (S1) |
| 연출 | 출격 시에만 실루엣에 점처럼 추가 · 기본 삼면도는 비장착 |

마징가식 “분리 공격”의 현대형 = **드론 사출**로 해석 가능. 본체 실루엣은 유지.

### 5.2 핀 패널 (Pin Panel)

의미: **힌지·핀으로 열린 장갑 패널** (핀 보드/가동 판). 펀넬 그 자체가 아니라 **몸 표면의 가동 판**.

| 항목 | 규칙 |
|------|------|
| 역할 | 방열·기동 보조·일시 실루엣 확장 · 광기/필살 연출 |
| 위치 | 어깨·측면·다리 등 **여백을 깨지 않는** 부위 |
| 평시 | **닫힘** = FRAME 실루엣 유지 |
| 전개 | 짧게 열림 · 패널 안쪽 accent/광 가능 |
| EP13 | 엑셀리온 광익과 **충돌하지 않게** — 광익이 주, 핀 패널은 보조 |
| 금지 | 상시 전개로 여성형·여백 키워드 파괴 · 등 거대 날개 대용 |

진겟타의 “열린 기세”를 **표면 가동**으로 번역한 층. 형태 카피 아님.

## 6. 통합 문법 (그릴 때)

```
여성 슈퍼로봇 실루엣 (FRAME LOCK)
  + 진겟타: 돌파·개방·같은 몸의 전개
  + 마징가: 아이콘·코어 한 방·분리 공격의 현대형(드론)
  + 핀 패널: 닫힌 여백 / 열릴 때만 기세
  + FSS·로봇혼: 깎인 금속 밀도·엣지 (표면만)
```

### 우선순위

1. FRAME_SPEC 실루엣·색·EP 규칙  
2. 여성 슈퍼로봇 읽힘  
3. 진겟타 기세 / 마징가 아이콘 (비카피)  
4. 드론·핀 패널 연출 층  
5. FSS 표면 밀도

## 7. 금지 요약

- 진겟타·마징가 **형태 직카피**
- 남성 bulk · 성인 히로인 과무장
- EP1–12에 상시 날개·배팩·패널 전개로 프레임 변경
- 드론 주연화·거대 비트 남발
- 핀 패널 상시 개방으로 여백 파괴
- “슈퍼로봇이니까” 실루엣 잠금 무시
