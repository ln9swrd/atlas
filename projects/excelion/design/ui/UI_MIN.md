# UI_MIN — D10 UI 최소 3요소

> 2026-08-06 · Design D10  
> 근거: 대본 UI 줄 · `08_PLAY_BRAVE` · 스토리 원칙(과장 UI 금지)

**상태: TEXT-LOCK**

S1 필수 UI는 **3개만**. 나머지 최소화.

---

## 1. 동조율 (Sync)

| 항목 | 내용 |
|------|------|
| 역할 | 공명·임계·과부하 신호 |
| 표시 | 한 줄 또는 짧은 바 · **「동조율 — 임계」** 등 단어 위주 |
| 위치 | 화면 가장자리 · 시야 중앙 가림 금지 |
| 연동 | 광기 단계 상승 시 수치/색 변화 가능 · 설명 문장 금지 |
| EP1 | 오프닝 필수 노출 |

---

## 2. 목표 (Objective)

| 항목 | 내용 |
|------|------|
| 역할 | 30초 안 승패 인지 |
| 표시 | **한 줄** · 예: `거점 사수` / `세스 저지` / `게이트` |
| 위치 | 상단 또는 코너 · 상시 떠 있되 작음 |
| 규칙 | 미션 타입(공성/수성/보스)만 · 장문 브리핑 금지 |

---

## 3. 통신 (Comms)

| 항목 | 내용 |
|------|------|
| 역할 | 카이·레이·유나 음성의 시각 앵커 |
| 표시 | 발신자 이름 짧게 + 파형/아이콘 최소 · 자막은 **짧은 대사만** |
| 특수 | EP8–9 **빈 주파수** · 「콜.」메아리 연출 |
| 금지 | 설정 강의 로그 · 장문 채팅창 |

---

## 공통 규칙

| 규칙 | 내용 |
|------|------|
| 톤 | retro · 단순 · BRAVE 팔레트(primary/secondary/accent) |
| 가독 | 전투 중 시야 우선 · UI는 보조 |
| 금지 | RPG 풀 HUD · 미니맵 과다 · 스킬 아이콘 나열(필요 시 후순위) |
