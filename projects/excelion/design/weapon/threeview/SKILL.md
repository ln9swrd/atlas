# Weapon Threeview

## Storage

```
projects/excelion/design/weapon/<weapon-name>/threeview/
```

Read DESCRIPTION.md for each weapon before generating.

## Rules

- Orthographic front / side / top (or back) when useful
- Clear hard-surface edges for 3D modeling
- Match faction palette (BRAVE accent vs ORD cold / Ashur hierarchy)
- Do not invent drop/loot fantasy; S1 boss weapons are not player drops
