# reference/ — 외부·참고 문서

> 2026-08-14 · 2차 구조 정리

이 폴더는 **Canon이 아니다**.

Excelion TEXT-LOCK · FINAL_SPEC · DESCRIPTION을 덮어쓰지 않는다.
최종 정체성은 Super Robot (`../CANON_HIERARCHY.md` 참조).

## 포함

| 경로 | 역할 |
|------|------|
| **fss/** | Five Star Stories / Mortar Headd 스타일·언어·무기 참고 |
| fss/FSS_STYLE_REF.md | 상징·적용 한도 |
| fss/FSS_DESIGN_LANGUAGE.md | 읽힘 순서·디테일 위계 |
| fss/FSS_WEAPON_DESIGN.md | 무기 문법 (네메시스 원격과 비충돌 명시) |

루트에 남은 `FSS_*.md`는 리다이렉트 스텁이다.

## 규칙

- 참고만 한다.
- 실루엣·팔레트·금지 조항을 이유로 변경하지 않는다.
- 컨셉 이미지 풀(`../brave/`, `../nemesis/`)도 참고 전용이다. 채택 시 DESIGN_QUALITY 미달 시 제외.
