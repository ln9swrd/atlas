# ORD_VISUAL_LANGUAGE — 적 기체 공통 그림체

> 2026-08-06 · Master 지시  
> 목적: **BRAVE를 제외**해도 적 기체만으로 “같은 Order 그룹”임을 디자인으로 식별  
> 연동: `ORD_SPEC` · `SETH_MECHA_SPEC` · `ASHUR_MECHA_SPEC` · `SUPER_ROBOT_MODERN`(적 측 밀도)

**상태: LOCK**

---

## 1. 한 줄

Order 기체 = **하나의 그림체(패밀리)** 안에서 역할만 갈라진다.  
양산·세스·아슈르는 **같은 언어**, 다른 **위계·체형 방언**.

BRAVE(여성 슈퍼·여백·호박 accent)와는 **언어 자체가 다름**.

---

## 2. 공통 문법 (모든 ORD·엘리트·아슈르기)

| 축 | 공통 규칙 |
|----|-----------|
| **진영감** | 냉색·저채도 금속 · 군단/위계 · 아군 호박 `#E8A020` **사용 금지** |
| **면** | 기능 판 · “벽·도구·판결” · BRAVE식 Imperial 여백 미학 **아님** |
| **각** | 엣지 예리 · 토이 라운딩 남발 금지 |
| **패널** | 구조 우선 · 장식 문양·문장 과다 금지 (양산은 더 투박) |
| **센서** | 슬릿·점광 · **냉광** (적·청백 계열) · 아군 호박 눈 금지 |
| **피니시** | 로봇혼급 엣지 가능 · 정보 과다 그리블로 BRAVE와 같은 “주인공 밀도” 내지 말 것 |

멀리서: **차갑고 각지고 아군색이 없다** → Order.  
그다음 실루엣 키로 GRUNT / HEAVY / GUN / MID / 세스 / 아슈르 구분.

---

## 3. BRAVE와 끊는 선 (필수)

| | BRAVE | Order 패밀리 |
|--|-------|----------------|
| 실루엣 | 여성형·여백·단순 덩어리 | 각·기능·역할형 |
| accent | 호박 `#E8A020` | **금지** · 냉광·저채도만 |
| 읽힘 | 주인공·선택 | 군단·처리·위계 |
| 성장 | S-Core·광기·EP13 전개 | 양산은 수 · 보스는 페이즈 |

---

## 4. 같은 그룹 안의 분화 (방언)

| 기 | 공통 유지 | 분화 (개성) |
|----|------------|-------------|
| **GRUNT** | 각·냉색·슬릿 | 작음·투박·여백 0 |
| **HEAVY** | 동일 | 넓·두껍·둔 |
| **GUN** | 동일 | 포신·돌출 우선 |
| **MID** | 동일 | 중형·병기 많음 |
| **세스** | 동일 색·각·냉광 | **+20%·근육질 전사·단정 차단·손 보임** |
| **아슈르** | 동일 냉색 계열(더 고요·비쌈) | **길이·고중심·손 숨김·수직 위계** |

세스·아슈르도 **Order 그림체를 벗어나지 않는다.** 다른 작품 주인공기처럼 보이면 실패.

---

## 5. 세스 = Order 전사 방언 (요약)

- 그림체: Order 공통 (각·청회흑회·냉광·호박 0)
- 방언: 근육질 · 30m · 차단벽 흉 · 민등 · 손 노출
- 양산보다 정돈 · 아슈르보다 짧고 지면에 붙음

---

## 6. 식별 테스트

1. BRAVE 없이 ORD만 나열 → **한 진영**으로 보이는가  
2. 그중 세스만 → **정돈된 큰 전사**로 집히는가  
3. 아슈르만 → **긴 원격 위계**로 집히는가  
4. 어느 것도 BRAVE 여백·호박·여성형으로 오인되지 않는가  

---

## 7. 금지

- 적기마다 다른 애니 그림체
- 세스/아슈르만 슈퍼로봇 주인공 팔레트
- 양산에 아군 accent
- “개성”을 이유로 공통 각·냉색 파기

**Order = 한 그림체. 역할만 방언.**
