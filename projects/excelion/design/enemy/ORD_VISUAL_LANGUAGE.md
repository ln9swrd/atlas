# ORD_VISUAL_LANGUAGE — 적 기체 공통 그림체

> 2026-08-07 · 네메시스 반영  
> 연동: `ORD_SPEC` · `SETH_MECHA_SPEC` · `NEMESIS_MECHA_SPEC` · `SUPER_ROBOT_MODERN`

**상태: LOCK**

---

## 1. 한 줄

Order 기체 = **하나의 그림체** 안에서 역할만 갈라진다.  
양산·세스·네메시스는 **같은 언어**, 다른 **위계·체형 방언**.

BRAVE와는 **언어 자체가 다름**.

---

## 2. 공통 문법

| 축 | 공통 규칙 |
|----|-----------|
| 진영감 | 냉색·저채도 · 아군 호박 `#E8A020` **금지** |
| 면 | 기능 판 · BRAVE식 Imperial 여백 아님 |
| 각 | 엣지 예리 |
| 센서 | 슬릿·냉광 |
| 피니시 | 로봇혼급 가능 · 주인공 밀도 금지 |

멀리서: **차갑고 각지고 아군색 없음** → Order.  
그다음 GRUNT / HEAVY / GUN / MID / 세스 / 네메시스.

---

## 3. BRAVE와 끊는 선

| | BRAVE | Order |
|--|-------|-------|
| 실루엣 | 여성형·여백 | 각·기능 |
| accent | 호박 | **금지** |
| 읽힘 | 선택 | 군단·처리·위계 |

---

## 4. 방언

| 기 | 분화 |
|----|------|
| GRUNT~MID | 역할형 투박 |
| 세스 | +20%·근육질·차단·손 보임 |
| 네메시스 | 길이·고중심·손 숨김·수직 위계 |

세스·네메시스도 Order 그림체를 벗어나지 않는다.

---

## 5. 금지

- 적기마다 다른 애니 그림체
- 세스/네메시스만 주인공 팔레트
- 양산에 아군 accent

**Order = 한 그림체. 역할만 방언.**
