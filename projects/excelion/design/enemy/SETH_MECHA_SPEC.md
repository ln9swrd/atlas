## 실루엣 텍스트

| 축 | 묘사 |
|----|------|
| 전체 | humanoid · **각이 살아 있음** · 군더더기 없음 |
| 크기 | BRAVE와 비슷하거나 약간 큼 · MID처럼 병기 과다하지 않음 |
| 두부 | 단정한 헬멧/센서 · 감정 없음 · 뿔·왕관·위계 장식 **금지** |
| 몸통 | 판이 매끄럽고 **차단벽**처럼 읽힘 · 여백은 BRAVE식 미학이 아님 |
| 팔 | 방어·제압 제스처에 맞는 단단한 암 · 거포로 실루엣 지배 금지 |
| 다리 | 안정·짧은 보폭 인상 · 돌진보다 “막아선다” |
| 배면 | 단순 · 과한 익형·망토형 금지 (아슈르와 분리) |

**키워드 3:** 단정 · 차단 · 장식 최소
