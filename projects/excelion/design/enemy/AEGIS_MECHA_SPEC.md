## 실루엣

| 축 | 묘사 |
|----|------|
| 전체 | **가로로 넓은 정면** · 벽·문 인상 |
| 두부 | 센서·슬릿 · 왕관·오만 장식 **최소화 또는 없음** |
| 몸통 | 두꺼운 흉·방패 일체형 · 여백은 “비움”이 아니라 **차단면** |
| 팔·손 | 방패 운용 · 반격 암 · **기능이 보이게** |
| 다리 | 넓게 접지 · 부유·원격 인상 **금지** |
| 배면 | 게이트/통로 쪽과 연결감 가능 · 망토형 위계 과장 금지 |

**키워드:** 방패 · 입구 · 기능 · 접지 · 오만 없음

| | 네메시스 | 아이기스 |

## 색

저채도 회·청흑. 네메시스 보라를 **약하게만** 엣지/슬릿에 가능.  
주조를 네메시스와 동일하게 두지 말 것.

금지: BRAVE 호박 accent · 광기 적열 · 화려 왕관색.

## 전투 연출 (메카)

- 방어 게이지 · 반격 창 · 텔레그래프 있는 반격
- 격파 후: 길이 열릴 뿐 · 폭발적 장엄 승리 연출 과다 금지
- 네메시스 원경 시선은 있어도 아이기스가 오만을 대신하지 않음
