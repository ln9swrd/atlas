## 한 줄

아슈르기 = **위계 · 길이 · 높은 중심 · 원격 존재감** · 손/무장이 잘 안 보임 · 세스기·ORD와 즉시 구분 · 오만을 **실루엣으로** 드러냄.

---

## 역할

| 항목 | 내용 |
|------|------|
| 기수 | 아슈르 (최종 보스) |
| 노출 | EP4 이름 → EP6 시선 → EP7 원격 일격 → EP9 전면 → EP13 결판 |
| 격 | S1 최종 벽 |
| 태도 | 리아를 적이 아니라 **아직 안 된 것**으로 봄 · 등급 |

---

## 실루엣 텍스트

| 축 | 묘사 |
|----|------|
| 전체 | humanoid이되 **세로로 김** · 중심이 높음 · 지상에 붙지 않은 인상 |
| 크기 | 세스·BRAVE보다 존재감 큼 (실제 m 수치보다 **화면 점유·거리감**) |
| 두부 | 내려보는 각도 · 얼굴/센서가 잘 안 열림 · 왕관형 가능하나 **광기 일그러짐 금지** |
| 몸통 | 긴 상체 · 여백이 “비어 있음”이 아니라 **닿을 수 없음**으로 읽힘 |
| 팔·손 | **손·무장이 실루엣에서 약하거나 숨김** (EP7 손 안 댐과 일치) |
| 다리 | 가늘고 김 · 접지보다 부유·원거리 압박 |
| 배면/외곽 | 망토·긴 패널·수직 라인으로 위계 · 세스의 각진 차단벽과 반대 |

**키워드 3:** 위계 · 길이 · 원격
