## 한 줄

Order 양산·중형. **각·기능·투박** · BRAVE보다 장식 적고 사람다움 없음 · 식별은 실루엣 키 4종.

공통: 엔릴 후손 실행 단위 · 색은 냉색·저채도(군단감) · 개별 개성 과다 금지.

## ORD-GRUNT (잡)

| 축 | 묘사 |
|----|------|
| 역할 | 전 구간 양산 · 섬멸 대상 |
| 크기 | BRAVE보다 작거나 비슷 · 위압 없음 |
| 실루엣 | **각진 두부** · 짧은 몸 · 팔다리 투박 · 여백 거의 없음 |
| 무장 | 내장 화기 또는 단순 블레이드 · 거대 실루엣 파괴 무기 없음 |
| 읽힘 | “많이 나온다” |

## ORD-HEAVY (중)

| 축 | 묘사 |
|----|------|
| 역할 | 전선 압박 · 방어 돌파용 |
| 크기 | BRAVE 이상 · 덩치로 압박 |

## ORD-GUN (원거리)

| 축 | 묘사 |
|----|------|
| 역할 | 원거리 견제 |
| 크기 | GRUNT급 또는 약간 큼 |
| 실루엣 | **포신·센서 돌출** · 몸통은 가늘거나 박스형 · 팔보다 무기 라인이 먼저 읽힘 |
| 무장 | 장포·미사일 포드 · 근접 실루엣은 약해 보임 |
| 읽힘 | “멀리서 쏜다” |

---

## ORD-MID (중보스 · EP5)

| 축 | 묘사 |
|----|------|
| 역할 | EP5 정점 · 병기 감 |
| 크기 | HEAVY 이상 · 화면에서 한 기만으로도 존재감 |
| 실루엣 | **중형 덩치 + 병기 과다** · GRUNT/HEAVY와 즉시 구분 · 각은 유지하되 부위가 많음 |
| 무장 | 다총구·아암 웨폰 · “양산의 정점”이지 세스/아슈르 아님 |
| 읽힘 | “지금까지와 다르다” (대본 CUT과 일치) |
| 금지 | 오만 위계 연출 · 비극 주연 연출 |
