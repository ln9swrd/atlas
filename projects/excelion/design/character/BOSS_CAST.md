# BOSS_CAST — D7 아슈르·세스 인물

> 2026-08-06 · Design D7  
> 근거: `ASHUR_ARROGANCE_FIXED` · `SETH_BATTLE_FIXED` · `NAMES_SILHOUETTE_FIXED` · 기체 스펙 D4–D5

**상태: TEXT-LOCK**

인물 실루엣은 기체와 **같은 키**를 공유한다. 얼굴 연기에만 의존하지 않음.

---

## 아슈르 (최종 보스 · 인물)

| 축 | 묘사 |
|----|------|
| 키워드 | 위계 · 길·높은 중심 · **손 안 보임** |
| 체형 | 세로로 긴 인상 · 내려보는 구도 · 지상에 붙지 않은 거리 |
| 얼굴 | 정면 응시 드묾 · 분노 클로즈업 남발 금지 · 무표정에 가까운 판정 |
| 손 | 제스처 최소 · 보여줘도 “만지지 않음” |
| 말 | 짧은 판정문만 · 장문·설교 실루엣(손짓 과다) 금지 |
| 읽힘 | “등급을 매긴다 · 아직 안 된 것” |

금지: 광기형 일그러진 얼굴 · 세스와 동일 실루엣 · 친근 호칭 포즈

---

## 세스 (ORD-ELITE · 인물)

| 축 | 묘사 |
|----|------|
| 키워드 | 단정 · 각·차단 · 전선 · 무표정 |
| 체형 | 정돈된 비율 · 오만 장식 없음 · 전선에 서 있는 밀도 |
| 얼굴 | 기본 무표정 · 균열은 **장면당 1회 이하**(시선 한 번 더 · 말 반 박) |
| 손 | 처리·보고 제스처 · 위계 과시 없음 |
| 말 | 짧음 · 「…보고, 끝.」 계열 |
| 읽힘 | “해야 해서 처리한다” |

금지: 비극 주연 · 아슈르급 위계 장식 · 카이 대칭 라이벌 연출

---

## 대비표

| | 아슈르 | 세스 |
|--|--------|------|
| 거리 | 원격·후방 | 전선 |
| 손 | 안 보임·안 댐 | 처리에 사용 |
| 감정 | 오만을 드러냄 | 안 드러내려 함 |
| 패배 | 시작에 불과 | 보고, 끝 |
| 실루엣 | 길·위계 | 단정·차단 |
