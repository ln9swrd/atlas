## 2. 인물 — 외형 · 체형 · 태도

### 2.1 실루엣과 체형

아슈르는 세로로 긴 인상을 준다. 중심이 높고, 지상에 완전히 붙지 않은 거리감을 유지한다. 내려보는 구도가 기본이다. 정면으로 응시하는 장면은 드물다.

- **두부**: 얼굴 윤곽이 또렷하나 표정 변화가 거의 없다. 무표정에 가까운 ‘판정’의 얼굴. 분노나 광기형 일그러짐은 금지.
- **손**: 제스처를 최소화한다. 보여줘도 “만지지 않음”으로 읽힌다. EP7 원격 일격의 논리적 연장.
- **전체 비율**: 가늘고 긴 실루엣. 세스의 단정·차단형과 즉시 구분된다.
- **의상/장식**: 위계를 드러내는 수직 라인·패널 계열. 과한 장식이나 친근한 포즈는 없다.

### 2.2 말과 시선

말수는 극히 적다. 짧은 판정문만 사용한다. 장문 강의·설교·동기 설명은 금지.

| EP | 고정 대사 / 시선 |
|----|------------------|
| 4 | 이름만 (본체 없음) |
| 6 | 원경 시선 1컷 · 말 없음 |
| 7 | 원격 일격 · 손 안 댐 |
| **9** | **「아직 급이 아니다」** (이 화만) |
| 10–12 | 말 최소 · 「이미 인간이 아니다」 계열 가능 |
| **13** | **「이것은 시작에 불과하다」** · 「급이 아니다」 반복 금지 |

시선은 내려봄·스침이 기본이다. 리아의 승리에도 “변수”로만 취급하며 놀라지 않는다. EP11 후퇴는 약함의 표현이 아니라 **재평가**다.

### 2.3 오만의 본질

아슈르의 오만은 감정 폭발이 아니다.  **위계를 믿는 자**의 자연스러운 태도다.

- 리아를 적으로 인식하지 않는다.
- 등급을 매기고, 아직 도달하지 못했다고 판정한다.
- 패배해도 오만은 유지된다. EP13 패배 시에도 형태 붕괴·비참·우스꽝 연출 금지.

## 3. 기체 — 아슈르기 (Ashur Mecha)

### 3.1 한 줄

아슈르기 = **위계 · 길이 · 높은 중심 · 원격 존재감**.  
손과 무장이 실루엣에서 약하거나 숨겨져 있다. 세스기·ORD·BRAVE와 즉시 구분된다. 오만을 **실루엣으로** 드러낸다.

### 3.2 실루엣 상세

| 축 | 묘사 |
|----|------|
| 전체 | humanoid이되 **세로로 김**. 중심이 높음. 지상에 붙지 않은 인상. |
| 크기 | 세스·BRAVE보다 존재감이 크다. (실제 m 수치보다 **화면 점유·거리감**) |
| 두부 | 내려보는 각도. 얼굴/센서가 잘 열리지 않음. 왕관형 가능하나 **광기 일그러짐 금지**. |
| 몸통 | 긴 상체. 여백이 “비어 있음”이 아니라 **닿을 수 없음**으로 읽힘. |
| 팔·손 | **손·무장이 실루엣에서 약하거나 숨김**. EP7 손 안 댐과 일치. |
| 다리 | 가늘고 김. 접지보다 부유·원거리 압박. |
| 배면/외곽 | 망토·긴 패널·수직 라인으로 위계. 세스의 각진 차단벽과 반대. |

**키워드 3:** 위계 · 길이 · 원격

### 3.3 색채

| 용도 | 방향 |
|------|------|
| 주조 | 깊은 흑·남·저채도 금속. ORD보다 **더 고요하고 비쌈**. |
| 강조 | 냉백·차가운 광. |
| 금지 | 광기형 적열 일그러짐 · 아군 호박 accent · 세스와 동일 배색. |

### 3.4 EP별 비주얼 밀도

| EP | 연출 |
|----|------|
| 4 | 이름만 · 기체 본체 없음 |
| 6 | 원경 실루엣 1컷 · 디테일 불필요 |
| 7 | 원격 일격 · 본체는 원거리·손 안 보임 |
| 9–12 | 전면 · 내려봄 · 등급 시선 |
| 13 | 풀 실루엣 · 패배해도 오만 유지 (형태 붕괴·추한 파괴 금지) |

### 3.5 세스기와의 필수 차이

| | 아슈르기 | 세스기 |
|--|----------|--------|
| 키 | 위계·길이·원격 | 단정·차단·장식 최소 |
| 손 | 안 보이거나 약함 | 제압·전선에 보임 |
| 장식 | 위계를 드러냄 | 거의 없음 |
| 거리 | 후방·원격 | 전선 |

아슈르기 ≠ 세스기 스케일업. 완전히 다른 존재감.

## 7. 금지 사항 (절대)

**인물**
- 광기형 일그러진 얼굴
- 세스와 동일 실루엣
- 친근 호칭 포즈
- 리아·카이와 주연 경쟁
- 장문 동기 설명·신화 강의
- EP13에서 「급이 아니다」 재사용

**기체**
- 세스기 스케일업 카피
- 광기 주인공형 일그러진 실루엣
- 매 화 혈투용 거대 무기 난무로 실루엣 파괴
- EP13 패배 시 우스꽝·비참 실루엣으로 오만 붕괴

**전투**
- 텔레그래프 없는 즉사
- 스킬명·이펙트에 설정 강의
- 리아 무기와의 톤 겹침

## 8. 제작 지침 요약

### 인물 삼면도
- 포즈: T-pose / A-pose, 세로로 긴 인상 유지
- 배경: 순백
- 뷰: 정면·측면·후면 (orthographic)
- 손 최소화 또는 가려진 인상
- 얼굴: 무표정에 가까운 판정
- 스타일: 90년대 Retro · 위계·오만

### 기체 삼면도
- 동일하게 세로로 긴 인상 · 높은 중심
- 손/무장 최소화
- 세스기와 실루엣 겹침 금지
- 색: 깊은 흑·남·저채도 금속 + 냉백 강조

### 연출 우선순위
1. 몸이 먼저 (시선·거리·손)
2. 말 짧게
3. 오만 = 형태와 거리로 읽히게
4. 패배해도 오만 유지
