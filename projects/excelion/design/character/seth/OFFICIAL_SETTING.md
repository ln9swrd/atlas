## 3. 기체 — 세스기

### 3.1 한 줄

세스기 = **단정·각·차단형** · 장식 최소 · 전선에서 “닫는” 실루엣 · 네메시스기와 명확히 다름 · 오만·위계 연출 없음.

### 3.2 실루엣 상세

| 축 | 묘사 |
|----|------|
| 전체 | humanoid · **각이 살아 있음** · 군더더기 없음 |
| 크기 | BRAVE와 비슷하거나 약간 큼 |
| 두부 | 단정한 헬멧/센서 · 감정 없음 · 뿔·왕관·위계 장식 **금지** |
| 몸통 | 판이 매끄럽고 **차단벽**처럼 읽힘 |
| 팔 | 방어·제압 제스처에 맞는 단단한 암 · 거포로 실루엣 지배 금지 |
| 다리 | 안정·짧은 보폭 인상 · “막아선다” |
| 배면 | 단순 · 과한 익형·망토형 금지 |

### 3.3 색

주조: 저채도 청회·흑회 · ORD 계열이나 더 정돈됨.  
강조: 냉광 슬릿 정도 · 호박 accent 금지.
