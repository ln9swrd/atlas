## 1. 정의

중간보스 = **단순 관문이 아니라 플레이 변곡점**  
= 플레이어를 **재교육**하는 구간  
≠ HP 체크 · ≠ 동일 패턴 반복

| 목표 | 내용 |
|------|------|
| 1 | 플레이 스타일 강제 변화 |
| 2 | 학습된 패턴의 붕괴 |
| 3 | 후반(네메시스) 능력의 **일부** 예고 |

---

## 2. 페이즈 구조 (공통)

| Phase | 역할 | 필수 |
|-------|------|------|
| **1** | 학습 확인 | 기존 패턴을 읽게 함 |
| **2** | 패턴 왜곡 | 속도·범위·타이밍 변화 |
| **3** | 신규 기믹 | 환경·디버프·조건 추가 |

### 전환 규칙 (v1.1)

- **시간 + 트리거 혼합** (경과 시간 · 약점 창 n회 · 씰 해제 n회 등)
- **HP% 트리거 금지** — Phase 전환에 HP 임계를 쓰지 않음
- 클리어는 HP 0 가능 · 전환 조건과 분리

---

## 3. 핵심 강화 요소

### (1) 패턴 반전
- 익숙한 공격 → 타이밍 지연 또는 즉발화
- 안전지대 → 함정화

### (2) 환경 개입
- 맵 붕괴 · 이동 제한
- 시야 차단 (전면 즉사급 금지)

### (3) 리소스 압박
- 회복 제한 구간
- 스킬 봉인 구간 (짧게)

## 4. 타입 A / B / C

| 타입 | 성격 | 플레이 강제 | 대표 |
|------|------|-------------|------|
| **A 압박형** | 지속 추격 · 공간 압박 | 회피·기동 위주 | 몬투 P1–2 · 네크 · 소벡 |
| **B 퍼즐형** | 조건 충족 시만 유효 딜 | 패턴·순서 해석 | **세스** · 호르 · 토트 · 와제 |
| **C 폭발형** | 짧은 고난이도 회피 창 | 집중 회피 | 몬투 P3 · **아누비스** |

- **몬투** = **A/C** (압박 → 공간 붕괴 → 폭발)
- **세스** = **B** (씰·차단 판단 중심)

상세 수치·트리거: `MIDBOSS_PHASE_DETAIL.md`
