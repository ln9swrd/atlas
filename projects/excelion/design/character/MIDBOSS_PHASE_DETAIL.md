# MIDBOSS_PHASE_DETAIL — 몬투 · 세스 Phase 상세

> 2026-08-09 · v1.1  
> 상위: `MIDBOSS_DESIGN` · `BOSS_COMBAT_SHAPE`  
> 스케일: B1 (BRAVE HP=100 · 필살=40)

**상태: 초안 · 실기 전**

---

## 0. 공통 규격

| 항목 | 규칙 |
|------|------|
| Phase 전환 | **시간 + 트리거 혼합** · **HP 임계 금지** |
| Phase 역할 | 1=학습 확인 · 2=왜곡 · 3=신규 기믹 |
| 반복 | 동일 패턴 루프 금지 · Phase마다 진화 필수 |
| 클리어 | HP 0 가능 · 단 **전환 조건으로 HP% 쓰지 않음** |
| 아슈르 | 폐기 · 참조 금지 |

### 전환 트리거 예

- 경과 시간 (권장 주)
- 특정 행동 성공 횟수 (약점 창 n회 · 씰 해제 n회)
- 환경 이벤트 (맵 조각 파괴 완료 등)

## 1. 몬투 (Montu) — EP5 · 타입 A/C

**역할:** 첫 벽 · 재교육 시작 · 압박→공간 붕괴  
**네메시스 예고:** 다병기 압박 · 「공간에 남는 잔향」 느낌만 (중력 아님)

### 수치

| 항목 | 값 |
|------|-----|
| HP | **360** |
| 목표 전투 | 3–5분 |
| 피격 (일반) | 10–14 |
| 피격 (약점 창) | 22–28 |
| 필살 배율 | ×1.4 (약점 창 중) |

### Phase 1 — 학습 확인 (A 압박)

| | |
|--|--|
| **시간** | 전투 시작 ~ **90초** 또는 약점 창 **2회** 성공 |
| **패턴** | 다병기 교대 사격 · 중거리 유지 · 안전지대 명확 |
| **학습** | 「병기 사이클 읽고 창에 들어간다」 |
| **금지** | 즉사 · 시야 전면 차단 |

### Phase 2 — 패턴 왜곡 (A→C)

| | |
|--|--|
| **진입** | P1 종료 트리거 |
| **시간** | 약 **60–75초** 또는 약점 창 **2회** 추가 |
| **왜곡** | 안전지대 중 1곳 함정화 · 사격 타이밍 지연/즉발 혼재 · 추격 가속 |
| **학습** | 「읽은 패턴을 의심한다」 |
| **환경** | 맵 가장자리 붕괴 시작 (이동 폭 −20%) |

### Phase 3 — 신규 기믹 (C 폭발)

| | |
|--|--|
| **진입** | P2 종료 트리거 |
| **시간** | 잔여 ~ 클리어 (목표 **45–60초**) |
| **기믹** | 전방 부채꼴 폭발 3연 · 짧은 고난이도 회피 · 회복 제한 15초 |
| **학습** | 「압박 끝에 폭발 구간이 온다」 |
| **클리어** | HP 0 · 레이 사후 침묵 스토리 연동 |

### 흐름 한 줄

```
다병기 읽기 → 안전지대 배신 → 공간 붕괴 + 폭발 회피
```

## 2. 세스 (Seth) — EP6 · 타입 B

**역할:** 차단·퍼즐 · 판단 중심 재교육  
**네메시스 예고:** 「보고, 끝」 · 위계적 처리 톤 (오만 금지)

### 수치

| 항목 | 값 |
|------|-----|
| HP | **480** |
| 차단 게이지 | **240** |
| 목표 전투 | 4–7분 |
| 피격 (차단 중) | 8–12 |
| 피격 (노출) | 18–22 |
| 집념 돌파 | ×1.5 · 과부하 지연 ×1.3 |

### Phase 1 — 학습 확인 (B)

| | |
|--|--|
| **시간** | 시작 ~ **120초** 또는 씰 해제 **1회** |
| **패턴** | 단정 차단면 · 직선 처리 · 씰 위치 고정·표시 |
| **학습** | 「차단을 부수지 말고 푼다」 |
| **딜 조건** | 씰 해제 후에만 유효 딜 |

### Phase 2 — 패턴 왜곡 (B)

| | |
|--|--|
| **진입** | P1 종료 (시간 또는 씰 1회) |
| **시간** | 약 **90초** 또는 씰 해제 **2회** |
| **왜곡** | 씰 위치 이동 · 가짜 안전 표시 1회 · 차단 타이밍 불규칙 |
| **학습** | 「표시를 그대로 믿지 않는다」 |
| **리소스** | 스킬 봉인 구간 8초 (씰 실패 시) |

### Phase 3 — 신규 기믹 (B)

| | |
|--|--|
| **진입** | P2 종료 |
| **시간** | 잔여 ~ 클리어 |
| **기믹** | 이중 씰 (동시 또는 연쇄) · 한쪽만 풀면 반격 · 환경 이동 제한 1회 |
| **학습** | 「순서·조건을 읽고 돌파한다」 |
| **클리어** | HP 0 · 「…보고, 끝.」 |

### 흐름 한 줄

```
씰 풀기 → 표시 불신 → 이중 조건 돌파
```
