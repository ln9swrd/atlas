## 0. 보스 = 시스템 학습 장치

보스는 강적만이 아니라 **플레이어가 다음 전투를 배우게 하는 장치**.

| 요소 | 요구 |
|------|------|
| 실루엣 | 흑실루엣만으로 구분 |
| 패턴 테마 | 한 화에 한 가지 핵심 학습 |
| 결과 연쇄 | 다음 EP에 영향 |
| 중간보스 | **재교육 구간** (`MIDBOSS_DESIGN`) |

### 재교육 원칙 (중간보스)

1. **반복 금지** — 동일 패턴 루프 금지
2. **패턴 진화 필수** — Phase마다 반드시 변화
3. **흐름 고정** — 학습 확인 → 왜곡 → 신규 기믹
4. **Phase 전환** — 시간+트리거 · **HP% 금지**

### 중간보스 페이즈

| Phase | 역할 |
|-------|------|
| 1 | 학습 확인 |
| 2 | 패턴 왜곡 |
| 3 | 신규 기믹 (환경·디버프) |

타입: **A 압박** · **B 퍼즐** · **C 폭발**
