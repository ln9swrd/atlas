# ANUBIS_MECHANICS — 인지 교란 시스템

> 2026-08-09 · prototype v1  
> 원칙: **이해하면 대응 가능** · 단순 시각 방해 금지

**상태: 시스템 정의 초안**

---

## 1. 목표

인지 교란을 “눈아픔”이 아니라 **규칙 레이어**로 구현한다.

| 허용 | 금지 |
|------|------|
| 예고된 짧은 UI 왜곡 | 예고 없는 입력 막기 |
| 가짜 경고(학습 가능한 차이) | 반응 불가능한 패턴 |
| 의미 반전(실선/점선 고정) | 매 회 랜덤 의미 |

---

## 2. UI 왜곡 (가짜 경고)

| 항목 | 값 |
|------|-----|
| 예고 | 0.6s 보라 펄스 + 고유 사운드 |
| 지속 | ≤ 0.8s |
| 내용 | HUD 일부 반전/깜박 · **전투 판정은 진실 유지** |
| 대응 | 이동·회피만 · 콤보 입력 자제 |
| 횟수 | P3 전투당 1회 |

가짜 위험 마커는 **점선** · 진짜는 **실선** (전 페이즈 동일 규칙).

---

## 3. 입력 지연/왜곡

| 항목 | 값 |
|------|-----|
| 사용 | 선택적 · P3만 |
| 지연 | 입력 → 실행 +40–60ms (체감 가능한 수준, 조작 불능 금지) |
| 예고 | 필수 |
| 금지 | 입력 무시 · 키 랜덤 재매핑 |

---

## 4. 패턴 의미 반전

| Phase | 규칙 |
|-------|------|
| P1 | 예고 = 진실 (학습) |
| P2 | 예고 길이 혼재 · 색 동일 · 길이로 구분 |
| P3 | 실선=위험 · 점선=가짜 (고정) |

반전 규칙을 **전투 중 바꾸지 않음**. 바꾸면 정보 실패(설계 오류).

---

## 5. 플레이어 학습 문장

1. 「선이 보이면 피한다」
2. 「길이·종류를 본다」
3. 「실선만 믿는다」

---
