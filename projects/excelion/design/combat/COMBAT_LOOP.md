# COMBAT_LOOP — 전투 루프

> 2026-08-09 · prototype v1

**상태: 운용 정의**

---

## 1. 한 줄 흐름

```
탐색 → 교전 시작 → 패턴 학습 → 왜곡 → 붕괴 → 종료
```

중간보스 공통 = Phase 1 학습 → Phase 2 왜곡 → Phase 3 붕괴/신규 기믹

---

## 2. 단계 정의

| 단계 | 플레이어 경험 | 시스템 |
|------|---------------|--------|
| 탐색 | 보스 실루엣·공간 파악 | 진입 연출 · 교전 전 무적 선택적 |
| 교전 시작 | 첫 패턴 노출 | Phase 1 타이머 시작 |
| 패턴 학습 | 정답 행동 습득 | 텔레그래프 정직 |
| 왜곡 | 같은 신호 배신 | Phase 2 트리거 |
| 붕괴 | 새 규칙 강제 | Phase 3 · 압박 최대 |
| 종료 | 클리어 또는 패배 | 결과 UI · 재도전 |

---

## 3. 진입 조건

- 스토리/스테이지 게이트 통과
- 플레이어 조작 가능 상태
- 보스 스폰 완료 · HP/상태 초기화

---

## 4. 페이즈 전환 (시간 기반)

| 보스 | P1 | P2 | P3 |
|------|-----|-----|-----|
| 몬투 | ~90s 또는 창 2회 | ~60–75s 또는 창 2회 | 잔여 |
| 세스 | ~120s 또는 씰 1 | ~90s 또는 씰 2 | 잔여 |
| 아누비스 | ~75s 또는 정대응 2 | ~70s 또는 재정대응 2 | 잔여 |

**HP% 전환 사용 안 함.**

---

## 5. 회복 타이밍

| 구간 | 회복 |
|------|------|
| Phase 전환 직후 1.5s | 짧은 숨 고르기 (자동 회복 소량 또는 아이템 창) |
| P3 진입 | 회복 **제한** 가능 (몬투 15s 등 스펙 따름) |
| 전투 중 자유 | 아이템 쿨 존중 · 스팸 방지 |

---

## 6. 실패 · 재도전

| 항목 | 내용 |
|------|------|
| 패배 조건 | 플레이어 HP 0 |
| 실패 표시 | 마지막 피격 패턴명 + 실패 유형(반응/판단/정보) |
| 재도전 | 즉시 재시작 · Phase 1부터 · 학습 유지(숙련) |
| 금지 | 패배 연출로 스토리 강제 분기 (중간보스는 재도전 가능) |

---

## 7. 핵심 질문

| 질문 | 답 |
|------|-----|
| 어떻게 배우가? | 정직한 예고 → 성공 피드백 |
| 어떻게 죽는가? | 미독·미실행 · 원인 표시 |
| 어떻게 다시 하는가? | 즉시 재도전 · 같은 규칙 |
