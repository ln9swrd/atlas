## 구현 순서 제안

1. Phase 상태 머신 (시간+트리거)

3. 몬투 영역/창
4. 세스 씰 UI
5. 아누비스 신호·인지 레이어 (**CRITICAL**)
6. 피드백 · 실패 표시
7. 테스트 시나리오 로그
