# TUNING_GUIDE — 실기 튜닝 기준

> 2026-08-09 · midboss v1.1

**상태: 운용 기준**

---

## 1. 테스트 기준

```
동일 빌드 · 3회 플레이
→ 그중 1회 이상 클리어 가능해야 함 (숙련 전제 아님 · 학습 가능 난이도)
```

| 결과 | 조치 |
|------|------|
| 0/3 클리어 | 패턴 가시성·반응 시간 완화 우선 |
| 1–2/3 | 목표 구간 · 미세 조정 |
| 3/3 여유 | 판단 압력 또는 공간 점유율 +1단계 검토 |

---

## 2. 조정 우선순위

1. **패턴 가시성** (텔레그래프 · 색 · 실루엣)
2. **반응 시간** (예고 길이 · 판정 너비)
3. **판정 정확도** (히트박스 · 무적 프레임)

HP·데미지만 먼저 올리지 않음.

---

## 3. 금지

- 랜덤 즉사
- 비가시 공격
- HP% Phase 전환
- 동일 패턴 무한 반복
- 정답 없는 회피 (운)
