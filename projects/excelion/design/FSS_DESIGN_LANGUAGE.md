## 1. 한 줄

FSS 디자인 언어 = **“지위가 있는 몸을, 깎인 금속으로, 한 번에 읽히게”** 만드는 문법.

---

## 2. 읽힘 순서 (시선 문법)

| 순서 | 레이어 | 내용 |
|------|--------|------|
| 1 | **실루엣** | 멀리서도 “기사/유일”인지 “양산”인지 구분 |
| 2 | **헤드** | 개성·가면·주인의 얼굴 대체 |
| 3 | **큰 면 분할** | 흉·어깨·허리·다리의 큰 덩어리 |
| 4 | **패널·엣지** | 깎인 금속임을 증명 |
| 5 | **포인트 색·문양** | 지위·시선 고정 |

**규칙:** 5가 1·2를 이기면 안 된다.

---

## 3. 디테일 위계

| 등급 | 요소 |
|------|------|
| S | 실루엣 · 헤드 실루엣 |
| A | 큰 면 분할 · 허리·어깨 볼륨 |
| B | 패널 단차 · 엣지 |
| C | 리벳·슬릿·벤트 |
| D | 문양·보조색 |

---

## 4. Excelion 적용 한도

| 빌릴 것 | 빌리지 말 것 |
|---------|--------------|
| 읽힘 순서 · 디테일 위계 | 기사 결투 세계관 |
| 곡 위 각 · 깎인 금속 | 특정 FSS 헤드/문장 |
| 여백=품격 · 포인트=지위 | ORD 유일화 |
| 절차 | TEXT-LOCK 실루엣·팔레트 변경 |
