## 1. 한 줄

FSS 디자인 언어 = **“지위가 있는 몸을, 깎인 금속으로, 한 번에 읽히게”** 만드는 문법.

상징(기사·예술품·유일)이 먼저 있고, 비례·헤드·장갑·여백·디테일이 그 문장을 구성한다.

---

## 2. 읽힘 순서 (시선 문법)

FSS 기체는 다음 순서로 읽히도록 설계된다.

| 순서 | 레이어 | 내용 |
|------|--------|------|
| 1 | **실루엣** | 멀리서도 “기사/유일”인지 “양산”인지 구분 |
| 2 | **헤드** | 개성·가면·주인의 얼굴 대체 |
| 3 | **큰 면 분할** | 흉·어깨·허리·다리의 큰 덩어리 |
| 4 | **패널·엣지** | 깎인 금속임을 증명 |
| 5 | **포인트 색·문양** | 지위·시선 고정 |

**규칙:** 5가 1·2를 이기면 안 된다. 디테일이 실루엣을 깨면 FSS가 아니라 장식 과잉이다.

---

## 3. 비례 문법

### 3.1 기본 비례 감각

| 요소 | 문법 |
|------|------|
| 전체 | humanoid · **세로로 우아** · 투박한 사각형 덩어리 지양 |
| 머리 | 실루엣 대비 작거나 압축 · 개성은 형태·가면으로 |
| 목 | 어느 정도 길이/분리 → “헬멧을 쓴 몸” |
| 어깨 | 존재감 있되 **과 bulk 금지** · 곡선 볼륨 + 각 판 |
| 흉·복부 | 큰 면 · 여백 가능 · 여기가 비면 품격, 여기가 난잡하면 양산 |
| 허리 | **한 단 잘록** → 기동·우아·성별 암시(과하지 않게) |
| 팔 | 몸통을 가리지 않음 · 원통+판 |
| 다리 | 길게 · “달릴 수 있는 기사” · 접지는 안정 |

### 3.2 비례가 상징에 복무하는 방식

- 길게 = 귀족·비일상
- 짧게 뭉치면 = 병기·양산
- 허리 잘록 = 사람다움·기동 (FSS는 사람다움을 **품격**으로 승화)
- 머리 과대 = 캐릭터화·치비화 → FSS 문법 밖

---

## 4. 헤드 문법 (가장 강한 개성 슬롯)

| 규칙 | 내용 |
|------|------|
| 역할 | 기사의 **가면·문장·이름** |
| 형태 | 마스크·뿔·장식 헬멧 · 얼굴면이 “열리지 않는 가면” |
| 대비 | 부드러운 두개 윤곽 + 각진 센서/슬릿 |
| 금지(Excelion) | FSS 특정 뿔·가면 카피 · 아슈르에 광기 일그러진 얼굴 |

헤드가 약하면 기체가 “익명 병기”로 떨어진다. 헤드가 과하면 실루엣이 깨진다. **개성은 헤드에 모으고, 몸은 품격으로 받친다.**

---

## 5. 장갑 논리 (Armor Logic)

FSS 장갑은 “붙인 판”이 아니라 **깎아 만든 층**으로 읽힌다.

### 5.1 층위

```
1. 골격 윤곽 (곡선 실루엣)
2. 주 장갑 판 (각·단차)
3. 패널 분할 (밀도)
4. 리벳·슬릿·미세 (설득력)
5. 문양·포인트 색 (지위)
```

### 5.2 논리 규칙

| 규칙 | 설명 |
|------|------|
| 판은 기능을 가장한 미학 | 실제 내부 구조와 1:1이 아니어도, **조립·고정·가동**처럼 보여야 함 |
| 큰 면은 비울 수 있다 | 여백 = 품격. 전부를 선으로 채우지 않음 |
| 여백 위의 선은 더 비싸야 한다 | 선이 적을수록 한 선의 단차·엣지가 중요 |
| 관절은 전환점 | 곡→각, 면→면이 바뀌는 곳. 뭉개지지 않음 |

---

## 6. 여백 문법 (Negative Space)

| 양산형 | FSS형 |
|--------|--------|
| 여백 = 미완성·저예산 | 여백 = **의도된 품격** |
| 면을 기능 파츠로 채움 | 큰 면을 남기고 엣지로 값을 올림 |

Excelion BRAVE의 Imperial 여백과 맞닿는 지점: **비운 면 + 고급 엣지**. 다만 BRAVE 여백은 “소녀의 몸/선택”이고, FSS 여백은 “기사의 갑옷”이다. 형식은 빌려도 의미는 섞지 않는다.

---

## 7. 디테일 위계 (Detail Hierarchy)

| 등급 | 요소 | 예산 |
|------|------|------|
| S | 실루엣 · 헤드 실루엣 | 절대 희생 금지 |
| A | 큰 면 분할 · 허리·어깨 볼륨 | 높게 |
| B | 패널 단차 · 엣지 | 로봇혼/센티넬 밀도 |
| C | 리벳·슬릿·벤트 | 규칙적·절제 |
| D | 문양·보조색 | 최소 · 실루엣 비파괴 |

**위계를 뒤집으면** (D를 S처럼 키우면) FSS가 아니라 데칼 기체·장식 기체가 된다.

---

## 8. 곡·각 문법 (요약 심화)

```
윤곽(곡)  →  품격·기동·사람다움
판(각)    →  금속·무기·단차
패널(곡을 따름) → “깎인 곡면” 증명
```

- 곡만 = 생물 / 각만 = 상자 병기
- FSS = **곡 위에 각을 올리고, 각 위에 패널을 판다**

---

## 9. 색 문법 (상징과의 연결)

| 층 | 색 역할 |
|----|---------|
| 주조 | 저채도 금속 = 몸·지위 바탕 |
| 엣지 하이라이트 | 조각임 증명 |
| 포인트 | 문장·코어·시선 = 유일성 |
| 금지 | 전신 고채도 · 형광 · 포인트가 실루엣을 먹음 |

색은 **마지막에 지위를 찍는 도장**이지, 형태를 대신하지 않는다.

---

## 10. 한 기체를 “FSS 언어”로 그리는 절차

1. **상징 한 줄** 정하기 (예: 위압적 유일 / 침묵하는 처리자 / 선택받은 몸)
2. **실루엣** — 멀리서 그 한 줄이 읽히게
3. **헤드** — 개성 슬롯 (Excelion에서는 TEXT-LOCK 우선)
4. **큰 면** — 여백과 덩어리
5. **곡 위 각** — 장갑 논리
6. **패널·엣지** — 로봇혼/센티넬 밀도
7. **색 포인트** — 지정 팔레트 안에서만
8. **검증** — 디테일이 실루엣을 깨면 되돌림

---

## 11. Excelion 적용 한도 (재확인)

| 빌릴 것 | 빌리지 말 것 |
|---------|--------------|
| 읽힘 순서 · 디테일 위계 | 기사 결투 세계관 |
| 곡 위 각 · 깎인 금속 | 특정 FSS 헤드/문장 |
| 여백=품격 · 포인트=지위 | ORD 유일화 |
| 절차(1→8) | TEXT-LOCK 실루엣·팔레트 변경 |

---

## 12. 금지 요약

- 디테일(D)이 실루엣(S)을 지배
- 헤드 카피 · 문장 카피
- 여백을 저예산으로 오해하고 선으로 채움
- 곡면 = 살, 각면 = 상자만 (문법 붕괴)
- “FSS 느낌”을 이유로 Excelion 금지 조항 무시
