## 1. 한 줄

FSS 스타일 = **기사·귀족의 예술품으로서의 메카**.  
양산 병기가 아니라, 전투하면서도 **아름답고·위엄 있으며·살아 있는 기계**로 읽히는 디자인.

---

## 2. 상징성 분석 (핵심)

FSS 메카(Mortar Headd)는 “거대한 무기”가 아니라 **상징의 집합**이다. 디자인은 그 상징을 형태·표면·색으로 드러낸다.

### 2.1 다섯 가지 상징 축

| 축 | 상징 | 형태·연출로 나타나는 방식 |
|----|------|---------------------------|
| **1. 기사** | 중세·르네상스 기사를 미래로 옮긴 존재 | 우아한 비율, 가면형 헤드, 갑옷 같은 패널, 퍼레이드와 전장을 모두 견딤 |
| **2. 예술품** | 살상용 도구이면서 미학적 완성체 | 고밀도 조각감, 문양, 고급 마감, “완성품 촬영” 수준의 피니시 |
| **3. 살아 있는 기계** | 순수 기계가 아니라 의지·품격이 있는 존재 | 유기+각의 곡면, 반투명·광윤, 생물 곡선이 아닌 **깎인 생명감** |
| **4. 지위·유일성** | 양산이 아닌 기사·가문·주문의 문장 | 기체마다 다른 헤드·색·장식, 군단 동일 도장과 대비 |
| **5. 결투** | 전쟁이 대량 살상이 아니라 기사 간의 결단에 가깝다는 세계관 | 단독 존재감, 위압적 실루엣, “한 기가 전황을 가른다”는 인상 |

### 2.2 상징이 디자인을 규정하는 방식

```
세계관(기사 사회)
    → 메카 = 기사의 연장·문장·자존
        → 디자인 목표 = 두렵고 + 아름답고 + 유일하다
            → 실루엣·표면·색·곡면이 모두 그 목표에 복무
```

- **양산 메카**의 상징: 소모, 규격, 기능, 숫자.
- **FSS 메카**의 상징: 이름, 주인, 품격, 결투.

그래서 FSS는 “예쁘게 그리는 것”이 아니라 **지위와 결투의 문법을 형태에 심는 것**이다.

### 2.3 대립 구조로 본 상징

| FSS가 거부하는 것 | FSS가 선택하는 것 |
|-------------------|-------------------|
| 소모품·숫자 | 유일·이름 있는 존재 |
| 순수 기능미 | 기능 + 미학의 동시 성립 |
| 생물 모방 | 생명감 있는 **금속 조각** |
| 군단 동일성 | 기사 개성 |
| 더러운 전장 풍화(기본) | 청결한 고급 상태(의식·퍼레이드 가능) |

### 2.4 Excelion과의 상징 구분 (중요)

Excelion의 메카는 FSS와 **세계관 상징이 다르다**. 참고는 가능하나 동일시하면 안 된다.

| | FSS | Excelion |
|--|-----|----------|
| 전쟁상 | 기사 결투·귀족 질서 | 생존·수성·광기·대가 |
| 주인공기 | 기사의 문장·자존 | **그 자리에 있던 아이**의 선택·집념 (BRAVE) |
| 적 상위기 | 대등한 기사·예술품 | **등급·위계** (아슈르) / **역할 수행** (세스) |
| 양산 | 거의 무대 밖 | ORD = 숫자·압박의 상징 |
| 가져올 상징 | 품격·유일성·조각감·위압의 **밀도** | — |
| 가져오면 안 되는 상징 | “우리는 귀족 결투를 한다”는 세계관 전체 | 리아·카이 서사와 충돌 |

**정리:** FSS 상징 중 **형태 언어**(품격·밀도·위압·유일감)만 빌리고, **사회 상징**(기사 질서·결투 미학 전체)은 Excelion에 이식하지 않는다.

## 3. 형태 언어 요약 (상징 → 디자인)

| 상징 | 실루엣 | 표면 | 색 |
|------|--------|------|-----|
| 기사 | 우아·긴 비율·가면 헤드 | 갑옷형 패널 | 저채도 금속 + 문장 포인트 |
| 예술품 | 과한 bulk 없음 | 고밀도·날카로운 엣지 | 주조 깊게, 포인트 비싸게 |
| 살아 있는 기계 | 곡+각 공존 | 깎인 곡면 위 패널 | 광윤·반투명 암시(선택) |
| 지위·유일 | 기체별 개성 | 장식은 절제하되 고급 | 양산 동일 도장 금지 |
| 결투·위압 | 단독 존재감 | 조각감 | 어두운 바탕 + 정확한 악센트 |

(표면·곡면·색 상세는 기존 항과 동일 방향.)

## 4. Excelion 기체별 적용 한도

| 기체 | FSS 상징에서 쓸 것 | 쓰지 말 것 |
|------|-------------------|------------|
| **BRAVE** | 품격 있는 금속·여백 속 밀도·“가치 있는 몸” | 기사 문장·귀족 자존으로 읽히게 만들기 |
| **엑셀리온** | 전개 = 생동·예술적 개방 | 별 기체의 귀족 교체 |
| **세스** | 침묵하는 권위·정제된 각 | 오만·문장·결투 미학 |
| **아슈르** | 위계·고요한 위압·유일감 | FSS 기사와 대등한 “결투 상대”로만 읽히게 하기 (아슈르는 등급 판정자) |
| **ORD** | 없음 (숫자의 상징 유지) | 유일·예술·귀족 상징 |

## 5. 금지

- FSS 세계관 전체(기사 사회·결투 문법)를 Excelion 스토리에 이식
- FSS 고유 헤드·문장·특정기 카피
- ORD에 유일·예술 상징 부여
- 상징을 이유로 TEXT-LOCK 실루엣·팔레트·금지 조항 무시
- “FSS니까 무조건 화려” → 화려함이 아니라 **지위와 밀도**
