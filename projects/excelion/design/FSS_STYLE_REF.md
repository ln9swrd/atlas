## 1. 한 줄

FSS 스타일 = **기사·귀족의 예술품으로서의 메카**.  
양산 병기가 아니라, 전투하면서도 **아름답고·위엄 있으며·살아 있는 기계**로 읽히는 디자인.

## 2. 핵심 특징 (구체)

### 2.1 실루엣 · 비율

| 축 | 내용 |
|----|------|
| 전체 | humanoid · **우아하고 긴** 인상 · 투박함보다 정제된 라인 |
| 머리 | 개성이 강한 헤드 디자인 (마스크·뿔·장식 헬멧). 얼굴면이 “가면”처럼 읽힘 |
| 목·상체 | 상대적으로 가늘거나 세련된 상체 · 어깨는 존재감 있으나 과한 bulk 지양 |
| 허리 | 한 단 들어간 라인 · 기동과 우아함을 동시에 |
| 다리 | 길고 날씬 · 접지감은 유지하되 “달리는 기사” 인상. 가끔 힐/포인트 풋 암시 |
| 손 | 정교한 매니퓰레이터 · 덩치로 실루엣을 깨지 않음 |

### 2.2 표면 · 디테일 밀도 (상세)

FSS 메카의 표면은 “그려 넣은 선”이 아니라 **주조·절삭·연마된 금속 조각**처럼 읽힌다.

#### 패널 라인

| 항목 | 내용 |
|------|------|
| 밀도 | **고밀도**. 면이 비어 보이지 않게, 그러나 선이 난잡하지 않음 |
| 성격 | 기능 분할 + 미적 분할이 동시에 존재. “기계 부품 경계”처럼 읽힘 |
| 깊이 | 얕은 홈이 아니라 **뚜렷한 단차·절개**로 보임 (로봇혼/센티넬급) |
| 방향 | 수직·수평·대각이 균형을 이룸. 한 방향으로만 흐르지 않음 |
| 금지 | 저밀도 카툰 라인 · 너무 가는 단일 선만으로 채우기 · 실루엣을 깨는 과다 교차 |

#### 엣지 · 모서리

| 항목 | 내용 |
|------|------|
| 기본 | **날카롭고 깨끗함**. 뭉개지거나 둥글게 뭉개진 인상 금지 |
| 혼용 | 큰 면은 약간의 곡률, 패널 경계·장갑 끝은 예리 |
| 읽힘 | “깎아 만든 금속” · 플라스틱 사출 느낌 지양 |

#### 리벳 · 패스너 · 미세 요소

- 리벳·볼트·핀이 **규칙적으로** 배치되어 공업적 설득력을 줌
- 과다 난립 금지 · “장식용 점”이 아니라 조립·고정 요소로 읽히게
- 센서 슬릿·벤트·미세 홈이 면 안에 자연스럽게 파임

#### 마감 · 재질 읽힘

| 요소 | 방향 |
|------|------|
| 기본 마감 | **매트 + 세미글로스 혼용**. 전체가 한 가지 광택이 아님 |
| 금속감 | 저채도 고급 금속 (티타늄·건메탈·다크스틸 계열) |
| 하이라이트 | 엣지·돌출부에만 얇고 정확한 하이라이트 · 페인터리 그라데이션 금지 |
| 질감 | “연마된 금속” · “도장된 장갑” · 가끔 반투명/적층 암시(고급기) |
| 금지 | 카툰 플랫 단색 · 과한 반사·렌즈플레어 · 녹·풍화 과다(기본 상태는 청결·고급) |

#### 장식 문양 (선택)

- 문장·선각·프레resco성 라인 가능
- **실루엣과 주요 패널을 방해하지 않는 범위**에서만
- Excelion 적용 시: BRAVE·아슈르는 절제, ORD는 거의 없음, 세스는 장식 최소 유지

#### 한 줄로 정리

> 고밀도 패널 + 날카로운 엣지 + 매트/세미글로스 금속 마감 = **조각된 기사 갑옷**  
> 선이 많아도 난잡하지 않고, 면이 있어도 비어 보이지 않음.

### 2.3 곡면 설계 (상세)

FSS 곡면의 핵심은 **“생물 곡선”이 아니라 “깎인 금속 곡선”**이다.

#### 원칙

| # | 원칙 |
|---|------|
| 1 | 곡선만 쓰면 생물체, 각만 쓰면 양산 병기 → **둘을 한 기체 안에 공존** |
| 2 | 곡선 위에도 패널 라인이 **따라간다** → “매끄러운 살”이 아니라 “깎인 곡면” |
| 3 | 큰 윤곽은 부드럽게, 그 위의 장갑·분할은 각지고 예리하게 |
| 4 | 곡선의 목적은 **우아함·기동감·품격**이지, 유기체 모방이 아님 |

#### 어디에 곡을 쓰는가

| 부위 | 곡면 역할 | 비고 |
|------|-----------|------|
| **헬멧·두부 윤곽** | 가면·두개골처럼 부드러운 큰 곡선 | 얼굴면·센서는 각·슬릿으로 대비 |
| **어깨** | 존재감 있는 둥근 볼륨 + 위 장갑 판은 각 | bulk 과다 금지 |
| **상완·전완** | 원통에 가까운 완만한 곡선 | 패널이 원주를 따라 흐름 |
| **흉부·복부** | 큰 면은 약한 곡률 또는 평면 | Imperial 여백과 충돌하지 않게 |
| **허리** | 한 단 들어가는 **S자·잘록** | 여성형·기동 실루엣의 핵심 |
| **허벅지·정강이** | 길고 날씬한 곡선 실루엣 | 위 장갑 판은 각·단차 |
| **무릎·관절** | 곡면 전환점 · 가동 암시 | 뭉개지지 않게 엣지 유지 |
| **발** | 접지 + 가끔 힐/포인트 암시 | 곡선으로 우아함, 접지면은 안정 |

#### 어떻게 깎는가 (설계 방법)

1. **1차 실루엣**: 부드러운 인체·기사 윤곽으로 잡는다.
2. **2차 장갑**: 그 위에 각진 판을 올린다. 판의 끝은 예리.
3. **3차 패널**: 곡선 면 위에 패널 라인을 **곡면을 따라** 판다. 선이 곡률을 강조하게.
4. **4차 엣지**: 판과 판이 만나는 곳, 곡이 끝나는 곳에 날카로운 단차.

결과: 멀리서는 우아한 곡선, 가까이서는 금속이 깎인 밀도가 보인다.

#### 곡면 위 패널 처리

| 올바른 처리 | 잘못된 처리 |
|-------------|--------------|
| 패널이 곡률을 따라 흐름 | 곡선 면을 무시하고 직선만 그림 |
| 단차가 곡면에서도 읽힘 | 선만 있고 깊이 없음 |
| 곡면이 “판의 집합”으로 보임 | 곡면이 매끈한 플라스틱/살처럼 보임 |
| 하이라이트가 엣지를 따라 끊김 | 곡면 전체에 부드러운 그라데이션만 |

#### 금지 (곡면)

- 전신을 부드러운 유기체 곡선으로만 처리 (생물화)
- 곡면 위에 패널·단차 없이 매끈하게만 둠
- 곡선을 이유로 엣지를 뭉앰
- 과도한 볼륨 곡선으로 실루엣 키워드(여백·길이·단정 등) 파괴
- ORD에 FSS식 우아 곡면 적용

#### 한 줄

> **큰 윤곽은 곡, 그 위의 장갑·패널은 각.**  
> 곡선은 우아함을 주고, 각과 단차는 금속임을 증명한다.

---

### 2.4 분위기 · 읽힘

| 읽힘 | 설명 |
|------|------|
| 기사 | 중세·르네상스 기사의 갑옷을 미래로 옮긴 인상 |
| 예술품 | 전장에서 위압적이면서 퍼레이드에서도 아름다움 |
| 살아 있는 기계 | 순수 무기보다 “의지와 품격이 있는 존재” |
| 귀족성 | 양산기와 확실히 구분되는 고급감·유일성 |

### 2.5 색 · 마감 (요약)

- 금속감 강함 (매트 + 세미글로스 혼용)
- 저채도 고급 금속 + 포인트 컬러 (금·은·냉색 악센트 등)
- 과도한 원색·카툰 채도 지양
- 표면이 “그려진 그림”이 아니라 “주조·연마된 금속”으로 읽히게

## 3. Excelion에 적용할 때 (중요)

FSS는 **참고 방향**이다. 기존 TEXT-LOCK을 덮어쓰지 않는다.

| 기체 | FSS 곡면·표면에서 가져올 것 | 가져오면 안 되는 것 |
|------|------------------------------|---------------------|
| **BRAVE** | 허리·다리의 우아한 곡선 + 여백 위 고급 패널 | 과한 볼륨·장식 곡선으로 여백 파괴 |
| **엑셀리온** | 광익·광윤과 어울리는 깎인 곡면 | 형태 자체를 FSS로 교체 |
| **세스** | 각진 본체 유지 · 엣지·패널만 고급화 | 우아 곡선으로 단정·차단 인상 약화 |
| **아슈르** | 긴 수직 면의 완만한 곡 + 위압적 금속감 | 손/무장 노출 · 생물형 곡선 |
| **ORD** | (거의 없음) 기능적 각·투박함 유지 | FSS 우아 곡면으로 양산감 상실 |

### 원칙

1. **실루엣 키워드 우선**
2. FSS는 **표면·곡면 품격·디테일 밀도**를 올리는 데 사용
3. “FSS 카피”가 아니라 “FSS급 완성도 + Excelion 고유 실루엣”
4. `DESIGN_QUALITY.md` (로봇혼/센티넬)와 방향 일치 → 채택 가능

## 4. 금지 (Excelion 기준)

- FSS 고유 헤드 장식(특정 뿔·가면)을 그대로 이식
- 장식 과다로 실루엣 키워드 파괴

- “FSS 스타일이니까”라며 TEXT-LOCK 비율·색·금지 조항 무시
- 저밀도·카툰화
- 패널을 “예쁜 선”으로만 그리고 단차·엣지 없이 처리
- 곡면 = 매끈한 살/플라스틱으로 처리
