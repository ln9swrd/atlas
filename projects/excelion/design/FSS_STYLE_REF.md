## 1. 한 줄

FSS 스타일 = **기사·귀족의 예술품으로서의 메카**.  
양산 병기가 아니라, 전투하면서도 **아름답고·위엄 있으며·살아 있는 기계**로 읽히는 디자인.

---

## 2. 핵심 특징 (구체)

### 2.1 실루엣 · 비율

| 축 | 내용 |
|----|------|
| 전체 | humanoid · **우아하고 긴** 인상 · 투박함보다 정제된 라인 |
| 머리 | 개성이 강한 헤드 디자인 (마스크·뿔·장식 헬멧). 얼굴면이 “가면”처럼 읽힘 |
| 목·상체 | 상대적으로 가늘거나 세련된 상체 · 어깨는 존재감 있으나 과한 bulk 지양 |
| 허리 | 한 단 들어간 라인 · 기동과 우아함을 동시에 |
| 다리 | 길고 날씬 · 접지감은 유지하되 “달리는 기사” 인상. 가끔 힐/포인트 풋 암시 |
| 손 | 정교한 매니퓰레이터 · 덩치로 실루엣을 깨지 않음 |

### 2.2 표면 · 디테일 밀도 (요약)

고밀도 패널 + 날카로운 엣지 + 매트/세미글로스 금속 마감 = **조각된 기사 갑옷**.  
(상세는 기존 패널·엣지·리벳·마감 항 유지)

### 2.3 곡면 설계 (요약)

**큰 윤곽은 곡, 그 위의 장갑·패널은 각.** 깎인 금속의 우아함.  
(상세는 기존 곡면 항 유지)

### 2.4 분위기 · 읽힘

| 읽힘 | 설명 |
|------|------|
| 기사 | 중세·르네상스 기사의 갑옷을 미래로 옮긴 인상 |
| 예술품 | 전장에서 위압적이면서 퍼레이드에서도 아름다움 |
| 살아 있는 기계 | 순수 무기보다 “의지와 품격이 있는 존재” |
| 귀족성 | 양산기와 확실히 구분되는 고급감·유일성 |

---

### 2.5 색채 심리학 (상세)

FSS에서 색은 **기능 식별**보다 **지위·위압·아름다움**을 전달한다.  
양산기의 “부대색”이 아니라, 기사 개인·가문·주문의 **문장색**에 가깝다.

#### 색이 하는 일

| 역할 | 설명 |
|------|------|
| **지위** | 고급 금속·금·은·깊은 흑 = 귀족·기사. 값싼 원색·형광 = 지양 |
| **위압** | 전장에서 “두려운 존재”로 읽히게. 어두운 바탕 + 날카로운 포인트 |
| **아름다움** | 퍼레이드·의식에서도 견딜 미학. 전투기이면서 예술품 |
| **개성** | 기체마다 다른 색 구성 = 유일성. 양산 동일 도장과 대비 |
| **생동** | 반투명·광윤·금속 하이라이트로 “살아 있는 기계” 암시 |

#### 색 계열과 심리 효과

| 계열 | 심리·읽힘 | FSS에서의 쓰임 |
|------|-----------|----------------|
| **깊은 흑·남흑** | 권위·침묵·위압·고급 | 흑기사·고위 기체. 가벼워 보이지 않음 |
| **금·황동·호박** | 귀족·신성·가치·시선 집중 | 문장·코어·포인트. 과다 시 천박 |
| **은·회백·티타늄** | 정제·차가움·기사 갑옷 | 주조색. 청결·연마된 인상 |
| **적·주홍** | 혈·위엄·경고·생동 | 포인트·문양. 전신 적 = 강렬하나 절제 필요 |
| **냉청·남** | 거리·고요·위계 | 원격·고위 인상. 아슈르 계열과 맞닿음 |
| **백·아이보리** | 순수·의식·대비 | 하이라이트·특수기. 오염 없이 고급으로 |
| **반투명·적층** | 생명·내부 구조·고급 기술 | 최상위기. “속이 비치는” 예술성 |

#### 채도·명도 원칙

| 원칙 | 내용 |
|------|------|
| 저채도 주조 | 본체는 채도를 낮춰 **금속·품격**을 유지 |
| 고채도 포인트 | 코어·문장·시선만 강하게. 전신 고채도 금지 |
| 명암 대비 | 어두운 면 + 밝은 엣지/포인트 = 조각감·위압 |
| 동일 톤 남발 금지 | 전체가 한 톤이면 양산·평면적으로 읽힘 |

#### 금지 (색)

- 카툰 원색 전면 도장
- 형광·네온으로 “싸구려 강렬함”
- 녹·풍화·더러운 전면 (기본은 청결한 고급 상태)
- 아군 식별용 호박 accent를 적 기체에 남발 (Excelion 규칙)
- 색만으로 실루엣·성격을 대체 (몸이 먼저)

#### 한 줄

> 색 = **지위를 입힌 금속**.  
> 주조는 낮고 깊게, 포인트는 정확하고 비싸게.

---

## 3. Excelion에 적용할 때 (중요)

FSS는 **참고 방향**이다. 기존 TEXT-LOCK 팔레트를 덮어쓰지 않는다.

| 기체 | FSS 색 심리에서 가져올 것 | 가져오면 안 되는 것 |
|------|---------------------------|---------------------|
| **BRAVE** | 회백·남회의 **정제된 고급감** + accent `#E8A020`의 “가치 포인트” | 전신 금·과한 문장색 |
| **엑셀리온** | accent 면적 증가 = 생동·전개. 반투명·광윤 암시 가능 | 팔레트 교체 |
| **세스** | 저채도 청회·흑회 = **침묵·처리**의 권위 | 금·적 포인트로 오만 연출 |
| **아슈르** | 깊은 흑·남 + 냉백 = **위계·원격·고요한 비쌈** | 적열·광기 원색 |
| **ORD** | 저채도 군단색 유지 | FSS식 금·반투명·개성 도장 |

### 원칙

1. **지정 팔레트 우선** (FRAME_SPEC · 각 MECHA_SPEC)
2. FSS는 **채도·명암·포인트 배치의 품격**을 올리는 데 사용
3. 색이 실루엣·금지 조항을 이기지 않음
4. `DESIGN_QUALITY.md`와 함께: 색도 “완성품 금속”으로 읽히게

---

## 4. 금지 (Excelion 기준) — 색 포함

- FSS 고유 헤드 장식 이식
- 장식·색 과다로 실루엣 키워드 파괴
- ORD에 FSS 고급 색·반투명 부여
- TEXT-LOCK 비율·색·금지 무시
- 저밀도·카툰 원색·형광
- 곡면 = 매끈한 살, 색 = 평면 도장만
