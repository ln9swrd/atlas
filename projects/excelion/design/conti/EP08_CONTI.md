### P01 · 2초
- **앵글:** 거점 와이드 · 압박
- **화면:** 수성 전선. 적이 밀어붙임. 지구 무드.
- **인물/기체:** BRAVE · ORD 잡/중
- **SFX:** 포격·기동 소음

### P02 · 2초
- **앵글:** 조종석 손
- **화면:** 경련. 코피 한 방울 가능. 광기 2→3 경계.
- **인물:** 리아 손
- **광기:** 3 진입 직전
- **대사:** 카이「과부하 직전이다. 내려—」 / 리아「안 돼.」

### P03 · 2초
- **앵글:** 시야 POV
- **화면:** 가장자리 균열 확대. 통신 유지 중인 카이 이름 표시.
- **광기:** 3 시야
- **인물:** 카이는 통신만 (옆·지탱)

### P04 · 3초 ★핵심
- **앵글:** 손 → 전면 공백
- **화면:** 손 **멈춤**. 조종 입력 없음. 시간감 ~3초. 치명 궤적이 BRAVE로 들어옴.
- **광기:** 3 **과부하 공백 (이 화만)**
- **SFX:** 통신·효과음이 한 박 비는 느낌

### P05 · 2초 ★핵심
- **앵글:** 외부 · 카이 측이 메움
- **화면:** 카이(또는 카이 측 유닛/엄호)가 궤적을 막음 → 피격. 리아 주연 센터를 카이가 뺏지 않게 · **메우는 동작**만.
- **대사:** 카이「끝나면 내려.」(H3)
- **인물:** 카이 = 동료 희생 · 라이벌 연출 금지

### P06 · 2초
- **앵글:** 통신 끊김 · 파형 사망
- **화면:** 빈 채널. 이름 소등. 잔상 0.5초 가능(습관 동작 · 설명 없음).
- **광기:** 3 잔상 씨앗
- **SFX:** 정적

### P07 · 2초
- **앵글:** 리아 손
- **화면:** 멈췄던 손이 **꽉 쥠**. 집념 재점화. 슬로건 제스처 금지.
- **대사:** 리아「…헛되게 안 해.」
- **광기:** 3 손 멈춤→쥠

### P08 · 2초
- **앵글:** UI + 전선
- **화면:** 거점 목표 **일부 클리어** 표시 가능. 스토리 레이어는 상실.
- **UI:** (선택) 거점 — 부분 달성
- **규칙:** 게임 클리어 연출과 카이 죽음을 한 칸에 섞어 축하하지 않음

### P09 · 2–3초
- **앵글:** 조종석 · 전방
- **화면:** 침묵. 빈 주파수. 시선 전방. 말 거의 없음.
- **인물:** 리아만
- **대사/내레이션:** 「그 죽음을 헛되게 하지 않겠다.」
