# Exelion Project Summary

> 최종 업데이트: 2026-07-21

---

# 프로젝트 목표
- 오리지널 메카 세계관 구축
- 슈퍼로봇과 리얼로봇의 장점을 결합한 디자인
- 3D 프린팅과 게임 제작을 동시에 고려한 설계
- 파라메트릭 모델링을 활용하여 다양한 기체를 빠르게 제작

---

# 디자인 방향

## 장르
- 모던 슈퍼로봇
- SF + 생체기계(Biomechanical)
- 일본 슈퍼로봇 감성과 현대적인 메카닉 디자인의 융합

## 기본 특징

- 약 25m급 메카
- 유선 중심
- 초기형은 단순
- 성장하면서 장식 증가

---

# 핵심 철학

> AI가 게임을 만드는 것이 아니라,
> 개발자가 더 좋은 게임을 만들도록 AI가 반복 작업을 대신한다.

Exelion은

'1인 개발 + AI'를 통해
상업적으로 성공 가능한 오리지널 게임 IP를 구축하는 것을 목표로 한다.

# 개발 방향

## 장르

Mission Based 3D Action RPG

초기 Tower Defense에서 방향을 변경하였다.

### 핵심 플레이

- 거점 공략
- 다수의 적 섬멸
- 거대 보스전
- 성장 시스템
- 스킬 활용
- 미션 선택형 진행

---

# 개발 원칙
