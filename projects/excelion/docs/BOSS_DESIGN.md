# BOSS_DESIGN — 프로토타입 패턴 규칙

## 패턴 타입

| type | 체감 |
|------|------|
| normal | 표준 경고→돌진 |
| fast | 짧은 텔레그래프 |
| delay | 긴 예고 후 돌진 |
| fake | 페인트→취소→실제 |
| combo | 연속 n회 |
| redirect | 벽 후 재조준 |

## 3페이즈

`phaseThresholds` 예: `[1.0, 0.66, 0.33]`

- P1 학습 · P2 왜곡 · P3 압박/혼합

## 로스터 체감

| 보스 | 축 |
|------|-----|
| MONTU | 압박·연타 |
| SETH | 페익·딜레이·판단 |
| NEMESIS | 리다이렉트·혼합·최종 벽 |

## 금지

- HP%만으로 난이도 올리기
- 텔레그래프 없는 즉사
- Ashur 설정 복구 (파일 id만 레거시)
