# PROJECT_RELATION — Atlas ↔ Excelion

> 2026-08-09

---

## 구조

```
Atlas (DevOS / 프레임워크·철학)
 └─ Excelion (실제 게임 제품 SoR)
```

| | Atlas | Excelion |
|--|--------|----------|
| 역할 | 시스템 정의 · 프로세스 · 멀티 프로젝트 틀 | **메카 IP 게임 구현** |
| 경로 | 레포 루트 · 공통 규칙 | `projects/excelion/` |
| 산출 | 워크플로 · 리뷰 · 자동화 철학 | 스토리·전투·에셋·플레이 빌드 |

---

## Excelion 역할

- 실제 구현 · 플레이 가능 상태
- SoR = `projects/excelion/` 만
- Atlas 규칙을 따르되, **재미·플레이**가 제품 성공 기준

---

## Atlas 역할

- 개발 OS · 병목 감소
- Excelion은 Atlas의 **검증 프로젝트** (`PROJECT_CHARTER`)

---

## 한 줄

Atlas가 게임을 만드는 것이 아니라, **Excelion을 플레이 가능하게 만드는 것**이 현재 목표다.
