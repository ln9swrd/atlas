## 한 줄

16세 **리아**가 BRAVE와 공명으로 묶인 뒤 수성·공성을 거치며 광기를 무기로 삼고, **카이**의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 차원 게이트를 닫아 **시간을 번다**.

---

## 몰입 원칙

| 원칙 | 실천 |
|------|------|
| **첫 30초** | 리아의 몸 + 이번 화 목표 |
| **공감** | “나라면 저렇게 했을 것 같다” |
| **애착** | 카이를 EP1부터 아끼게 |
| **대가** | 이길수록 “뭘 잃었지?” |
| **상실** | EP8 카이 = Point of No Return |
| **돌파** | 아슈르를 꺾는 것이 감정 폭발 |
| **이름** | 조연은 부른다 (카이·유나·레이) |
| **외부 체감** | 매 화 끝 새로 쓸 수 있게 된 것 1줄 |

### 금지

- 개막 신화 강의 · 리아 없이 본부만 · 설정 폭주
- 카이=라이벌 · 아슈르 주인공화
- “게이트 용량 때문에”를 전면 설명 (배경만)
- “S-Core가 반응했다” (→ **리아가 끌어냈다**)

### 매 화 체크

1. 첫 30초: 몸 + 목표?
2. 끝: 성장 1단 + 외부 체감?
3. 가져갈 한 문장?
4. 조연 이름 불렸나?

## 서사 원칙

| 원칙 | 내용 |
|------|------|
| 주인공 = 리아 | 카메라 우선 |
| 톤 | **열혈 + 광기** |
| 성장 | 광기 거부→수용→무기→경계 너머 |
| BRAVE | 같은 모습 · EP13만 엑셀리온 진화 |
| 카이 | 동료 · EP8 희생 |
| 아슈르 | 격이 다른 최종 보스 · 오만 |
| 엔딩 | 시간 벌기 · 리아는 EP1의 아이가 아님 |

### 3막

```
EP1–4   거부 → 징후          광기를 두려워하며 싸운다
EP5–8   수용 직전 → 상실     대가 · 카이 죽음 (전환점)
EP9–13  무기 → 경계 너머     아슈르 결판 · 게이트 · 진화
```

## Season 1 — 13 Episodes

### EP1. 동기화

| | |
|--|--|
| 관객 질문 | **오늘, 이 거리는 빠져나갈 수 있나?** |
| 성장 | 민간인 → 살아남은 몸 · 첫 광기 반응 |
| 외부 체감 | BRAVE 첫 기동 |
| 앵커 | **카이**가 말리지만 리아 거부 |

**가져갈 문장:** 세계가 끝났는데, 나는 아직 여기 있다.

### EP2. 잔향

| | |
|--|--|

| 외부 체감 | S-Core 첫 열기 · 후유증 |

### EP3. 각성의 대가

| | |
|--|--|
| 관객 질문 | **이 전선에서 몇 명을 데려올 수 있나?** |
| 성장 | 한계까지 · “멈출 수 없다” |
| 외부 체감 | 부작용 · 열혈+광기 동시 |
| 앵커 | 카이·유나가 말려도 안 멈춤 |

**가져갈 문장:** 살렸는데도, 눈은 이미 꺼져 있었다.

### EP4. 남겨진 것

| | |
|--|--|

**가져갈 문장:** 선택받지 않아도, 내리지 않기로 했다.

### EP5. 균열

| | |
|--|--|
| 관객 질문 | **이 요새를 빼앗을 수 있나?** |
| 성장 | 부수는 손의 무게 · 의식 상실 후 재탑승 |
| 외부 체감 | 중보스 · **레이** 갈등 정점 |
| 앵커 | 카이 부상 · 이후 지휘부 갈등 반복 없음 |

**가져갈 문장:** 지키는 손이 곧 부수는 손이었다.

---

### EP6. 달의 그림자

| | |

| 앵커 | 아슈르가 리아를 “변수”로 인식 |

**가져갈 문장:** 승리가 쌓여도 전망은 없었다.

---

### EP7. 광기의 문턱

| | |
|--|--|
| 관객 질문 | **이 거점을 사수할 수 있나?** |
| 성장 | 자아 경계 흐려짐 |
| 외부 체감 | S-Core 본격 · 자비 없는 전투 |
| 앵커 | 유나: “너는 이미 경계를 넘었다” · 카이 공포 |

**가져갈 문장:** 무너질 뻔했고, 그래도 탔다.

---

### EP8. 선택의 무게 — **중간 전환점**

| | |
|--|--|
| 관객 질문 | **카이를 지킬 수 있나?** |
| 성장 | 이분법 붕괴 · **돌이킬 수 없음** |
| 외부 체감 | **카이 죽음** · 리아 직접 목격 |
| 앵커 | 엔키 메시지 · 진화 매개체 직감 |

**구조**
1. 기록 조각. 강의 금지.
2. 전투. 카이가 리아를 구하다 죽음.
3. 리아가 본다. 통신이 끊긴다.

**가져갈 문장:** 같아도, 다시 싸우기로 했다. (그 죽음을 헛되게 하지 않겠다)

### EP10. 달 뒷면

| | |

### EP12. 게이트 앞에서

### EP13. 파괴

| | |
|--|--|

| 외부 체감 | **엑셀리온 진화 완성** · 아슈르 패배 · 게이트 붕괴 |

리아는 더 이상 EP1의 아이가 아니다. 시간 벌기. S2 암시.
