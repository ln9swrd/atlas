# 09_STORY_S1 — 시즌1 스토리 (13화 = 13 스테이지)

> **중심**: **리아의 서사** · 열혈 + 광기 · 관객 몰입  
> **형식**: TV 13화 · 각 화 = 게임 1스테이지  
> Updated: 2026-08-06 · **P1** 카이 애착 · EP8 전투 논리 · 리아만 타는 이유

---

## 한 줄

16세 **리아**가 BRAVE와 공명으로 묶인 뒤 수성·공성을 거치며 광기를 무기로 삼고, **카이**의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 차원 게이트를 닫아 **시간을 번다**.

---

## 몰입 원칙

| 원칙 | 실천 |
|------|------|
| **첫 30초** | 리아의 몸 + 이번 화 목표 |
| **공감** | “나라면 저렇게 했을 것 같다” |
| **애착** | 카이 EP1–7 애착 장면 (아래 EP별) |
| **대가** | 이길수록 “뭘 잃었지?” |
| **상실** | EP8 카이 = Point of No Return |
| **돌파** | 아슈르를 꺾는 감정 폭발 |
| **이름** | 카이·유나·레이 부름 |
| **외부 체감** | 매 화 끝 1줄 |

### 금지

- 개막 신화 강의 · 카이=라이벌 · 아슈르 주인공화
- “게이트 용량 때문에” 전면 설명 · “S-Core가 반응했다”
- 카이 죽음을 **우연한 피격**으로 처리 (과부하 3초 논리 필수)

### 매 화 체크

1. 첫 30초: 몸 + 목표?
2. 끝: 성장 + 외부 체감?
3. 가져갈 한 문장?
4. 카이 등장 화면 **애착 비트** 있는가? (EP1–7)

### EP8. 선택의 무게 — **중간 전환점**

| | |
|--|--|
| 관객 질문 | **카이를 지킬 수 있나?** |
| 성장 | **돌이킬 수 없음** |
| 외부 체감 | **카이 죽음** · 리아 직접 목격 |

**전투 논리 (필수)**
1. 기록 조각 · 강의 금지 · 진화 매개체 직감
2. 전투 중 리아 **광기 과부하** → 조종 입력 붕괴 **약 3초**
3. 그 빈 틈으로 치명 궤적
4. **카이가 궤적을 메움** → 피격
5. **직전**: 카이 대사 1개 (살 것 같은 호흡, 예: “끝나면 내려”) → 바로 죽음
6. 리아 시야 · 통신 끊김

**가져갈 문장:** 그 죽음을 헛되게 하지 않겠다.
