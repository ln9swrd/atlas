> **중심**: **리아의 서사** · 회마다 **성장** · 관객이 **쉽게 몰입**  
> **형식**: TV 13화 · 각 화 = 게임 1스테이지  
> 설정 SoR: `03_WORLD` · `01_CHARACTER` · `04_MISSION` · `05_ENEMY` · `08_PLAY_BRAVE`

## 한 줄

16세 **리아**가 이미 점령당한 지구에서 BRAVE와 공명으로 묶인 뒤, 수성(守城)과 공성(攻城)을 거치며 커지고, 달 뒷면에서 게이트 워든과 혈투한 뒤 차원 게이트를 닫아 **시간을 번다**.

---

## 몰입 원칙 (관객용 · 확정)

보는 사람이 **설명 없이** 따라올 수 있어야 한다. 설정이 앞서면 몰입이 끊긴다.

| 원칙 | 실천 |
|------|------|
| **리아의 감정 = 입구** | 매 화 첫 구간은 설정이 아니라 리아의 상태(공포·배고픔·떨림·침묵) |
| **한 화 한 질문** | 관객이 들고 갈 질문 하나 |
| **보여 주고 말하지 말 것** | 한 뿌리·엔릴은 강의 금지. 잔해·통증·공명으로만 |
| **인과가 손 안에** | A가 깨지면 B가 위험. 본부 용어 남발 금지 |
| **매 화 작은 완결** | 큰 전쟁 전에 「오늘 이 거점 / 이 사람 / 이 선택」이 닫힌다 |
| **게임과 같은 호흡** | 컷신 길게 안 끌기. 전투가 감정 클라이맥스에 붙음 |
| **이름보다 관계** | 조연은 「리아에게 뭐가 되나」로만 등장 |

### 몰입이 깨지는 것 (금지)

- 개막 세계관 나레이션 장문
- 리아 없이 본부 회의만 이어지는 구간
- 한 화에 설정 폭주 (한 뿌리+달+게이트를 동시에 설명)
- 성장 없는 「이번 화도 그냥 싸움」
- 관객이 리아보다 적을 더 이해하게 만드는 대사 과잉

### 매 화 체크 (작성·윤문 시)

1. 이 화 시작, 리아는 **무엇을 느끼는가?**
2. 이 화 끝, 리아는 **무엇이 달라졌는가?** (성장 1단)
3. 관객이 집에 가져갈 **한 문장**은 무엇인가?

## 세계·진행 (무대 요약)

- 개막: 지구 **여러 곳 이미 점령**. 침공 ≈ BRAVE **공명 각성**.
- 진행: **수성(방어)** 비중이 먼저 → **공성(탈환)** 교차 → 달.
- 조력: 지구 대응 세력 필수. 주인공은 되지 않음.
- 진실 곡선: 어떻게(경로·게이트) → 왜(멸절·엔릴 후손) → 한 뿌리(중후반).
- 피날레: **보스 혈투 → 게이트 파괴 → 시간 벌기** (완전 승리 아님).
- 적·BRAVE = **한 뿌리** (영생·영혼 계통). S-Core = 겟타선형 체감.

### 용어

| 수성 守城 | 아군 거점 사수·방어 (행성 아님) |
| 공성 攻城 | 적 거점 공격·탈환 |

## Season 1 — 13 Episodes

각 화: **관객 질문** = 몰입 훅 · **성장** = 리아 변화 · **스테이지** = 플레이 목표.

---

### EP1. 하늘이 갈라진 날

| | |
|--|--|
| 맵 | 1 · 일상 구역 → 붕괴 거리 |
| 관객 질문 | **이 아이는 살아남을까?** |
| 성장 | 민간인 → **살아남은 몸** |
| 타입 | 생존 · 기동 · 탈출 |

설명 없이 일상이 깨진다. 리아의 숨·발소리·먼지가 먼저. 침공 파동과 함께 BRAVE가 **공명**으로 기동한다. 선택받은 의식이 아니라 **그 자리에 있던 아이**. 첫 전투는 서툴고, 이기는 연출보다 도망쳐 살아남는 연출이 크다.

> 「파일럿 확인…」 / 「동조율 — 임계.」

**가져갈 문장:** 세계가 끝났는데, 나는 아직 여기 있다.

---

### EP2. 마지막 거점

| | |
|--|--|
| 맵 | 2 · **수성** |
| 관객 질문 | **오늘 밤 이 지붕을 지킬 수 있을까?** |
| 성장 | 도망 → **등 뒤를 지키는 손** |
| 타입 | 거점 사수 · 웨이브 · 지휘관형 적 |

본부는 짧게. 리아가 선다. 동료는 직책 나열이 아니라 등 뒤의 목소리로만. S-Core가 처음 뜨거워진다. 「지키는 밤」이 시즌1 초반의 호흡.

**가져갈 문장:** 누군가를 뒤에 두고 섰다.

---

### EP3. 폐허의 도시

| | |
|--|--|
| 맵 | 3 · 점령·폐허 시가지 |
| 관객 질문 | **구해도 고마워하지 않는 사람들을 어떻게 하지?** |
| 성장 | 이기면 끝 → **구하지 못하는 눈** |
| 타입 | 확보 · 구조 · 물량 웨이브 |

잠든 듯한 물량. 일부만 구출된다. BRAVE Project·엔키 흔적은 **스치기만**. 강의 없음. 리아의 시선이 꺼진 눈에 머문다.

**가져갈 문장:** 살렸는데도, 눈은 이미 꺼져 있었다.

---

### EP4. 잃어버린 연구소

| | |
|--|--|
| 맵 | 4 · 지하·연구소 잔해 |
| 관객 질문 | **이 기체는 도대체 누구 것인가?** |
| 성장 | 「왜 나」 → **우연을 짊어짐** |
| 타입 | 데이터 회수 · 탈출 · 자폭 시계 |

기록은 짧게, 자폭 시계가 더 크게. 「공명한다」 한 줄이면 충분. 달 쪽 이상 신호는 **느낌만**. 내리지 않기로 하는 선택이 성장.

**가져갈 문장:** 선택받지 않아도, 내리지 않기로 했다.

---

### EP5. 붉은 사막

| | |
|--|--|
| 맵 | 5 · **공성** · 요새 |
| 관객 질문 | **이겨도 왜 이렇게 씁쓸하지?** |
| 성장 | 지키면 선 → **부수는 손의 무게** |
| 타입 | 요새 돌파 · **중보스 1** |

첫 본격 공성. 보스전은 손으로 느끼게. 승리 후 시체와 침묵이 대사보다 길다. 수성만 하던 손이 공성의 손을 알게 된다.

**가져갈 문장:** 지키는 손이 곧 부수는 손이었다.

---

### EP6. 바다 위의 요새

| | |
|--|--|
| 맵 | 6 · 해상·플랫폼 |
| 관객 질문 | **이기는데 왜 끝이 안 보이지?** |
| 성장 | 단기 승리 → **끝 없는 전쟁을 봄** |
| 타입 | 플랫폼 제압 · 증원 억제 |

부숴도 증원이 온다. 리아의 한 마디 「이기고 있는 거 맞아?」가 설정 설명 대신. 「어떻게」 침공하는가의 단서가 달 쪽으로 기운다.

**가져갈 문장:** 승리가 쌓여도 전망은 없었다.

---

### EP7. 검은 기사

| | |
|--|--|
| 맵 | 7 · **수성** · 거점 |
| 관객 질문 | **저 말이 틀렸다고 어떻게 말하지?** |
| 성장 | 적=물량 → **말에 흔들리고 버팀** |
| 타입 | **엘리트** · 거점 사수 |

엘리트 대사 최소. 리아의 침묵·호흡이 더 길다. 밤에 통신을 끄는 장면이 클라이맥스. 「한 뿌리」 직전 감정 준비.

**가져갈 문장:** 무너질 뻔했고, 그래도 탔다.

---

### EP8. 오래된 기록

| | |
|--|--|
| 맵 | 8 · 아카이브·유적 |
| 관객 질문 | **나와 적이 같은 뿌리라면?** |
| 성장 | 이분법 → **한 뿌리 위 재선택** |
| 타입 | 탐색 · 방어 이탈 · 회수 |

조각만. 도표·강의 금지. 엔릴 후손 / 엔키 / BRAVE. 리아의 구역질·손이 핵심. 「문을 닫아야 한다」는 필요해서 나온다.

**가져갈 문장:** 같아도, 다시 싸우기로 했다.

---

### EP9. 하늘을 향하여

| | |
|--|--|
| 맵 | 9 · 궤도·항로 거점 |
| 관객 질문 | **이 희생이 길을 열까?** |
| 성장 | 나만 → **공동의 대가** |
| 타입 | 궤도 돌파 · 호위·손실 |

이름 없는 손실 목록. 리아의 고개가 설명 대신. 달 출격이 **합의**된다. 혼자서는 못 간다.

**가져갈 문장:** 혼자서는 달까지 못 간다.

---

### EP10. 달

| | |
|--|--|
| 맵 | 10 · 달 표면 거점 |
| 관객 질문 | **왜 하필 이 아이였을까?** |
| 성장 | 수동 동조 → **능동 파일럿** |
| 타입 | 달 거점 확보 · 저중력 |

지형과 기체가 겹치는 **이미지**로. 장문 기록 X. 「우연이 아니어도, 내가 타겠다.」

**가져갈 문장:** 우연이 아니어도, 내가 타겠다.

---

### EP11. 달의 뒷면

| | |
|--|--|
| 맵 | 11 · 달 뒷면 · 생산/병소 |
| 관객 질문 | **저 문이 모든 적의 입구인가?** |
| 성장 | 막연함 → **닫을 문이 선명** |
| 타입 | 생산 노드 파괴 · 접근 |

차원 게이트와 병소를 **보게** 한다. 토하고 헬멧. 대사 한마디면 됨. 「여기서 끝내자.」

**가져갈 문장:** 여기서 끝내자.

---

### EP12. 최후의 동조

| | |
|--|--|
| 맵 | 12 · 게이트 앞 |
| 관객 질문 | **리아가 그 힘을 감당할 수 있나?** |
| 성장 | 힘에 실려 감 → **힘과 함께 선다** |
| 타입 | **게이트 워든 혈투** (페이즈) |

막판 보스. 밀리고, 붙잡고, 호흡. 신화 이름보다 **지금 이 조종석**. S-Core·완전 전개 직전. 게이트는 아직 안 부순다 — **보스가 먼저**.

**가져갈 문장:** 끌려가지 않고, 붙잡았다.

---

### EP13. 시간을 벌다

| | |
|--|--|
| 맵 | 13 · 게이트 |
| 관객 질문 | **이기지 못해도 의미 있는가?** |
| 성장 | 이기고 싶다 → **포기하지 않는 사람** |
| 타입 | 워든 종결 · **게이트 파괴** · 엔딩 |

워든 격파 후 게이트 약점. 짧은 일격(초필 후보). 너머의 그림자(S2 떡밥). 리아의 잔열.

> 「우리는 세상을 구하지 못했다.」  
> 「하지만… 미래를 포기하지도 않았다.」

**가져갈 문장:** 시간을 벌었다. (그리고 리아는 EP1의 아이가 아니다.)
