## 한 줄

16세 **리아**가 무너진 세계에서 BRAVE와 묶인 뒤, 수성(守城)과 공성(攻城)을 거치며 커지고, 달 뒷면 게이트를 닫아 시간을 번다.

## 몰입 원칙 (관객용 · 확정)

| 원칙 | 실천 |
|------|------|
| **리아의 감정 = 입구** | 매 화 첫 5분은 설정이 아니라 리아의 상태 |
| **한 화 한 질문** | 관객이 들고 갈 질문 하나 |
| **보여 주고 말하지 말 것** | 한 뿌리·엔릴은 강의 금지 |
| **매 화 작은 완결** | 오늘 이 거점 / 이 선택 |
| **게임과 같은 호흡** | 플레이가 감정 클라이맥스에 붙음 |

### 매 화 체크

1. 시작, 리아는 **무엇을 느끼는가?**  
2. 끝, 리아는 **무엇이 달라졌는가?**  
3. 관객이 가져갈 **한 문장**은?
