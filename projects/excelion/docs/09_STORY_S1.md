## 한 줄

16세 **리아**가 이미 점령당한 지구에서 BRAVE와 공명으로 묶인 뒤, 수성(守城)과 공성(攻城)을 거치며 커지고, 달 뒷면에서 게이트 워든과 혈투한 뒤 차원 게이트를 닫아 **시간을 번다**.

---

## 몰입 원칙 (관객용 · 확정)

보는 사람이 **설명 없이** 따라올 수 있어야 한다. 설정이 앞서면 몰입이 끊긴다.

| 원칙 | 실천 |
|------|------|
| **첫 30초** | 리아의 몸(숨·손·시선) + **이번 화 목표**가 동시에 보임 |
| **입구 = 감정 + 목표 + 대결** | 설정 나레이션으로 시작하지 않음 |
| **한 화 한 질문** | 관객이 들고 갈 **목표/승패 질문** 하나 |
| **보여 주고 말하지 말 것** | 한 뿌리·엔릴은 강의 금지. 잔해·통증·공명으로만 |
| **이름이 붙으면 감정도 붙는다** | 동료는 가칭이라도 **부른다** (노아·진·유나) |
| **인과가 손 안에** | A가 깨지면 B가 위험. 본부 용어 남발 금지 |
| **매 화 작은 완결** | 「오늘 이 거점 / 이 사람 / 이 선택」이 닫힌다 |
| **게임과 같은 호흡** | 컷신 길게 안 끌기. 전투 = 감정 클라이맥스 |
| **외부 체감** | 매 화 끝 「새로 쓸 수 있게 된 것」 1줄 |

### 몰입이 깨지는 것 (금지)

- 개막 세계관 나레이션 장문
- 리아 없이 본부 회의만 이어지는 구간
- 한 화에 설정 폭주
- 성장 없는 「이번 화도 그냥 싸움」
- 관객이 리아보다 적을 더 이해하게 만드는 대사 과잉
- 카이 주인공화 · 리아 없이 카이 시점 롱컷
- 조연을 직책으로만 호칭 (이름 없이 “통신 담당”) 

### 매 화 체크 (작성·윤문 시)

1. **첫 30초**: 리아의 몸 + 이번 화 목표가 보이는가?
2. 이 화 끝, 리아는 **무엇이 달라졌는가?** (성장 1단 + 외부 체감)
3. 관객이 집에 가져갈 **한 문장**은 무엇인가?
4. 조연이 나왔다면 **이름이 한 번이라도** 불렸는가?

## 세계·진행 (무대 요약)

- 개막: 지구 **여러 곳 이미 점령**. 침공 ≈ BRAVE **공명 각성**.
- 진행: **수성** 먼저 → **공성** 교차 → 달.
- 조력: 노아·진·유나 · 지휘관(레이) — 주인공 되지 않음.
- 피날레: **보스 혈투 → 게이트 파괴 → 시간 벌기**.
- 적·BRAVE = **한 뿌리**. S-Core = 겟타선형 체감.

| 공성 攻城 | 적 거점 공격·탈환 |
