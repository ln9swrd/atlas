## 1. 목표

5~10분 내외의 **실제 플레이 가능한 전투 데모**.

“재미있는가”를 최소 비용으로 검증.

## 3. 기존 잠금과의 관계

- EP1 / EP6 / EP8 목표·페이즈·클리어 조건은 `state/VERTICAL_SLICE_EP1_6_8.md` 기준.
- Unreal VS는 위 문서의 **전투 루프·수치 앵커**를 재사용한다.
- 충돌 시 **기존 설정 우선**.

---

## 4. 성공 기준 (제안)

- 접근→콤보→밀기→필살 루프가 막힘 없이 돌아간다.
- 히트·회피·필살 피드백이 즉각적이다.
- 보스 1 Phase 이상 학습 가능하다.
- 5~10분 안에 클리어 또는 의도된 실패를 경험한다.

- 엑셀리온 진화
- 풀 시네마틱
- 세이브 슬롯 다수
