## S-Core

| 항목 | 내용 |
|------|------|
| 비유 | 겟타선 — 싸울수록·한계에 닿을수록 폭발 |
| **연출 규칙** | “코어가 반응했다” 금지 → **리아가 끌어냈다** |

| 형태 | BRAVE 동일 유지 · 위기 시 일시 과부하 · **EP13만 엑셀리온 진화** |

| 단계 | 구간 | 해금 | 체감 |
