## 핵심 시스템

| 시스템 | 역할 |
|--------|------|
| 썬더 블레이드 | 근접 |
| 브레스트 캐논 | 중거리 |

## S-Core = 겟타선형

| 항목 | 내용 |
|------|------|
| 비유 | **겟타선** — 싸울수록·한계에 닿을수록 규모·화력 폭발 |
| 세계 연결 | 적과 BRAVE가 공유하는 **한 뿌리**(영생·영혼 계통)가 전장에서 열리는 것 |
| 플레이 | 숫자 스탯보다 **게이지·필살·후반 배율**로 체감 |
| 공명 | 침공 개시 때 BRAVE 각성 = 같은 뿌리의 다른 극이 깨어남 |

| 항목 | 값 |
|------|-----|

| 필살 | ≥50, 소모 50 |
