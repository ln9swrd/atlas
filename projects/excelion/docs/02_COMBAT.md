## S-Core = 겟타선형

| 항목 | 내용 |
|------|------|
| 비유 | **겟타선** — 싸울수록·한계에 닿을수록 규모·화력 폭발 |
| 세계 연결 | 적과 BRAVE가 공유하는 **한 뿌리**(영생·영혼 계통)가 전장에서 열리는 것 |
| 플레이 | 숫자 스탯보다 **게이지·필살·후반 배율**로 체감 |
| 공명 | 침공 개시 때 BRAVE 각성 = 같은 뿌리의 다른 극이 깨어남 |

### S-Core 단계 (소년만화 외부 체감)

| 단계 | 구간 | 해금 | 관객 체감 |
|------|------|------|-----------|
| **I 기본** | EP1–4 | 필살 가능 (≥50) | 서툰 기동 → 첫 필살 |
| **II 각성** | EP5–8 | 충전 배율 1.3 · 필살 강화 | 중보스·라이벌전에서 「커진다」 |
| **III 한계** | EP9–12 | 충전 배율 1.6 · 초필 직전 | 달·워든 혈투 |
| **IV 전개** | EP13 | 초필 (100+완전전개) | 게이트 파괴 일격 |

규칙:
- 매 화 끝, 관객이 「이번 화에서 새로 쓸 수 있게 된 것」을 알 수 있어야 함
- 단계 상승은 스토리 성장(리아)과 동기화 (`01_CHARACTER` · `09_STORY_S1`)

### 수치 초안 (테스트 전)

| 항목 | 값 |
|------|-----|
| 최대 | 100 |
| 필살 | ≥50, 소모 50 |
| 초필 | 100+완전전개, 소모 100 |
| 소형 적중 +2 / 중형 +4 / 처치 잡 +5 / 중+ +10 |
| 회피 성공 +3 / 피격 −5 |
| 후반 충전 배율 | 1.0 (I) → 1.3 (II) → 1.6 (III) |
