# 00_VISION — Excelion

> Updated: 2026-08-06 · **SH-5** 몰입 핵 정합 (감정 + 목표 + 대결)

## 목표
- 오리지널 메카 세계관 구축
- 슈퍼로봇 + 리얼로봇 장점 결합
- 3D 프린팅과 게임 제작을 동시에 고려
- 파라메트릭 모델링으로 다양한 기체 빠른 제작
- 1인 개발 + AI로 상업 가능 IP

## 장르
- Mission Based 3D Action RPG
- 모던 슈퍼로봇 / SF + 생체기계(Biomechanical)
- 서사 톤: **소년만화형 쾌감** (목표·대결·성장 체감) + 리아 중심 감정

## 핵심 플레이
- 공성(攻城) / 수성(守城) / 섬멸 / 보스전
- S-Core 단계 성장 (I~IV) · 미션 선택형

## 서사 · 몰입 핵

**주인공은 리아.**  
관객 입구 = **감정 + 목표 + 대결**  
— 세계관 설명이 아니라 리아의 상태, 이번 화의 승패, 라이벌/보스와의 충돌.

매 화 한 질문(목표/승패), 매 화 한 단 성장 + 외부 체감, 설정은 보여 주기.
