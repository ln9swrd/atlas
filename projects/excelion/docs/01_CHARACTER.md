# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **보완** 핵심 표 복구 · 카이 잔상 · 아슈르 대사 분리 정합

## 원칙

**S1의 스토리 중심은 리아다.**  
**톤: 소년만화 · 열혈 + 광기**  
**관객 입구 = 공감 → 애착 → 대가 → 상실 → 집념 → 돌파**

### 몰입 3규칙

1. **몸이 먼저** — 대사·설정 전에 리아의 숨·손·시선
2. **아끼게 만든 뒤 잃는다** — 카이 EP1–7 애착
3. **이 화의 승패를 안다** — 30초 안에 목표

## 시즌1 1줄

16세 **리아**가 수성·공성을 거치며 광기를 무기로 삼고, 카이의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 특별함 | 능력 X · **선택과 집념** O |
| 핵심 갈등 | 인간이기를 유지하면서 인간이 아닌 힘을 쓰는 것 |

### 왜 리아만 타는가

| 단계 | 내용 |
|------|------|
| EP1 | 그 자리 · 공명 임계 · 다른 지원자 없음 |
| EP2–4 | 대안 공명 **실패** 암시 1장면 |
| EP5 | 레이 하차 명령 → 대안 투입 → **기체 거부** → 리아 재탑승 → 레이 사후 침묵 |
| 이후 | 지휘부 갈등 반복 없음 · EP9~ 보급/호위는 “막지 않음”으로 처리 (강의 금지) |

### 광기 시각 신호 (매 화 1개 이상 노출)

| 단계 | 구간 | 손 | 시야 | 통신 | BRAVE |
|------|------|-----|------|------|-------|
| 0 | EP1–2 | 떨림 | 정상 | 짧음 | 서툰 기동 |
| 1 | EP3–4 | 꽉 쥠 | 순간 왜곡 | 숨 섞임 | 예측 불허 1회 |
| 2 | EP5–7 | 경련·코피 | 가장자리 균열 | 톤 저하/끊김 | 일시 빛·균열 |
| 3 | EP8–9 | 멈췄다 쥠 | 카이 잔상 가능 | 침묵 김 | 과부하=대가 |
| 4 | EP10–12 | 안정+광기 | 고의로 연다 | 웃음·결단 | 일시 전조 |
| 5 | EP13 | 한계 너머 | 전면 | 결단=행동 | **엑셀리온 진화** |

과부하 시 조종 공백 **~3초** → EP8 카이 희생 논리.

### EP1 / EP8 / EP13 대사 초안

**EP1** 카이「내리지 마.」 / 리아「…해봐야 알아.」 / 「동조율 — 임계.」  
**EP8** 카이「끝나면 내려.」 → 피격 / 리아「…헛되게 안 해.」  
**EP13** 아슈르「이것은 시작에 불과하다.」 / 리아「여기까지야.」「시간을 벌었다.」  
(아슈르「급이 아니다」는 **EP9만** — 13 반복 금지)

## 관계 구조

### 카이 — 동료 · EP8 희생

| EP | 애착 비트 (필수) |
|----|------------------|
| 1 | 말림 「내리지 마」 |
| 2 | 통신으로 이름 · 안심 |
| 3 | 말려도 따라감 |
| 4 | 돌봄 한 마디 |
| 5 | 부상 · 재출격 말림 |
| 6 | 농담 또는 한숨 |
| 7 | 공포 + 통신 유지 |

**EP8 전투 논리**
1. 리아 광기 과부하 → 조종 공백 ~3초  
2. 치명 궤적 → 카이가 메움 → 피격  
3. 직전 「끝나면 내려.」 → 리아 목격 · 통신 끊김  

**EP9–11 카이 잔상 (설명 없이 1회씩)**

| EP | 예시 (택1) |
|----|------------|
| 9 | 습관 동작 · 빈 통신 주파수 · 카이가 쓰던 호칭이 목에 걸림 |
| 10 | 짧은 잔상 또는 “끝나면 내려” 메아리 1회 |
| 11 | 전투 직전 손이 한 번 멈추는 정도 |

슬로건(“카이를 위해”) 반복 남발 금지. **몸이 먼저.**

### 레이 — 숫자 책임 → EP5 정점 → 사후 침묵 → EP9~ 안 막음
