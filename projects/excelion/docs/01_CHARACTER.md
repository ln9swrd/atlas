# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **A 채택** (e.md) — 카이=동료 희생 · 아슈르 · 열혈+광기

## 원칙

**S1의 스토리 중심은 리아다.**  
**회마다 리아는 성장한다.**  
**톤: 소년만화 · 열혈 + 광기**  
**관객 입구 = 공감 → 애착 → 대가 → 상실 → 집념 → 돌파**

### 몰입 3규칙

1. **몸이 먼저** — 대사·설정 전에 리아의 숨·손·시선
2. **아끼게 만든 뒤 잃는다** — 카이를 초반부터 붙인다
3. **이 화의 승패를 안다** — 30초 안에 목표 보임

## 시즌1 1줄

16세 **리아**가 수성·공성을 거치며 광기를 무기로 삼고, 카이의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 특별함 | 능력 X · **선택과 집념** O |
| 핵심 갈등 | 인간이기를 유지하면서 인간이 아닌 힘을 쓰는 것 |
| 성장 | 광기 거부 → 수용 → 무기로 사용 → 경계 너머 |
| 포지션 | 의지를 행동으로 증명하는 파일럿 |

### 내면 갈등

- 표면: 광기를 받아들일 것인가
- 심층: 이게 나인가, 기계인가
- 감정: 대가(신체·관계·존재)를 알면서도 멈추지 않음
- S1 해소: 완전 해소 아님. 인간성 일부 포기 + 집념 유지 → S2 여운

### 관객이 리아에게 붙는 지점

| 감정 | 활용 | 몸의 신호 |
|------|------|-----------|
| 무서움 | EP1–2 | 숨·떨리는 손 |
| 집념 | EP3–5 | 멈추지 않는 손 |
| 흔들림 | EP7 | 경계가 흐려짐 |
| **상실** | **EP8 카이** | 직접 목격 |
| 광기 수용 | EP10–12 | 웃으며 받아들임 |
| 돌파 | EP13 | 한계를 넘은 손 |

### 성장 사다리

| 구간 | 단계 | 한 줄 |
|------|------|--------|
| EP1–4 | 거부 → 징후 | 광기를 두려워하며 싸운다 |
| EP5–8 | 수용 직전 → **상실** | 대가를 알고, 카이를 잃는다 |
| EP9–13 | 무기로 사용 → 경계 너머 | 집념으로 아슈르를 꺾고 문을 닫는다 |

## 관계 구조

### 카이 — 가장 가까운 동료 (필수)

| 항목 | 내용 |
|------|------|
| 역할 | 리아를 **걱정하고 옆에 있는** 사람 |
| 동기 | 리아를 살리는 것 |
| 등장 | EP1부터 · 애착 축적 |
| **EP08** | 리아를 구하다 **죽음** · 리아가 직접 목격 |
| 이후 | 죽은 뒤에도 리아의 집념을 지탱 |

> 관객이 카이를 아끼게 만들어야 EP8이 아프다. 라이벌이 아님.

### 유나 — 냉정한 베테랑

| 항목 | 내용 |
|------|------|
| 역할 | 리아의 변화를 **외부에서 비춤** |
| 시선 | “시한폭탄” → “이미 경계를 넘었다” → 함께 싸움 |
| 등장 | EP2~ |

### 레이 — 지휘관

| 항목 | 내용 |
|------|------|
| 역할 | 조직 vs 개인 긴장 |
| 변화 | 리아를 막음 → EP5 정점 → 이후 믿음 (갈등 반복 없음) |
| 등장 | 짧게 · 주인공 되지 않음 |

### 아슈르 — 최종 보스 (대립축)

| 항목 | 내용 |
|------|------|
| 역할 | **격이 다른** 소년만화 최종 보스 |
| 자아 | 있음 · 엔릴 후예 명령으로 전선 지휘 · 맹목적 아님 |
| 태도 | 오만 · “아직 상대할 급이 아니다” |
| 시선 | 흥미로운 변수 → 제거해야 할 위협 → 인정 |
| 등장 | EP4 암시 · EP6 시선 · EP9 전면 · EP10–13 결판 |

> 아슈르는 주인공이 아님. 리아 없이 아슈르 시점 롱컷 금지.

## BRAVE · S-Core

- BRAVE = 리아의 **거울** · 시종일관 **같은 모습**
- 위기 때만 일시적 과부하 연출 (빛·균열)
- **진짜 형태 변화 = EP13 엑셀리온 진화만**
- S-Core: 리아의 **의지**가 코어를 끌어낸다 (시스템이 반응하는 것이 아님)
- 광기 = 자아↔S-Core 경계 붕괴 · **성장의 대가** (버프 아님)
