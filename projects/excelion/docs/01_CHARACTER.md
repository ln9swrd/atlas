# 01_CHARACTER — 파일럿 & BRAVE

## 원칙

**S1의 스토리 중심은 리아다.**  
**회마다 리아는 성장한다.**  
**관객은 리아의 감정으로 들어온다** — 설정이 아니라 호흡·손·눈으로.

## 시즌1 1줄

16세 **리아**가 공성(攻城)과 수성(守城)을 오가며 커지고, 달에서 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 성장 규칙 | **1화 = 최소 1단** (손·눈·가슴·목소리) |
| 몰입 규칙 | 관객이 리아보다 설정을 먼저 이해하면 실패 |

### 관객이 리아에게 붙는 지점

| 쉬운 감정 | 활용 |
|-----------|------|
| 무서움 | EP1–2 · 도망과 첫 수성 |
| 미안함 | EP3 · 구하지 못한 눈 |
| 씁쓸함 | EP5 · 이겨도 남는 것 |
| 흔들림 | EP7–8 · 말과 한 뿌리 |
| 결심 | EP10–13 · 타겠다는 선택 · 문 닫기 |

### 리아 성장 사다리 (요약)

| 구간 | 단계 | 한 줄 |
|------|------|--------|
| EP1–4 | 생존자 → 짐꾼 | 공포를 지고 움직인다 |
| EP5–8 | 짐꾼 → 전투원 | 대가를 알고 다시 고른다 |
| EP9–13 | 전투원 → 파일럿 | 이름을 걸고 문을 닫는다 |

## BRAVE

- 한 뿌리 · S-Core · 리아의 **거울**  
- 성장 연동: 서툰 기동 → 필살 체감 → 완전 전개 직전 → 게이트 출력

## 용어

| 수성 守城 | 거점 사수 (행성 아님) |
| 공성 攻城 | 적 거점 탈환 |
