# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **P3** 유나·레이 동기 · 중반 대립 · 초반 전투 하이라이트

## 원칙

**S1의 스토리 중심은 리아다.**  
**톤: 소년만화 · 열혈 + 광기**  
**관객 입구 = 공감 → 애착 → 대가 → 상실 → 집념 → 돌파**

### 몰입 3규칙

1. **몸이 먼저**
2. **아끼게 만든 뒤 잃는다** (카이 EP1–7)
3. **이 화의 승패를 안다**

## 시즌1 1줄

16세 **리아**가 수성·공성을 거치며 광기를 무기로 삼고, 카이의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · **그 자리에 있던 아이** |
| 특별함 | 능력 X · **선택과 집념** O |

### 왜 리아만 · 광기 신호 · 대사 초안

- 리아만: 대안 공명 실패 → EP5 레이 사후 침묵 (`P1`)
- 광기 시각 신호 0–5단계 (`P2` 표 유지)
- EP1/8/13 대사 초안 (`P2` 유지)

### 초반 전투 하이라이트 (P3 · EP1–4)

매 화 **이겼다/살아남았다** 체감 1개. 길게 끌지 않음.

| EP | 하이라이트 (외부 체감) |
|----|------------------------|
| 1 | 서툰 기동 속 **첫 회피→반격 1타**로 탈출 루트 확보 |
| 2 | 수성 중 **S-Core 첫 필살**로 웨이브 한 줄기 끊음 |
| 3 | 물량 속 **한 명만이라도** 끌어내 탈출 성공 |
| 4 | 자폭 시계 직전 **데이터 회수 컷** + 기동 탈출 |

## 관계 구조

### 카이 — 동료 · EP8 희생

애착 EP1–7 · 과부하 3초 빈틈을 메움.

### 유나 — 냉정한 베테랑 (P3 동기)

| 항목 | 내용 |
|------|------|
| 역할 | 리아의 변화를 밖에서 비춤 |
| **동기** | **과거에 광기/과부하로 파일럿을 잃음** → 리아를 “시한폭탄”으로 봄 |
| 변화 | 경계 → “이미 넘었다” → EP12 합류 |
| 규칙 | 과거 강의 금지 · **한 줄·한 시선**으로만 |

### 레이 — 지휘관 (P3 동기)

| 항목 | 내용 |
|------|------|
| 역할 | 조직 vs 개인 |
| **동기** | **산 사람 숫자를 책임지는 자리** → 리아 독주가 전선을 흔들까 두려워 막음 |
| 변화 | EP5 정점(대안 실패) → 사후 침묵 → EP9 이후 안 막음 |
| 규칙 | 주인공화 금지 · 갈등 반복 없음 |

### 아슈르 — 최종 보스

EP4 이름 · EP6 시선 · EP7 원격 일격 · EP9~13 전면.

### 중반 대립 — 아슈르 부하 엘리트 (P3)

카이가 동료 희생이라 **이겨야 할 중간 적**이 필요.

| 항목 | 내용 |
|------|------|
| 가칭 | **ORD-ELITE** (아슈르 부하 · 이름 미정) |
| 역할 | 중반 “이 상대를 넘어야 한다” |
| 등장 | **EP6** 전선 압박 또는 **EP9** 항로 돌파 차단 |
| 태도 | 아슈르만큼 오만하진 않음 · **실행자** |
| 결과 | 격파 가능 · 아슈르 본체는 아님 |

> 라이벌 서사 아님. 카이와 대칭 금지. 리아 성장의 **계단**.
