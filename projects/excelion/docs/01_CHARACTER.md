# 01_CHARACTER — 파일럿 & BRAVE

## 원칙

**S1의 스토리 중심은 리아다.**  
**톤: 소년만화 · 열혈 + 광기**  
**관객 입구 = 공감 → 애착 → 대가 → 상실 → 집념 → 돌파**

### 몰입 3규칙

1. **몸이 먼저**
2. **아끼게 만든 뒤 잃는다** (카이 EP1–7)
3. **이 화의 승패를 안다**

## 시즌1 1줄

16세 **리아**가 수성·공성을 거치며 광기를 무기로 삼고, 카이의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · **그 자리에 있던 아이** |
| 특별함 | 능력 X · **선택과 집념** O |
| 핵심 갈등 | 인간이기를 유지하면서 인간이 아닌 힘을 쓰는 것 |

### 왜 리아만 타는가 (P1)

EP1 공명 → EP2–4 대안 실패 암시 → EP5 대안 투입 실패·기체 거부 → 레이 사후 침묵.

### 광기 시각 신호 (P2 · 관객용 고정)

관객이 매 화 “이번엔 어디까지”를 보게 한다. 설명 금지 · **보여 주기만**.

| 단계 | 구간 | 손 | 시야/HUD | 통신·목소리 | BRAVE |
|------|------|-----|----------|-------------|-------|
| 0 거부 | EP1–2 | 떨림 | 정상 | 짧음 | 서툰 기동 |
| 1 징후 | EP3–4 | 꽉 쥠 | 순간 왜곡 | 숨이 섞임 | 예측 불허 1회 |
| 2 과부하 | EP5–7 | 경련·코피 | 가장자리 균열 | 톤이 낮아지거나 끊김 | 일시 빛/균열 |
| 3 상실 후 | EP8–9 | 멈췄다 다시 쥠 | 카이 잔상 가능 | 침묵이 김 | 과부하 = **대가** |
| 4 수용 | EP10–12 | 안정+광기 | 고의로 연다 | 웃음·짧은 결단 | 일시 엑셀리온 전조 |
| 5 너머 | EP13 | 한계를 넘긴 손 | 전면 | 결단이 행동 | **엑셀리온 진화** |

과부하 시 **조종 공백 ~3초** 가능 → EP8 카이 희생 논리.

### EP1 / EP8 / EP13 대사 초안 (P2)

**EP1**
- 카이: 「내리지 마.」
- 리아: (타며) 「…해봐야 알아.」
- 시스템: 「동조율 — 임계.」

**EP8**
- 카이: 「끝나면 내려.」
- (과부하 3초 → 카이 피격)
- 리아: (통신 끊긴 뒤, 혼자) 「…헛되게 안 해.」

**EP13**
- 아슈르: 「아직 급이 아니다.」 → (밀리며) 「이것은 시작에 불과하다.」
- 리아: 「여기까지야.」
- (게이트 붕괴 후) 「시간을 벌었다.」

> 초안. 확정 전 · 늘리지 말 것.
