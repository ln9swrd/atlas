# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **몰입 보완** (동료 가칭 · 카이 존재감 · 관객 입구)

## 원칙

**S1의 스토리 중심은 리아다.**  
**회마다 리아는 성장한다.**  
**관객 입구 = 감정 + 목표 + 대결**  
— 설정이 아니라 호흡·손·눈·그리고 **이번 화의 승패**.

### 몰입 3규칙 (관객용)

1. **몸이 먼저** — 대사·설정 전에 리아의 숨·손·시선이 보인다
2. **이름이 붙으면 감정도 붙는다** — 조연은 가칭이라도 부른다
3. **이 화의 승패를 안다** — 관객이 “오늘 뭘 지켜야/빼앗아야 하는지” 30초 안에 안다

## 시즌1 1줄

16세 **리아**가 공성(攻城)과 수성(守城)을 오가며 커지고, 달에서 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 성장 규칙 | **1화 = 최소 1단** (손·눈·가슴·목소리) + **외부 체감 1개** (S-Core/전투 결과) |
| 몰입 규칙 | 관객이 리아보다 설정을 먼저 이해하면 실패 |
| 포지션 | 감정을 느끼는 아이 → **의지를 행동으로 증명하는 파일럿** |

### 관객이 리아에게 붙는 지점

| 쉬운 감정 | 활용 | 몸의 신호 |
|-----------|------|-----------|
| 무서움 | EP1–2 · 도망과 첫 수성 | 숨·발소리·떨리는 손 |
| 미안함 | EP3 · 구하지 못한 눈 | 시선이 꺼진 눈에 머묾 |
| 씁쓸함 | EP5 · 이겨도 남는 것 | 승리 후 침묵이 대사보다 김 |
| 흔들림 | EP7–8 · 라이벌·한 뿌리 | 통신을 끄고도 조종석에 남음 |
| 결심 | EP10–13 · 타겠다는 선택 | 손이 게이트를 향함 |

### 리아 성장 사다리 (요약)

| 구간 | 단계 | 한 줄 | 소년만화 체감 |
|------|------|--------|----------------|
| EP1–4 | 생존자 → 짐꾼 | 공포를 지고 움직인다 | 첫 승리 / 첫 한계 |
| EP5–8 | 짐꾼 → 전투원 | 대가를 알고 다시 고른다 | 라이벌 등장 · 패배 · 재도전 |
| EP9–13 | 전투원 → 파일럿 | 이름을 걸고 문을 닫는다 | 한계 돌파 · 최종 대결 |

## 관계 구조 (몰입용 · 가칭 확정 전)

### 라이벌 — 카이 (가칭)

| 항목 | 내용 |
|------|------|
| 역할 | 리아를 **밀어붙이는 대립축** |
| 등장 | EP7 본격 · EP8 재대면 |
| 정체 | 적 측 엘리트 (한 뿌리 공명) — 확정 전 |
| 기능 | 패배 → 재도전 |
| 관객 체감 | “저 사람은 리아보다 한 수 위다” · 이름보다 **압도감** |
| 대사 | 한 화에 1~2줄. 설명 금지 |

> 카이는 주인공이 아님. 리아 없이 카이 시점 롱컷 금지.

### 동료 (가칭 · 관객이 부를 수 있게)

| 가칭 | 역할 | 리아에게 | 등장 |
|------|------|----------|------|
| **노아** | 등 뒤의 목소리 · 통신 지원 | “아직 뒤에 있다”는 안심 | EP2~ |
| **진** | 기술·정보 · 짧은 팩트 | “지금 뭐가 위험한지” 알림 | EP4~ |
| **유나** | 같은 전선 · 희생/이탈 후보 | 이름이 사라지면 아프다 | EP6~ · EP9 후보 |

규칙:
- 직책 나열 금지. 「리아에게 뭐가 되나」만.
- 매 등장 시 **이름 한 번**은 부른다 (몰입 앵커).
- 유나가 이탈하면 EP9에서 이름 없는 손실이 아니라 **유나의 빈자리**로.

### 멘토/지휘관 (가칭: 레이)

- 짧게. “선택받은 자”가 아니라 **아직 부족한 파일럿**으로 밀어붙임.
- 주인공 되지 않음. 리아 판단이 우선.

## BRAVE

- 한 뿌리 · S-Core · 리아의 **거울**  
- 성장 연동: 서툰 기동 → 필살 체감 → 완전 전개 직전 → 게이트 출력
- **외부 체감 규칙**: 매 화 끝, 관객이 “이번 화에서 새로 쓸 수 있게 된 것” 1줄을 알 수 있어야 함

## 용어

| 수성 守城 | 거점 사수 (행성 아님) |
| 공성 攻城 | 적 거점 탈환 |
