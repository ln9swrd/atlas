# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **1단계 소년만화 축** 반영 (라이벌·동료·행동 증명형 성장)

## 원칙

**S1의 스토리 중심은 리아다.**  
**회마다 리아는 성장한다.**  
**관객 입구 = 감정 + 목표 + 대결**  
— 설정이 아니라 호흡·손·눈·그리고 **이번 화의 승패**.

## 시즌1 1줄

16세 **리아**가 공성(攻城)과 수성(守城)을 오가며 커지고, 달에서 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 성장 규칙 | **1화 = 최소 1단** (손·눈·가슴·목소리) + **외부 체감 1개** (S-Core/전투 결과) |
| 몰입 규칙 | 관객이 리아보다 설정을 먼저 이해하면 실패 |
| 포지션 | 감정을 느끼는 아이 → **의지를 행동으로 증명하는 파일럿** |

### 관객이 리아에게 붙는 지점

| 쉬운 감정 | 활용 |
|-----------|------|
| 무서움 | EP1–2 · 도망과 첫 수성 |
| 미안함 | EP3 · 구하지 못한 눈 |
| 씁쓸함 | EP5 · 이겨도 남는 것 |
| 흔들림 | EP7–8 · 말과 한 뿌리 · **라이벌** |
| 결심 | EP10–13 · 타겠다는 선택 · 문 닫기 |

### 리아 성장 사다리 (요약)

| 구간 | 단계 | 한 줄 | 소년만화 체감 |
|------|------|--------|----------------|
| EP1–4 | 생존자 → 짐꾼 | 공포를 지고 움직인다 | 첫 승리 / 첫 한계 |
| EP5–8 | 짐꾼 → 전투원 | 대가를 알고 다시 고른다 | 라이벌 등장 · 패배 · 재도전 |
| EP9–13 | 전투원 → 파일럿 | 이름을 걸고 문을 닫는다 | 한계 돌파 · 최종 대결 |

## 관계 구조 (소년만화 축 · 1단계)

### 라이벌 (필수 슬롯)

| 항목 | 내용 |
|------|------|
| 역할 | 리아를 **밀어붙이는 대립축** |
| 등장 | EP7 전후 본격화 (이전에는 암시만) |
| 정체 | 같은 공명 각성자 **또는** 적 측 엘리트 고정 1명 |
| 기능 | 패배 → 재도전 → EP12 전 최종 대결 후보 |
| 이름 | **가칭: 카이** (확정 전 · 문서 슬롯만) |

> 카이는 “주인공이 아닌 대립축”. 리아를 가리지 않는다.

### 동료 (2~3명)

| 슬롯 | 역할 | 비고 |
|------|------|------|
| 동료 A | 등 뒤의 목소리 → 이름 있는 지원 | 초반부터 |
| 동료 B | 기술/정보 담당 | 중반 |
| 동료 C | 희생 또는 이탈 가능 | EP9 전후 후보 |

조연은 「리아에게 뭐가 되나」로만 등장. 직책 나열 금지.

### 멘토/지휘관

- 짧게 등장.
- 리아를 “선택받은 자”가 아니라 **아직 부족한 파일럿**으로 밀어붙임.
- 주인공이 되지 않음.

## BRAVE

- 한 뿌리 · S-Core · 리아의 **거울**  
- 성장 연동: 서툰 기동 → 필살 체감 → 완전 전개 직전 → 게이트 출력
- **외부 체감 규칙**: 매 화 끝, 관객이 “이번 화에서 새로 쓸 수 있게 된 것” 1줄을 알 수 있어야 함

## 용어

| 수성 守城 | 거점 사수 (행성 아님) |
| 공성 攻城 | 적 거점 탈환 |
