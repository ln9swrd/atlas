# 01_CHARACTER — 파일럿 & BRAVE

> Updated: 2026-08-06 · **P1** 카이 애착 · EP8 전투 논리 · 리아만 타는 이유

## 원칙

**S1의 스토리 중심은 리아다.**  
**회마다 리아는 성장한다.**  
**톤: 소년만화 · 열혈 + 광기**  
**관객 입구 = 공감 → 애착 → 대가 → 상실 → 집념 → 돌파**

### 몰입 3규칙

1. **몸이 먼저** — 대사·설정 전에 리아의 숨·손·시선
2. **아끼게 만든 뒤 잃는다** — 카이를 EP1부터 붙인다 (아래 애착 표)
3. **이 화의 승패를 안다** — 30초 안에 목표 보임

## 시즌1 1줄

16세 **리아**가 수성·공성을 거치며 광기를 무기로 삼고, 카이의 죽음을 등에 업고 달에서 **아슈르**와 결판낸 뒤 게이트를 닫아 시간을 번다.

## 파일럿 — 리아

| 항목 | 내용 |
|------|------|
| 연령 | **16세 소녀** |
| 가칭 | **리아** |
| 각성 | 공명 · 선택받은 의식 아님 · **그 자리에 있던 아이** |
| 특별함 | 능력 X · **선택과 집념** O |
| 핵심 갈등 | 인간이기를 유지하면서 인간이 아닌 힘을 쓰는 것 |
| 성장 | 광기 거부 → 수용 → 무기로 사용 → 경계 너머 |
| 포지션 | 의지를 행동으로 증명하는 파일럿 |

### 왜 리아만 타는가 (개연성 · P1)

| 단계 | 내용 |
|------|------|
| EP1 | 그 자리에 있던 아이 · 공명 임계 · 다른 지원자 없음 |
| EP2–4 | 후속 공명 시도 **실패**(다른 파일럿 동기화 거부/위험) — 강의 없이 **한 장면**으로만 |
| EP5 | 레이가 하차 명령 · 리아 의식 상실 후 **재탑승** |
| EP5 정점 | 대안 파일럿 긴급 투입 시도 → **공명 불일치로 기체 거부** · 전선 붕괴 직전 |
| 이후 | 레이가 사후 침묵/승인 · 지휘부 갈등 반복 없음 |

> “선택받은 자”가 아니라 **다른 선택이 실패한 자리**에 리아가 남는다.

### 내면 갈등

- 표면: 광기를 받아들일 것인가
- 심층: 이게 나인가, 기계인가
- 감정: 대가를 알면서도 멈추지 않음
- S1 해소: 완전 해소 아님 → S2 여운

### 관객이 리아에게 붙는 지점

| 감정 | 활용 | 몸의 신호 |
|------|------|-----------|
| 무서움 | EP1–2 | 숨·떨리는 손 |
| 집념 | EP3–5 | 멈추지 않는 손 |
| 흔들림 | EP7 | 경계가 흐려짐 |
| **상실** | **EP8 카이** | 직접 목격 |
| 광기 수용 | EP10–12 | 웃으며 받아들임 |
| 돌파 | EP13 | 한계를 넘은 손 |

## 관계 구조

### 카이 — 가장 가까운 동료 (필수)

| 항목 | 내용 |
|------|------|
| 역할 | 리아를 **걱정하고 옆에 있는** 사람 |
| 동기 | 리아를 살리는 것 |
| 등장 | EP1부터 |
| **EP08** | 리아를 구하다 **죽음** · 리아가 직접 목격 |
| 이후 | 리아의 집념을 지탱 |

#### 카이 애착 장면 (EP1–7 · 최소 4회+ · P1)

| EP | 장면 (필수) | 관객이 느끼는 것 |
|----|-------------|------------------|
| 1 | 말림 — “내리지 마” / 리아 거부 | 옆에 있는 사람 |
| 2 | 수성 중 **통신으로 이름 부름** · 짧은 안심 | 등 뒤 |
| 3 | 말려도 안 멈추는 리아를 **끝까지 따라감** | 포기 안 함 |
| 4 | (선택) 연구소에서 **물·담요/한 마디** | 일상적 돌봄 |
| 5 | **부상** · 그래도 리아 재출격 말림 | 위험해진 사람 |
| 6 | 짧은 **농담 또는 한숨** (전선 유지 중) | 아직 살아 있음 |
| 7 | **공포**를 보이면서도 통신을 끊지 않음 | 아끼니까 아픔이 커짐 |

규칙: 직책 나열 금지. 매 등장 **이름 한 번**. 라이벌 연출 금지.

#### EP8 희생 — 전투 논리 (P1)

우연한 죽음이 아님.

1. 전투 중 리아 **광기 과부하** → 조종 입력 붕괴 **약 3초**
2. 그 빈 틈으로 치명 궤적 진입
3. **카이가 그 궤적을 몸으로 메움** (기체/엄호 중 피격)
4. 리아 시야에 카이가 들어온다 · 통신 끊김
5. 직전 호흡: 카이가 **살 것 같은 선택/대사 1개** (예: “끝나면 내려”) → 바로 피격

> 리아의 힘이 만든 빈 틈을 카이가 메운다 = 대가의 개연성.
