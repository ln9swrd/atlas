## 엑셀리온 (진화)

### 원칙

| # | 규칙 |
|---|------|
| 1 | **동일 골격** · 완전 다른 기체 교체 금지 |
| 2 | **리아가 끌어낸다** (“코어가 반응” 금지) |
| 3 | 광기 = **대가** (버프 연출 아님) |
| 4 | 확장 **1단계**만 (무한 변신 금지) |
| 5 | 네메시스 실루엣과 즉시 구분 유지 |

### 단계

| 구간 | 상태 | 비주얼 |
|------|------|--------|
| EP1–10 | BRAVE | 초기형 · accent 호박 |
| **EP11** | **일시 전조** | 윤곽 한 단계 확장 · 빛 변화 · 수 초 후 사그라짐 |
| EP12 | 잔광 가능 | 풀 진화 아님 |
| **EP13** | **엑셀리온** | 확장 1단계 **고정** · 초필 가능 |

### 변화 요소 (1단계)

| 축 | 내용 |
|----|------|
| 윤곽 | 전체 실루엣 소폭 확장 · 여백이 줄어든 인상 |
| 빛 | accent가 코어·이음새로 확산 · 냉백+호박 혼합 가능 |
| 슬롯 | thruster / backpack 중 **택1~2 활성** (날개·추진 실루엣) |
| 기동 | 무거워 보이지 않음 · 밀고 나가는 힘 |
| 전투 | 네메시스 봉쇄 무시/조기 소멸 · N04 취소 가능 · 피해 ×1.5 |
