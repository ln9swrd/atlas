# COMBAT_SYSTEM — 구현용 전투 시스템

> 2026-08-09  
> 원천: `design/combat/PATTERN_EXECUTION_SPEC` · `COMBAT_LOOP` · `FEEDBACK_SYSTEM` · `ANUBIS_MECHANICS`  
> 목적: **기획이 아니라 구현 가능한 형태**

---

## 1. 전투 흐름 (런타임)

```
1. 보스 패턴 선택 (Phase 상태 머신)
2. 경고 표시 (시각/사운드)
3. 플레이어 입력 (이동·회피·공격)
4. 판정 (히트/회피/실패)
5. 피드백 출력 (히트스톱·플래시·SFX)
6. Phase 트리거 검사 → 전환 또는 종료
```

---

## 2. Phase 상태 머신

| 상태 | 동작 |
|------|------|
| Enter | 타이머 시작 · 패턴 풀 로드 |
| Active | 패턴 큐 실행 |
| Check | 시간 또는 행동 트리거? |
| Advance | 다음 Phase (HP% 사용 금지) |
| Defeat / Clear | 결과 UI · 재도전 |

트리거 예: 경과 시간 · 약점 창 n회 · 씰 해제 n회.

---

## 3. 패턴 실행 단위

모든 패턴은 다음 필드를 코드 데이터로 가짐:

- 발동 조건 · 시전 시간 · 경고 · 대응 · 실패 결과 · 판정 범위 · 카메라

데이터 원천: `design/combat/PATTERN_EXECUTION_SPEC.md`

---

## 4. 판정

| 유형 | 처리 |
|------|------|
| 보스 → 플레이어 | 위험 존 겹침 · 무적 프레임 제외 |
| 플레이어 → 보스 | 약점 창 배율 · 차단 중 감쇠 |
| 회피 성공 | 대쉬 무적 · 존 이탈 |

---

## 5. 피드백 (필수)

| 이벤트 | 최소 출력 |
|--------|----------|
| 타격 | 숫자 + SFX + 히트스톱 |
| 회피 성공 | 잔상/틱 |
| 위험 강 | 흔들림 + 적 플래시 + 경고음 |
| 패배 | 실패 유형 1줄 (반응/판단/정보) |

---

## 6. 아누비스 전용

- UI 왜곡: 예고 후 ≤0.8s
- 이중 신호: 실선=위험 · 점선=가짜 (고정)
- 입력 완전 차단·랜덤 재매핑 금지

상세: `design/combat/ANUBIS_MECHANICS.md`
