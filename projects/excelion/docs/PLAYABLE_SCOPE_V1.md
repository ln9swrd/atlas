# PLAYABLE_SCOPE_V1 — 최소 플레이 가능 범위

> 2026-08-10 · 플레이어 **AXION** · VS 보스 **세스** · S-Core 가칭

---

## 포함

| 항목 | 내용 |
|------|------|
| 플레이어 | 1기 (**AXION** 플레이스홀더) |
| 적 | 2종 (속도형 · 파워형 더미) |
| 보스 | 1종 (**세스** · 패턴 최소 1–2개) |
| 조작 | 이동 · 기본 공격 · 회피(대쉬) |
| 전투 | 피격 · HP · 간단한 예고 1종 |
| 루프 | 패배 시 재도전 |

---

## 성공 정의

```
더미 메쉬만으로
이동 → 공격 → 회피 → 피격 → (세스 패턴 1) → 클리어 또는 재도전
```

관련: IMPLEMENTATION_QUEUE · NAMING_STATUS · COMBAT_SYSTEM
