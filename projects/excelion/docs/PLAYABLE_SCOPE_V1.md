# PLAYABLE_SCOPE_V1 — 최소 플레이 가능 범위

> 2026-08-09

---

## 플레이 가능 기준

조작 가능한 기체로 **한 번의 교전**을 끝까지 할 수 있으면 V1 충족.

---

## 포함

| 항목 | 내용 |
|------|------|
| 플레이어 | 1기 (BRAVE 플레이스홀더) |
| 적 | 2종 (속도형 · 파워형 더미) |
| 보스 | 1종 (**몬투** 권장 · 패턴 최소 1–2개) |
| 조작 | 이동 · 기본 공격 · 회피(대쉬) |
| 전투 | 피격 · HP · 간단한 예고 1종 |
| 루프 | 패배 시 재도전 |

---

## 제외 (V1)

- 스토리 연출 · 컷신
- UI 완성도 · 메뉴 폴리시
- 커스터마이징 · 강화 트리
- 아누비스 인지 교란 풀셋
- 고퀄 모델 · 최종 애니
- 24화 전체 스테이지

---

## 성공 정의

```
더미 메쉬만으로
이동 → 공격 → 회피 → 피격 → (보스 패턴 1) → 클리어 또는 재도전
이 한 사이클이 끊기지 않음
```
