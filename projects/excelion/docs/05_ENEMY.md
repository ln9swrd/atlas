# 05_ENEMY — 몹·보스

## 설정

| 항목 | 내용 |
|------|------|
| 세력 | **엔릴 후손** 측 침공 단위 (통칭 Order) |
| 목적 | 인류 멸절 |
| 뿌리 | BRAVE와 **한 뿌리** (영생·영혼 계통) · 방향만 반대 |
| 게이트 | 후손 측 통로 · 달 뒷면 |
| 각성 연계 | 침공 개시 ≈ BRAVE 공명 각성 |

중후반에야 “같은 뿌리”를 암시. 개막에 설명하지 않음.

## 보스 페이즈

### 중보스 (EP5 · ORD-MID)

| 페이즈 | 내용 | 체감 |
|--------|------|------|
| P1 | 패턴 학습 · 가드/회피 요구 | 첫 본격 보스 |
| P2 | 패턴 강화 · 필살 유도 | S-Core II 직전 체감 |

### 엘리트 / 라이벌 카이 (EP7–8)

| 페이즈 | 내용 | 체감 |
|--------|------|------|
| P1 | 압도 · 리아 밀림 | 「저 기사에게 빼앗기지 않을 수 있나?」 |
| P2 | 한 뿌리 암시 · 대화 최소 | 흔들림 |
| 결과 EP7 | 패배 또는 아슬아슬한 수성 | 재도전 동기 |
| EP8 | 재대면 · 재선택 | 「같아도 다시 싸운다」 |

> 카이는 주인공이 아님. 리아를 가리지 않음. (`01_CHARACTER`)

### 게이트 워든 (EP12–13)

| 페이즈 | 내용 | 체감 |
|--------|------|------|
| P1 | 혈투 · 밀림 | S-Core III |
| P2 | 혈투 · 붙잡기 | 힘과 함께 선다 |
| P3 | 게이트 개방 · 파괴 타이밍 | 초필(IV) · 시간 벌기 |

**① 혈투 → ② 게이트 파괴**  
완전 승리 아님. 너머는 S2 떡밥.

## 규칙

- 물량 · 패턴 · **보스만 페이즈**
- 같은 뿌리 설정은 연출·설정 암시용 (플레이 조작 변경 없음)
- 보스 격파 = 스토리 성장 + S-Core 단계와 동기화 (`02_COMBAT`)
