## ORD-ELITE — 세스

### 한 줄
판정으로 전선을 닫는 실행자. 넘어야 할 계단. 최종 벽 아님.

| 항목 | 내용 |
|------|------|
| 이름 | **세스** (S1 잠금) |
| 격 | MID 이상 · 네메시스 미만 |
| 핵심 | “싫어서가 아니라 **해야 해서**” |
| 시선 | 방해 / 처리 / 보고 |
| 충성 | 역할 충실 (네메시스 숭배 X) |

### 감정 균열 (미묘)

무표정 기본 · **장면당 균열 1회 이하.**

| 감정 | 티 |
|------|-----|
| 불쾌 | 말 반 박 짧아짐 |
| 흥미 | 시선 한 번 더 |
| 당황 | 보고 문장 한 번 끊김 |
| 패배 | 절규 없이 무전 단절 |

### 전투 · 배치

압박·차단 · 약점=집념 돌파·과부하 지연 · **EP6 격파**  
HP **48** · 페이즈 2 · `state/BOSS_STATS_SETH_NEMESIS.md`  
패배: 기동 정지 · 「…보고, 끝.」

### 금지

카이 대칭 · 비극 주연 · 네메시스급 · 균열 남발
