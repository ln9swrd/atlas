## ORD-ELITE — 세스 (아슈르 부하)

### 한 줄

아슈르의 **손발**. 감정으로 싸우지 않고, **판정으로 전선을 닫는** 실행자. 넘어야 할 계단이지 최종 벽이 아니다.

### 기본

| 항목 | 내용 |
|------|------|
| ID | ORD-ELITE |
| 가칭 | **세스** (확정 전) |
| 호칭 | 집행자 / 전선 대리 |
| 소속 | 엔릴 후손 · **아슈르 직속** |
| 자아 | 있음 · 맹목적 병기 아님 |
| 격 | ORD-MID 이상 · **아슈르 미만** |

---

### 성격 (보완)

**핵심:** 세스는 “싫어해서” 싸우지 않는다. **해야 해서** 싸운다.

| 층 | 내용 |
|----|------|
| 표면 | 과묵 · 표정 변화 거의 없음 · 목소리 일정 |
| 판단 | 사람을 악/선으로 안 나눔 · **방해 요소 / 처리 대상 / 보고 대상**으로만 분류 |
| 자존 | 낮지 않음 · 다만 아슈르처럼 오만하게 드러내지 않음 · “등급”으로 세계를 봄 |
| 호기심 | 거의 없음 · 예외: **예상을 벗어나는 수치**(리아의 동조·광기)만 짧게 응시 |
| 공포 | 잘 안 보임 · 패배 직전에도 호들갑 없음 · 침묵 또는 보고로 끝냄 |
| 충성 | 맹신 아님 · **역할에 대한 충실** (아슈르 개인 숭배 X) |

**아슈르와의 차이**

| | 아슈르 | 세스 |
|--|--------|------|
| 태도 | 오만 · “급이 아니다” | 담담 · “처리한다” |
| 말 | 존재 압박 | 업무 보고 |
| 리아 시선 | 변수→위협→인정 | 수치 이상→보고→제거 시도 |
| 패배 | 서사의 무게 | 계단이 무너짐 |

**인간 측에서 보이는 인상**
- 유나: “저건 화가 난 게 아니다. 일한다.”
- 카이: 말수가 없어서 더 불쾌함
- 리아: 처음엔 다른 적과 같아 보이다가, **안 흔들리는 점**이 거슬림

**하지 않는 것**
- 도발·조롱 장광설
- 리아에게 이념 설교
- 아슈르 흉내 (오만 카피)
- 패배 후 원념 독백

---

### 아슈르와의 관계

| 항목 | 내용 |
|------|------|
| 위치 | 부하 · 대리 실행자 |
| 태도 | 절대시하지 않음 · **거역하지 않음** |
| 기능 | “직접 나설 급이 아니다”일 때 전선에 파견 |
| 보고 | 리아를 변수로 올림 → EP6~7 아슈르 관심 연결 |
| 패배 시 | 아슈르 오만 유지 가능 |

---

### 전투

| 항목 | 내용 |
|------|------|
| 스타일 | 패턴 명확 · 압박·차단·포위 · 낭비 없는 기동 |
| 공간 왜곡 | 없음 또는 열화 1회 |
| 약점 | 집념형 돌파 · 예상 밖 과부하에 대응 한 박자 늦음 |
| 페이즈 | P1 압박 · P2 강화 차단 · 자폭 돌입 없음 |

패배 연출: 과장된 절규 없이 **기동 정지·보고 단절**. 담담함이 끝까지 유지될수록 “일하던 자가 멈췄다”는 느낌이 남음.

---

### 이야기 기능

1. 중반 “이 상대를 이겨야 한다”
2. 적 측에 얼굴 부여 (아슈르 소진 없이)
3. MID → 세스 → 아슈르 계단
4. EP7 일격 전 전선이 무거워진 이유 (설명 없이)

### 배치

**EP6 권장** (전선 압박·격파). 미사용 시 EP9 항로 차단.

### 금지

- 카이 대칭 라이벌 · 세스 시점 롱컷 · 비극 주연화
- 아슈르급 연출 · 매 화 재등장 · 아슈르 분신 설정

### 대사 초안 (최대 2줄/등장)

- 「전선 유지. 변수는 보고했다.」
- 「등급 외. 제거한다.」
- 「아직, 그 정도는 아니다.」
- 패배: 「…보고, 끝.」 / 침묵
