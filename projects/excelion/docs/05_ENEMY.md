# 05_ENEMY — 몹·보스

## 설정

| 항목 | 내용 |
|------|------|
| 세력 | **엔릴 후손** 측 침공 단위 (통칭 Order) |
| 목적 | 인류 멸절 |
| 뿌리 | BRAVE와 **한 뿌리** (영생·영혼 계통) · 방향만 반대 |
| 게이트 | 후손 측 통로 · 달 뒷면 |
| 각성 연계 | 침공 개시 ≈ BRAVE 공명 각성 |

중후반에야 “같은 뿌리”를 암시. 개막에 설명하지 않음.

## 로스터

ORD-GRUNT / HEAVY / GUN / ELITE / **GATE 워든**

## 막판 보스

**① 혈투 → ② 게이트 파괴**  
P1–P2 혈투 · P3 게이트 개방·파괴 · 시간 벌기

## 규칙

물량 · 패턴 · 보스만 페이즈 · 같은 뿌리 설정은 연출·설정 암시용 (플레이 조작 변경 없음)
