## ORD-ELITE — 아슈르 부하 (확장)

### 한 줄

아슈르의 **손발**. 명령을 실행하는 전선 지휘 단위. 최종 보스가 아니라 **넘어야 할 계단**.

### 기본

| 항목 | 내용 |
|------|------|
| ID | ORD-ELITE |
| 가칭 | **세스** (확정 전 · 문서 슬롯) |
| 호칭 | 집행자 / 전선 대리 |
| 소속 | 엔릴 후손 · **아슈르 직속** |
| 자아 | 있음 · 맹목적 병기 아님 |
| 격 | 중보스(ORD-MID) 이상 · **아슈르 미만** |

### 아슈르와의 관계

| 항목 | 내용 |
|------|------|
| 위치 | 부하 · 대리 실행자 |
| 태도 | 아슈르를 **절대시**하지는 않음 · 그러나 **거역하지 않음** |
| 기능 | 아슈르가 “직접 나설 급이 아니다”일 때 전선에 보냄 |
| 보고 | 리아를 “변수”로 상부에 올림 → EP6~7 아슈르 관심으로 연결 |
| 패배 시 | 아슈르의 오만은 안 깨짐 · “역시 내가 나설 필요는 없었다 / 있었나” 정도만 |

> 세스가 죽거나 패해도 아슈르 서사의 무게는 유지. 세스가 복수·각성 주인공이 되지 않음.

### 성격·전투

| 항목 | 내용 |
|------|------|
| 성격 | 과묵 · 효율 · 감정 표출 적음 |
| 말투 | 짧음 · 명령·수치·판정 위주 (장광설 금지) |
| 전투 | **패턴 명확** · 압박·차단·포위 · 아슈르식 공간 왜곡은 **못 씀** 또는 열화판 1회 |
| 약점 | 집념형 돌파(리아)에 약한 면 · 예상을 벗어난 과부하에 대응 지연 |
| 페이즈 | P1 압박 패턴 · P2 강화 차단 · (선택) P3 자폭급 돌입 없음 — 격파 가능 유지 |

### 이야기 기능

1. 중반 **“이 상대를 이겨야 한다”** 체감
2. 아슈르를 일찍 소진하지 않으면서 적 측 얼굴을 줌
3. 리아 성장의 계단 (ORD-MID → ELITE → 아슈르)
4. EP7 아슈르 원격 일격 전/후에 **전선이 왜 무거워졌는지** 설명 없이 보여 줌

### 배치 (한 곳만)

| 옵션 | 구간 | 역할 | 비고 |
|------|------|------|------|
| **A** | EP6 | 전선 압박 · 격퇴/격파 | 이후 EP7 아슈르 일격이 “윗선”으로 읽힘 |
| **B** | EP9 | 항로 차단 · 격파 후 달 진입 | 카이 사후 돌파의 첫 벽 |

기본 권장: **A (EP6)**. B는 A 미사용 시.

### 금지

- 카이와 라이벌 대칭 (아군 동료 vs 이 부하는 축이 다름)
- 세스 시점 롱컷 · 세스 비극 주연화
- 아슈르와 동일 스케일 연출
- 패배 후 매 화 재등장으로 인플레
- “아슈르의 분신” 설정 (별 인격 유지)

### 대사 초안 (최대 2줄/등장)

- 「전선 유지. 변수는 보고했다.」
- 「아직, 그 정도는 아니다.」 (리아 돌파 직전)
- 패배 시: 「…보고, 끝.」 또는 침묵

## 중보스 EP5 (ORD-MID)

## 아슈르

EP4 이름 · EP6 시선 · EP7 원격 일격 · EP9–13 전면  
세스 패배 여부와 무관하게 **오만 유지** 가능. 리아를 위협으로 재평가하는 전환은 EP10 전후.

## 규칙

- 보스만 페이즈
- 병력 증가 = 아슈르 판단의 결과
- 리아가 한계를 넘긴 결과로 상급이 밀림
