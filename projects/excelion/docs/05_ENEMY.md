| 항목 | 내용 |
|------|------|
| 이름 | **세스** (S1 잠금) |
| 격 | MID 이상 · 네메시스 미만 |
| 핵심 | “싫어서가 아니라 **해야 해서**” |
| 시선 | 방해 / 처리 / 보고 |
| 충성 | 역할 충실 (네메시스 숭배 X) |

| 패배 | 절규 없이 무전 단절 |
