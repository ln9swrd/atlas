## ORD-ELITE — 세스 (아슈르 부하)

### 한 줄

아슈르의 **손발**. 감정으로 싸우지 않고, **판정으로 전선을 닫는** 실행자. 넘어야 할 계단이지 최종 벽이 아니다.

### 기본

| 항목 | 내용 |
|------|------|
| ID | ORD-ELITE |
| 가칭 | **세스** (확정 전) |
| 호칭 | 집행자 / 전선 대리 |
| 소속 | 엔릴 후손 · **아슈르 직속** |
| 자아 | 있음 · 맹목적 병기 아님 |
| 격 | ORD-MID 이상 · **아슈르 미만** |

---

### 성격

**핵심:** “싫어해서”가 아니라 **해야 해서** 싸운다.

| 층 | 내용 |
|----|------|
| 표면 | 과묵 · 표정 변화 거의 없음 · 목소리 일정 |
| 판단 | 방해 / 처리 / 보고 대상으로만 분류 |
| 자존 | 있음 · 오만하게 안 드러냄 · 등급으로 봄 |
| 호기심 | 예상을 벗어나는 수치만 짧게 응시 |
| 충성 | 역할에 대한 충실 (개인 숭배 X) |

---

### 감정 표현의 미묘한 차이

세스는 무표정이 기본이다. 다만 **완전 무감정이 아니다.**  
감정은 **크게 터지지 않고, 짧은 균열로만** 새어 나온다. 관객·리아가 “기계인가?” 했다가 “아닌가?” 하게 만드는 층.

#### 1. 기본 상태 vs 균열

| 상태 | 보이는 것 | 의미 |
|------|-----------|------|
| 기본 | 시선 고정 · 호흡 일정 · 말 속도 동일 | 업무 모드 |
| 균열 | **0.5박**만 시선이 멈춤 / 손가락·조종 입력이 한 프레임 늦음 | 판정 밖 입력을 받음 |
| 회복 | 바로 원래 템포로 복귀 · 변명·설명 없음 | 감정을 인정하지 않음 |

> 균열은 **한 장면에 1회 이하**. 반복하면 캐릭터가 무너짐.

#### 2. 감정 종류별 — 티 나는 방식 (미묘)

| 감정 | 세스의 티 | 하지 않는 것 |
|------|-----------|--------------|
| **불쾌** | 말이 반 박 짧아짐 · 「처리한다」만 남음 | 욕·조롱 |
| **흥미** | 시선이 리아/수치에 **한 번 더** 머무름 | 질문 공세 |
| **당황** | 보고 문장이 한 번 끊겼다 이어짐 | 큰 동작·후퇴 연출 과장 |
| **인정(마지못)** | 「등급 외」 뒤 **침묵 1초** | “강하군” 식 찬사 |
| **패배** | 목소리 높이지 않음 · 「보고, 끝」 또는 무전만 끊김 | 절규·원념 |

#### 3. 아슈르와의 감정 표현 차이

| | 아슈르 | 세스 |
|--|--------|------|
| 오만 | 말로 내려누름 | 말 없이 등급만 매김 |
| 관심 | “흥미롭다”를 드러냄 | 관심도 **보고 대상**으로만 처리 |
| 분노 | 압박·존재감으로 보여 줌 | 분노 대신 **템포만** 조금 빨라짐 (거의 안 보임) |
| 패배감 | 서사적 여운 (“시작에 불과”) | 여운을 **안 남기려** 함 · 그래서 더 서늘함 |

#### 4. 리아와의 대비 (연출 힌트)

| | 리아 | 세스 |
|--|------|------|
| 감정 | 몸(손·숨·시야)에 먼저 나옴 | 몸에 안 내려고 함 |
| 흔들림 | 관객이 바로 읽음 | 관객이 **늦게** 읽음 |
| 전투 중 | 광기가 표정·통신으로 샘 | 광기 없음 · 균열만 |

리아가 세스를 이긴 뒤에도 “이겼다”보다 **“저 사람은 왜 안 흔들렸지?”**가 남으면 성공.

#### 5. 연출 규칙

- 감정 대사로 설명하지 말 것 (「불쾌하다」 금지)
- 균열은 **동작·타이밍·침묵**으로만
- 아슈르처럼 크게 연기하지 말 것
- 패배 직전 균열 1회는 허용 (예: 보고 문장 중단)

### 아슈르와의 관계 · 전투 · 배치

- 거역 않음 · 변수 보고 · EP6 권장 격파
- 전투: 압박·차단 · 약점 = 집념 돌파·과부하 한 박 지연
- 패배: 기동 정지·보고 단절 (담담 유지)

### 금지

카이 대칭 · 세스 시점 롱컷 · 비극 주연 · 아슈르급 · 매 화 재등장 · 분신 설정  
**감정 균열 남발** (무표정 캐릭터 붕괴)

### 대사 초안

- 「전선 유지. 변수는 보고했다.」
- 「등급 외. 제거한다.」
- 「아직, 그 정도는 아니다.」
- 패배: 「…보고, 끝.」 / 침묵
