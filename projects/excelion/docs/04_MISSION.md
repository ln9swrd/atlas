# 04_MISSION — 맵·미션

## 범위

S1: 지구(**공성=탈환** + **수성=방어**) → 달 피날레.  
**13화 = 13스테이지** 대응은 `docs/09_STORY_S1.md`.

## 용어 (확정)

| 용어 | 한자 | 미션 의미 |
|------|------|-----------|
| **공성** | 攻城 | 적 거점·요새 **공격·탈환** |
| **수성** | 守城 | 아군 거점 **사수·방어** (행성 Mercury 아님) |

같은 지형도 목표만 바꾸면 공성 맵 ↔ 수성 맵으로 재사용 가능.

## 개막

- 여러 거점 **이미 점령**.
- 초반은 **수성** 비중이 큼 + **공성**(점령지 탈환)이 붙음.

## 맵 구조

| 구분 | 개수 | 역할 |
|------|------|------|
| 지구 점령 거점 | 다수 | **공성** (탈환 공략) |
| 지구 사수 거점 | 다수 | **수성** (방어·생존) |
| 지구 중보스·엘리트 | 3~4 | 점령 핵 · 단서 · EP5/7 |
| 달 표면 | 1+ | EP10 |
| 달 뒷면 | 1 | EP11–13 · 워든 · 게이트 |

### 진행

```
수성(守城)으로 전선 유지
  + 공성(攻城)으로 밀어붙임
  → 달 해금 (EP9)
  → 피날레 (EP11–13)
```

### 피날레

보스 혈투 → 게이트 파괴 → 시간 벌기

## 목표 타입

섬멸 / **공성**(거점 파괴·탈환) / **수성**(생존·사수) / 보스 / 게이트 / 데이터 회수 / 구조

## 원칙

조작 동일 · **행성 맵으로서의 수성 없음** · 1화 1클리어 리듬을 우선
