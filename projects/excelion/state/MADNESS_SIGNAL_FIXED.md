1. **1화 1신호 이상** — 표에 없는 추가 신호 자유, 표 신호는 생략 금지
2. **몸이 먼저** — 신호 나온 뒤 대사 (대사로 신호 설명 금지)
3. **잔상** — EP9–11만 · 설명 없이 · 1회/화
4. **과부하 3초** — EP8 전용 · 다른 화에서 동일 길이 공백 금지
5. **진화** — EP13만
