## EP1 「동기화」 — 첫 전투

### 판타지
살아남고 싶다 · BRAVE에 **올라타기로 선택** · 첫 필살의 전율.

### 미션
| 항목 | 내용 |
|------|------|
| 목표 | 탈출 / 첫 침입자 저지 |
| 형태 | 학살형 + 짧은 돌파 |
| 적 | GRUNT 무리 (HP15 · 동시 4–6) |
| S-Core | I ×1.0 |
| 시간 목표 | 전투 2–4분 · 전체 스테이지 4–7분 |

### 플레이 비트

1. **탑승 선택** — 시스템 강제가 아님 · 손·한 마디
2. **접근→콤보** — 근접 10 · 중거리 8 · Heat 관리 도입
3. **첫 필살** (≥50) — 무리 일괄 · “끌어냈다” 체감
4. **카이 비트** — H1「콜.」 또는 짧은 통신 1회 (애착 씨앗)
5. **탈출/클리어** — 가져갈 문장 여운

### 클리어 / 실패
| | |
|--|--|
| 클리어 | 경로 확보 · 첫 침입자 처리 |
| 실패 | HP 0 · 재도전 |

### 재미 게이트
- 30초 안에 “내가 탄다”가 보임
- 필살 1회가 희열로 연결
- 카이 한 비트 후 EP8이 비지 않을 것

### 수치 앵커 (B1)
GRUNT 15 · 필살 40 · 대시 12f/0.6s · Heat 100

## EP6 「달의 그림자」 — 세스 1:1

### 판타지
이길수록 전망이 없다 · **안 흔들리는 벽**을 무너뜨리고 싶다 · 선택(집념)으로 파고듦.

### 미션
| 항목 | 내용 |
|------|------|
| 목표 | 세스 격파 |
| 형태 | 1:1 보스형 |
| 적 | 세스 HP **480** · 페이즈 2 |
| S-Core | II ×1.3 |
| 시간 목표 | 4–7분 |

### 페이즈

| P | HP | 행동 |
|---|-----|------|
| 1 | 480→144 | 차단 사격 · 전선 밀기 · 씰 전개 (게이지 240) |
| 2 | 144→0 | 프로세큐트 · 노출 창 · 재차단 1회 |

### 플레이 비트

1. **정면 거부** — 씰·직선 · 세스는 안 흔들림
2. **집념 돌파** — 씰 약점 ×1.5 · 창 창출
3. **P2 처리** — 텔레그래프 있는 일격 · 카운터 창
4. **클리어** — 「…보고, 끝.」 · 네메시스 원경 1컷(말 없음)
5. **카이** — H1 가능 · 희생 전 마지막 애착 구간

### 클리어 / 실패
| | |
|--|--|
| 클리어 | HP 0 |
| 실패 | HP 0 · 재도전 |

### 재미 게이트
- “이 적을 이기고 싶다”가 성립
- 세스 감정 균열·사연 없음 유지
- 격파 후에도 전망 없음 (다음 벽 암시)

### 스킬 참조
`BOSS_WEAPON_SKILLS` SK-S01~S06

## EP8 「선택의 무게」 — 상실 + 부분 성공

### 판타지
그 죽음을 헛되게 하지 않겠다 · **스테이지는 부분 성공 가능** · 스토리는 카이 상실.

### 미션 (두 층 분리)
| 층 | 내용 |
|----|------|
| **게임** | 거점 사수 · 목표 일부 달성 가능 |
| **스토리** | 과부하 3초 → 카이 희생 · 통신 끊김 |

| 항목 | 내용 |
|------|------|
| 목표 | 거점 방어 + (스토리) 상실 수용 |
| 형태 | 방어형 + 광기 대가 |
| 적 | GRUNT/HEAVY 파도 · 보스 아님 |
| S-Core | II ×1.3 |
| 시간 목표 | 6–10분 |

### 플레이 비트

1. **거점 압박** — 돌파 유닛 우선 · 학살 루프
2. **과부하 직전** — 광기 신호 · 손 경련 · 끌어감
3. **카이 H3** — 「끝나면 내려.」 · 3초 메움
4. **피격·끊김** — 스토리 상실 · 스테이지는 클리어 가능
5. **리아** — 「…헛되게 안 해.」 · 가져갈 문장

### 클리어 / 실패 (게임 층)
| | |
|--|--|
| 클리어 | 거점 유지 · 제한 목표 달성 |
| 실패 | 거점 HP 0 또는 플레이어 HP 0 |

스토리 상실은 **클리어와 분리** · 재도전해도 서사상 카이는 돌아오지 않음(고정).

### 재미 게이트
- EP1–7 애착이 없으면 공허 → EP1 비트 필수
- 과부하 3초가 “버프”로 읽히면 실패 → 대가·손 연출
- 부분 성공과 상실이 동시에 성립해야 함

### 금지
- 카이 슬로건 남발
- 완전 실패 스테이지로만 설계
- 광기 = 순수 강화
