## 1. 스토리

- [ ] 테마(질서 vs 생명·희망)만 있고 **본편 아크** 없음
- [ ] 주인공(파일럿) 인물·동기·성장 거의 없음
- [ ] 미션 간 **서사 연결**(왜 이 거점을 지켜야 하는가) 약함
- [ ] Season 1(지구) 최소 스토리라인 미정의

## 2. 세계관

- [ ] `WORLD.md`는 단순 생존 설정, README의 **고대 문명·루프·시즌 확장**과 불일치
- [ ] 적 세력(Order)의 기원·목적·내부 구조가 “불명” 수준
- [ ] 거점·요새 도시의 구체적 구조·일상·자원 흐름 부족
- [ ] **단일 출처 세계관 문서** 필요

## 3. 게임플레이

- [ ] 핵심 루프는 있으나 **미션 타입별 차이**가 추상적
- [ ] 실패/재도전 시 보상·패널티 규칙 미정
- [ ] 성장(강화)이 “숫자 vs 플레이 경험” 원칙만 있고 **구체 트리** 없음
- [ ] 미션 선택 UI·진행 구조(분기/선형) 미정

## 4. 전투

- [ ] Prototype 범위는 잘 잘림
- [ ] 일반/중형/엘리트 적의 **역할·체감 차이** 미설계
- [ ] Heat / Overdrive의 수치·리스크·보상 개념 수준
- [ ] 보스 패턴·약점·부위 파괴 **템플릿** 없음

## 5. 기체 · 디자인

- [ ] Brave → … → Exelion Empress **단계별 외형·전투 변화** 미정의
- [ ] “여성형 실루엣 + 강인함” 원칙은 있으나 **시각 레퍼런스 고정** 약함
- [ ] 무장(메가 캐논 외) 라인업·역할 분담 미정
- [ ] 3D 프린트/게임용 모델 공용 기준 미정리

## 6. S-Core · 진화

- [ ] 설정(가능성의 심장)은 있으나 **게임 규칙** 없음
  - 진화 조건, 타이밍, 플레이어 선택 여부
  - 진화 시 조작·무장·연출 변화 범위
- [ ] 적이 진화하지 않는 이유를 플레이에 어떻게 보여줄지 미정

## 7. 적 디자인

- [ ] 계급(Drone → … → Sovereign)만 있고 **각 계급의 전투 역할** 부재
- [ ] 보스 1기 Prototype용 **구체 스펙·패턴** 없음
- [ ] 적 비주얼 톤(질서·경직) 가이드 부족

## 8. 문서 · 구조

- [ ] 기획 Bible이 `excelion-forge/docs`에 있어 게임/툴 경계 혼란
- [ ] README · WORLD · Charter 간 **용어·범위 불일치**
- [ ] Prototype 완료 기준(DoD)이 문서마다 흩어짐
