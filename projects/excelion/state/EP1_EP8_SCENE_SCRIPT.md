## EP1. 동기화

| 항목 | 값 |
|------|-----|
| 질문 | 거리 빠져나가나? |
| 목표 (30초) | 회피 → 반격 1타 → 탈출 |
| 광기 | 0 (손 떨림 · 서툰 기동) |
| 카이 비트 | 「내리지 마.」 |
| 가져갈 문장 | 세계가 끝났는데, 나는 아직 여기 있다. |

### CUT 01 — 오프닝

**ACTION**  
거리. 연기. 무너진 건물.  
리아, BRAVE 조종석. 손 떨림. 숨만.

**SFX** 통신 잡음

**DIALOGUE**  
카이 「…내리지 마.」  
리아 「…해봐야 알아.」

**UI** 동조율 — 임계.

### CUT 02 — 전투

**ACTION**  
적 1기 돌진.  
리아: 회피 실패 직전 → 본능 대시 → 반격 1타.  
적 밀림. 탈출 경로 열림.  
손 떨림 여전. 기동 서툴지만 살아남음.

### CUT 03 — 엔딩

**ACTION**  
먼 하늘. 연기 가심.  
리아, 손 내려놓지 않음.

**DIALOGUE** (독백 1줄 또는 내레이션)  
「세계가 끝났는데, 나는 아직 여기 있다.」

## EP8. 선택의 무게

| 항목 | 값 |
|------|-----|
| 질문 | 카이를 지킬 수 있나? → 못 지킴 |
| 게임 목표 | 거점 사수 · 일부 달성 가능 |
| 스토리 | 카이 상실 (게임 클리어와 분리) |
| 광기 | 3 (멈췄다 쥠 · 잔상 가능 · 과부하=대가) |
| 카이 비트 | 「끝나면 내려.」 |
| 가져갈 문장 | 그 죽음을 헛되게 하지 않겠다. |

### CUT 01 — 압박

**ACTION**  
거점 압박. 카이 통신 유지.  
리아 광기 2→3 경계. 손 경련. 코피 한 방울.

**DIALOGUE**  
카이 「과부하 직전이다. 내려—」  
리아 「안 돼.」

### CUT 02 — 과부하 3초

**ACTION**  
시야 가장자리 균열. 조종 공백.  
치명 궤적 → 카이가 메움.

**DIALOGUE**  
카이 「끝나면 내려.」

**ACTION**  
피격. 통신 끊김.  
리아, 손 한 번 멈춤 → 꽉 쥠.  
잔상 0.5초 (카이 습관 동작 · 설명 없음).

### CUT 03 — 부분 성공

**UI** 거점 목표 일부 클리어

**ACTION**  
스토리 레이어: 카이 상실.  
(게임 클리어와 섞지 않음)

### CUT 04 — 엔딩

**ACTION**  
침묵. 빈 주파수.  
리아, 시선 전방. 말 거의 없음.

**DIALOGUE**  
리아 「…헛되게 안 해.」

**DIALOGUE** (독백/내레이션)  
「그 죽음을 헛되게 하지 않겠다.」
