# PLAY_DESIGN_6STEPS — 2026-08-06

> SoR: 플레이 재미 설계 6단계 확정

## 1. 핵심 플레이 루프
완료 (기존 루프 유지)

접근 → 콤보 → 밀기 → 필살 → 다음 무리

## 2. 플레이어 판타지
- **존재**: 소년만화 주인공
- **멋있는 순간**
  1. 각성 순간의 전율
  2. 초필살기로 보스 섬멸할 때의 희열

## 3. 진행(Progression) 시스템
- S-Core 단계 상승
- 필살 해금
- 기체 각성 단계

주요 상승은 **스토리/에피소드 진행**으로 한다.  
반복 파밍을 강제하지 않는다.

## 4. 미션 다양성 + 목표 변화
- 에피소드마다 미션이 다름
- 공격형 / 방어형 목표 혼재

## 5. 난이도 곡선 + 피드백
- 파워 상승을 직접 체감
- 클리어 시간 단축
- (점수 있을 경우) 점수 상승
- 이전엔 일격이 안 되던 적이 재조우 시 일격필살로 클리어

## 6. 한 판의 긴장감과 클라이맥스
- 직접 데미지를 받는다
- HP(또는 에너지) 0 → 미션 실패 → 재도전

---

## 전투 패턴 예시

### 1. 학살형 (성장 체감)
- 적: 소형 무리 8~12기
- 패턴: 돌진 → 둘러싸기 → 원거리 사격
- 플레이: 콤보 쓸어버리기 → 필살로 남은 무리 일괄 처리
- 피드백: 클리어 시간 단축, 이전 2~3타 → 1타

### 2. 방어형 (시간 압박)
- 목표: 거점/동료 보호
- 적: 중간 규모 + 돌파형 유닛
- 패턴: 일정 시간마다 돌파 유닛이 거점 직행
- 플레이: 우선순위 판단 → 돌파 유닛 먼저 → 나머지 학살
- 실패: 거점 HP 0 또는 플레이어 HP 0

### 3. 1:1 보스형 (긴장·각성)
- 페이즈 1: 정면 돌진 + 광역 베기
- 페이즈 2: 속도 상승 + 연속 콤보 (직접 데미지 위험 증가)
- 페이즈 3: 각성 타이밍 유도 → 초필살로 결정타
- 피드백: 각성 카메라·이펙트 + 초필살 타격감

### 4. 재조우형 (파워 상승 확인)
- 초반 힘든 중간 보스를 후반 재조우
- 이전: 여러 콤보 + 필살 필요
- 이후: 각성/강화 필살로 일격 처리

## 다음 미션 수치 표시 (초안)
- 미션 선택 화면: 필요 최소 수치 vs 현재 수치 (부족=빨강, 충분=초록)
- 부족 시 채우는 방법 표시 (스토리 진행 / 특정 조건)
- 파밍 강제 없음

## 원칙
- 파워 밸런스 유지
- 반복 파밍으로 지루하게 만들지 않음
- 학살 + 1:1 + 방어 + 성장 체감이 에피소드마다 섞임
