## 컷별 상세 (제작 메모)

### 1. EP1 임계
- **ACTION:** 조종석 손 클로즈 → 떨림 → 적 돌진 → 본능 대시 → 반격 1타 → 탈출 경로
- **DIALOGUE:** 카이「콜.」(H1) / 리아「…해봐야 알아.」
- **UI:** 동조율 — 임계
- **가져갈 문장:** 세계가 끝났는데, 나는 아직 여기 있다.
- 금지: 설정 강의 · 장문 · EP1 카이 시드로 「내리지 마」 사용 금지

### 2. EP5 균열
- **ACTION:** 몬투 등장 → 레이 하차 명령 → 대안 거부(튕김) → 재탑승 → 경련·코피 → 몬투 돌파 1회 · 카이 부상 통신
- **가져갈 문장:** 지키는 손이 곧 부수는 손이었다.
- 금지: 지휘부 장문 갈등

### 3. EP6 세스 격파
- **ACTION:** 세스 차단형 기동 → 격파 → 「…보고, 끝.」 → **원경 네메시스 시선 1컷**(말 없음) → 카이「콜.」
- **가져갈 문장:** 승리가 쌓여도 전망은 없었다.
- 금지: 세스 비극 주연

### 4. EP8 과부하 3초
- **ACTION:** 경련 → 시야 균열 → **조종 공백 ~3초** → 카이가 메움 → 피격 → 손 멈춤→꽉 쥠
- **DIALOGUE:** 카이「끝나면 내려.」 / 리아「…헛되게 안 해.」
- **가져갈 문장:** 그 죽음을 헛되게 하지 않겠다.
- 금지: 과부하 타 화 재연 · 슬로건

### 5. EP9 빈 주파수
- **ACTION:** 침묵 · 빈 채널 · 「콜.」메아리 0.5초 → 네메시스 전면 → 「아직 급이 아니다」 → 돌파(이기지 못함)·생존
- **가져갈 문장:** 혼자서는 달까지 못 간다. (그래도 간다)
- 금지: 열혈 구호 · 「급이 아니다」 외 장문

### 6. EP8→9 잔상 연결
- **ACTION:** EP8 엔딩 빈 주파수 → EP9 손이 통신 스위치를 찾는 습관(설명 없음)
- 목적: 애착→상실이 **몸**으로 이어짐을 검증

### 7. EP11 전조
- **ACTION:** 일시 엑셀리온 빛(완전 진화 아님) → 네메시스 한 발 후퇴=재평가(인정·공포 아님) → 손 한 번 멈춤(잔상)
- **가져갈 문장:** 여기서 끝내자.

### 8. EP12 붙잡기
- **ACTION:** 네메시스 오점·물건 시선 → 리아 수용 → 유나·레이 합류(이미 지켜보던 이들 · 구원 연출 금지)
- **가져갈 문장:** 끌려가지 않고, 붙잡았다.

### 9. EP13 진화
- **ACTION:** 실루엣 확장 1단계(날개·광윤·선 밀도) · **동일 골격** · 시야 전면
- **DIALOGUE:** 리아「여기까지야.」
- 금지: 완전 다른 로봇 교체 · 「급이 아니다」 재사용 · 「시작에 불과」 EP13 사용 금지

### 10. EP13 시간 벌기
- **ACTION:** 게이트 붕괴 → 세계 반응 1컷(침묵/통신/달 표면 택1) → 잔해 너머 **거대한 관측** 1컷(형태 불명)
- **DIALOGUE:** 리아「시간을 벌었다.」
- S1 클리어 = 시간 벌기 명시
