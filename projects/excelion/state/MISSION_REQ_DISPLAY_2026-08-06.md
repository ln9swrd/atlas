# MISSION_REQ_DISPLAY — 다음 미션 수치 표시

> 2026-08-06 · 플레이 설계 6단계 후속  
> 원칙: 파밍 강제 없음 · UI_MIN 유지 · 한눈에 이해

## 목적

플레이어가 미션 선택 시
1. 다음 미션에 필요한 최소 수치를 알고
2. 현재 자신의 수치를 비교하고
3. 부족하면 어디서 채울 수 있는지 바로 알 수 있게 한다.

---

## 표시 위치

**미션 선택 화면** (전투 중 UI가 아님)

기존 UI_MIN 3요소(동조율·목표·통신)와 분리. 전투 HUD에 추가하지 않는다.

---

## 표시 내용 (최소)

| 항목 | 표시 |
|------|------|
| 필요 | S-Core 단계 (예: III 이상) |
| 현재 | 내 S-Core 단계 |
| 상태 | 충분 = 초록 / 부족 = 빨강 |
| 보충 방법 | 한 줄 (예: 「EP5 클리어 시 상승」) |

### 예시

```
다음 미션: EP6 세스 저지
필요  S-Core III
현재  S-Core II   ← 빨강
채우기 EP5 클리어
```

충분할 때:
```
다음 미션: EP6 세스 저지
필요  S-Core III
현재  S-Core III  ← 초록
도전 가능
```

---

## 규칙

1. **주요 수치는 S-Core 단계만** 표시한다. (필살 해금·각성 단계는 스토리 진행에 묶여 있으므로 별도 강조하지 않음)
2. 부족해도 **도전은 가능**하다. (실패 위험만 높아짐)
3. 보충 방법은 **스토리/에피소드 진행**만 안내한다. 반복 파밍 경로를 안내하지 않는다.
4. 장문 설명·아이콘 나열·복잡한 스탯 창 금지.

---

## 밸런스 연동

- S-Core 배율: I 1.0 · II 1.3 · III 1.6 · IV EP13 (`BALANCE_SOR`)
- 권장 단계로 들어오면 적절한 긴장감
- 낮으면 실패 위험 상승 · 높으면 학살·일격 체감 증가
