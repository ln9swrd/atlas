## 2. 실루엣 구조

### 2.1 전체 인상

- 낮고 압축된 체형
- 상체를 작게 유지
- 하체와 전면 질량을 강조
- 여러 기체가 좁은 간격으로 몰려올 때 **하나의 압박 덩어리**로 읽힘

### 2.2 부위별

| 부위 | 방향 |
|------|------|
| 두부 | 낮고 각진 · 짧은 목 · 위압 없음 |
| 상체 | 작음 · 짧은 흉 · 전면 질량은 하체보다 약함 |
| 어깨·팔 | 두껍고 짧음 · 장비 일체감 · 길게 뻗지 않음 |
| 골반 | 넓음 · 저중심의 기준점 |
| 하체 | **상대적으로 큼** · 강한 허벅지·종아리 |
| 발 | 넓고 안정 · 접지감 |
| 전면 | 중간 돌출 · 돌진 인상을 보조하되 RAM FRAME만큼 전경 치우치지 않음 |

### 2.3 흑실루엣 검증 목표

멀리서(집단):
- 좁은 간격의 낮은 기둥들이 한 덩어리로 보임
- 상체 구분이 약하고 하체 질량이 먼저 읽힘

단독:
- 각 · 작음 · 양산 (ORD_SPEC 키워드 유지)
- HEAVY(넓·두껍·둔) · GUN(포신·돌출) · MID/몬투와 즉시 구분

## 3. 비율 구체화

| 축 | 값 방향 |
|----|---------|
| 전체 높이 | 낮음 · BRAVE 대비 작거나 비슷 · 위압 없음 |
| 상체 : 하체 | 상체 작음 / 하체 큼 |
| 중심 높이 | **낮음** (저중심) |
| 전면 돌출 | 중간 |
| 좌우 폭 | 골반·발 기준으로 안정 · 상체는 상대적으로 좁음 |
| 목 | 짧음 |
| 팔 길이 | 짧고 두꺼움 |
| 다리 비율 | 하체 강조 · 과도한 장신 금지 |

비율 원칙: **압축**과 **집단 시 기둥 실루엣**이 깨지지 않게 유지한다.

---

## 4. 식별 포인트

### 4.1 1순위 (집단)

- 좁은 간격으로 몰려오는 **낮은 기둥 무리**
- 전면 질량 + 강한 하체가 합쳐진 압박 덩어리
- 스폰 직후부터 “많이 온다”가 실루엣만으로 전달

### 4.2 2순위 (단독)

- 각진 두부 + 짧은 몸
- 저중심 · 넓은 골반 · 강한 하체
- 사람형 조종 로봇 인상 약화 · 투기 기계 인상 강화

### 4.3 타 기체와의 구분

| 대비 | 구분 포인트 |
|------|-------------|
| HEAVY | GRUNT는 더 작고 압축 · HEAVY는 넓·두껍·둔 |
| GUN | GRUNT는 포신·원거리 돌출 없음 |
| MID/몬투 | GRUNT는 병기 과다·중형 존재감 없음 |
| 세스 | GRUNT는 단정·차단·위계 없음 |
| 네메시스 | GRUNT는 길이·고중심·위계 금지 |
| BRAVE | GRUNT는 여백·여성형·호박 accent 없음 |

## 5. 3TONE 방향

`MECHA_3TONE_LOW_DETAIL` 준수 · 최대 3톤 · 대형 면 중심 · 과도한 패널 분할 금지.

| 톤 | 방향 | 면적 |
|----|------|------|
| **T1 주색** | 산화철 계열 (철녹·적갈 저채도) | 60–70% · 넓은 장갑 |
| **T2 보조** | 흙·암회 | 20–30% · 흉·팔·다리 구분 |
| **T3 포인트** | 센서 적/냉점 | 5–10% · 눈·센서만 |

규칙:
- 큰 면 단위의 명암 구분 우선
- 패널라인으로 개성 만들지 않음
- 아군 호박 accent 금지
- 4톤 이상 · Level 4+ 패널 금지

---

## 6. 전투 역할과의 연결

| 단계 | 실루엣이 전달할 것 |
|------|-------------------|
| 스폰 | 낮은 기둥들이 한꺼번에 나타남 |
| 접근 | 간격이 좁아지며 하나의 압박 덩어리로 합쳐짐 |
| 압박 | 전면 질량 + 하체 추진이 화면을 채움 |
| 파괴 | 개별은 쉽게 무너짐 · 집단 압력은 수로 유지 |

“고급 병기”가 아니라 **저가 양산 · 소모 · 떼로 덮침**이 실루엣만으로 읽혀야 한다.
