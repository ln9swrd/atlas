## 4. Pressure — 플레이어 압박 방식

| 패턴 | 내용 | 플레이어 대응 방향 |
|------|------|-------------------|
| **수 압박** | GRUNT 다수 동시 접근 | 끊기 · 한 줄씩 처리 |
| **시야 오염** | 낮은 기둥이 화면을 채움 | 거리 확보 · 집단 단위 타격 |
| **혼합 물결** | GRUNT 주력 + HEAVY/GUN 소량 | 역할 분담 (돌파/엄호) |

압박의 본질:
- 개별 DPS가 아니라 **동시 출현 수**
- “많이 온다”가 실루엣·행동 모두에서 일치

금지:
- 개인 필살 연출
- 도주·항복·감정 대사
- 보스 페이즈 전환 연출 차용

## 5. Break — 쉽게 파괴되는 조건

| 항목 | 규칙 |
|------|------|
| HP | `BALANCE_ENEMY_MULT` **15** (BRAVE 1.0 기준 · 참고) |
| 1히트 DMG | 적→플레이어 **4–6** (참고) |
| 성격 | 단독 화력 약함 · **한 줄로 묶이면 끊김** |
| 파괴 피드백 | 기동 정지 · 보고·감정 없음 |
| 목표 TTK | 단기 처치는 빠르게 · 집단은 수로 유지 (B3 TTK 구간 TBD) |

원칙:
- “쉽게 파괴” = 개별이 약함
- “압박 유지” = 수가 충분함

## 7. Telegraph — 집단 인식 신호

플레이어가 **실루엣만으로** 집단을 읽게 한다.

| 거리 | 신호 |
|------|------|
| 원거리 | 낮은 기둥들이 좁은 간격으로 출현 |
| 중거리 | 간격이 좁아지며 **하나의 압박 덩어리**로 합쳐짐 |
| 근거리 | 전면 질량 + 하체 추진이 화면을 채움 |

텔레그래프 원칙:
- 정직 · 과장된 예고 연출 최소
- 보스식 Phase 왜곡 텔레그래프 **비적용**
- 색·이펙트로만 구분하지 않음 · **형태·배치**가 1순위
