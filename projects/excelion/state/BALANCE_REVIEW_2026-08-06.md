# 밸런스 B단계 검토·보완 — 2026-08-06

## 1. 총평

| 항목 | 평가 |
|------|------|
| 절차 (B0→B6) | 완결 · 재개 가능 |
| 스토리·광기 정합 | B5 PASS · 양호 |
| 수치 일관성 | **이중 단위** 잔존 (레거시×10) |
| 실기 준비도 | 문서 초안 수준 · 시뮬 미실시 |

**결론:** 승격 유지 가능. 아래 **필수 보완**만 반영하면 SoR 품질이 안정된다.

## 2. 발견된 문제

### P1 — 상태 표기 불일치 (필수)

| 문서 | 문제 |
|------|------|
| `BALANCE_ENEMY_MULT` 등 | 헤더에 여전히 DRAFT (B4–B5 전) |
| B6 후 | SoR는 승격됐는데 하위 문서 상태가 안 맞음 |

→ 하위 문서를 **CONFIRMED (실기 전)** 으로 통일.

### P2 — 이중 단위 (필수 문서화)

| 스케일 | 예 |
|--------|-----|
| 레거시 | 세스 HP 48 · 필살 4 |
| SoR (B1) | 세스 HP 480 · 필살 40 |

위험: `BOSS_STATS`·`02_COMBAT`·`05_ENEMY`를 직접 수정할 때 ×10 누락.

→ SoR에 **단일 진실** 선언: 구현·튜닝은 B1 스케일만. 레거시는 환산 참조.

### P3 — 적 화력 절대값 부족 (권고)

ORD 표의 「화력 배수」만 있고 **1히트 DMG**가 없음.  
세스만 8–22 절대값이 있음.

→ GRUNT/HEAVY/GUN/MID 피격 DMG 한 줄씩 보강.

### P4 — EP9 vs EP10–12 HP (의도 확인)

아슈르 EP9 **720** > EP10–12 **560–640**.  
스토리상 전면 첫 대면이 더 무거운 것은 가능하나, 숫자만 보면 “약해짐”으로 읽힘.

→ 주석: EP9=존재감 벽 · EP10–12=압박 리듬(짧은 교전·반복)용 풀 조정 **의도**.

### P5 — S-Core 충전 검산 공백 (권고)

가정 +1.5/s×배율 + 타격+2 만으로 필살 주기 명문 검산 없음.

→ 샘플: I구간 전투 30s ≈ 시간 45 + 타격 10회×2=20 → 65 ≥50 **필살 1회 가능** 명시.

### P6 — 범위 밖 (보류)

- 드론·날개 모드 스탯
- 히트박스·액티브 프레임
- 회복 아이템
- 난이도 모드
- 실기 DPS 로그

시각화·포지 Hold와 동일하게 **별 트랙**.
