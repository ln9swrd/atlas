---

## 1. 문제

플레이테스트: 스테이지 **클리어**만 보이면 플레이어가 **카이 생존**으로 오해할 수 있음.  
설계는 이미 **두 층**을 분리함 (`VERTICAL_SLICE` EP8). 이 문서는 **결과 화면/연출 순서**만 고정한다.

---

## 2. 영역 정의

| 영역 | 정의 | 기존 클리어 조건 (변경 없음) |
|------|------|------------------------------|
| **Gameplay Result** | 전투·미션 수치 결과 | **Clear:** 거점 유지 · 제한 목표 달성  
**Fail:** 거점 HP 0 또는 플레이어 HP 0 |
| **Story Result** | EP8 서사 층 | 과부하 3초 → 카이 메움·피격 → 통신 끊김 → **상실 고정**  
재도전해도 스토리상 카이 복귀 **없음** |

두 영역은 **독립 플래그**. 한쪽이 다른 쪽을 덮어쓰지 않음.

---

## 3. 표시 순서 (혼동 방지)

권장 시퀀스 (구현 전 연출 계약):

```
1) 인게임 비트 종료
   · H3「끝나면 내려.」→ 피격·끊김 (스토리 비트, 기존 대본)
2) 짧은 침묵 / 빈 주파수 (CUT 05 계열)
3) Result Sheet — 구역 A: Gameplay Result
4) Result Sheet — 구역 B: Story Result  (A와 시각적으로 분리)
5) 리아「…헛되게 안 해.」/ 가져갈 문장 (기존 캐논)
6) 진행 (다음 EP) 또는 재도전 선택
```

규칙:
- **Story Result를 Gameplay Clear 배너 안에 넣지 않음**
- Gameplay Clear 아이콘/색과 Story Loss 아이콘/색 **동일 팔레트 금지** (TBD 구체 색)
- 한 화면에 두 블록이 동시에 보여도 **레이블이 다름**

---

## 4. 최소 카피 (캐논 비훼손)

기존 대본·슬라이스 문장만 사용. **신규 슬로건 창작 없음.**

### 4.1 Gameplay Result

| 상태 | 레이블 (제안) | 본문 카피 (최소) |
|------|---------------|------------------|
| Clear | **작전 결과** | 거점 유지 · 목표 일부 달성  
  (UI 기존: 「거점 목표 일부 클리어」와 정합) |
| Fail | **작전 결과** | 거점 상실 또는 기체 전투 불능 |

### 4.2 Story Result

| 상태 | 레이블 (제안) | 본문 카피 (최소) |
|------|---------------|------------------|
| Loss (고정) | **통신** | 채널 단절 · 카이 응답 없음  
  (대본: 빈 주파수 · 「끝나면 내려.」 직후 끊김) |
| (표시 보조) | — | 리아「…헛되게 안 해.」는 **결과 시트 밖** 연출 컷으로 유지 가능 |

가져갈 문장 (기존): 「그 죽음을 헛되게 하지 않겠다.」 — 결과 시트 하단 또는 페이드 후 1회.

금지 카피:
- 「카이를 구했다」
- 「전원 생존」
- Clear와 동일 문구로 상실을 가림
- 슬로건 “카이를 위해” 남발

## 5. 예외 매트릭스 (플레이 vs 스토리)

| Gameplay | Story | 표시 |
|----------|-------|------|
| **Clear** | **Loss** | **정상 EP8 주 경로** · 두 블록 모두 표시 · 혼동 방지 최우선 |
| **Fail** | **Loss** | 작전 실패 + 통신 단절 · 재도전 시 **스토리 Loss 유지** |
| Clear | (Loss 미발생) | **EP8 설계상 비정상** · 스펙 외 · 구현 시 스토리 비트 스킵 금지 |
| Fail | (Loss 미발생) | 스펙 외 · 과부하 전 전멸 등 · TBD |

**재도전:** Gameplay만 리셋. Story Loss 플래그는 세션/세이브에 **잔류** (VERTICAL_SLICE 고정).

## 6. 레이아웃 스케치 (논리만)

```
┌─────────────────────────────┐
│  [작전 결과]  Clear / Fail  │  ← Gameplay Result
│  거점 … · 목표 …            │
├─────────────────────────────┤  ← 구분선 (필수)
│  [통신]  채널 단절          │  ← Story Result
│  응답 없음                  │
└─────────────────────────────┘
        (이후 연출 컷 / 문장)
```

단일 “MISSION COMPLETE” 풀스크린만 쓰는 구성 **금지**.
