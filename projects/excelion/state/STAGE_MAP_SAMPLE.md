## EP15 「팀」 — 균열 지대 전선

### 목표
전선 유지 + 거점/민간 사수 · 세크 격파는 수단.

### 레이아웃 (텍스트)

```
        [능선 GUN 가능]
              |
  [좌 파도] — [중앙 축] — [우 파도]
              |
         [세크 스폰]
              |
         [거점 / 사수선]
              |
         [아군 출격]
```

| 구역 | 내용 |
|------|------|
| 중앙 축 | 세크 주 동선 · 방패면 정면 |
| 좌·우 파도 | ORD GRUNT/HEAVY 유입 · 팀 엄호 구간 |
| 능선 | GUN 견제 · 유나 관측 콜 |
| 거점 | 사수 실패 = 스테이지 실패 가능 |

### 페이즈

| P | 조건 | 맵 변화 |
|---|------|---------|
| 1 | 세크 HP > 30% | 파도 주기 유입 · 실드 전개 |
| 2 | HP ≤ 30% 또는 게이지 0 | 실드 재전개 1회 · 보고 처리 창 |

### 클리어 / 실패

| | |
|--|--|
| 클리어 | 세크 HP 0 **또는** 제한 시간 내 거점 사수 + 전선 유지 |
| 실패 | 거점 붕괴 · 전선 완전 봉쇄 |

팀: 리아 돌파 · 엄호 측면 · 유나 관측 · 레이 숫자.

## EP21 「방패」 — 게이트 입구

### 목표
와제 격파 → 길이 열림. 네메시스 흔들림 없음.

### 레이아웃 (텍스트)

```
        [게이트 내부 →]
              |
      [와제 방패면]
     /        |        \
 [측면 창]  [정면]  [측면 창]
     \        |        /
      [접근 통로 · 폭 제한]
              |
         [아군 출격]
```

| 구역 | 내용 |
|------|------|
| 정면 | 방패면 · 직선 무효 · 반격 창 |
| 측면 창 | 게이지 파열 후 유효 · 좁은 각도 |
| 통로 | 폭 제한 · P2 「문 닫힘」 시 더 좁아짐 |
| 게이트 너머 | 클리어 후 진입만 · 전투 없음 |

### 페이즈

| P | 조건 | 맵 변화 |
|---|------|---------|
| 1 | 게이지 > 0 | 방패면 전면 · 반격 임계 |
| 2 | 게이지 0 또는 HP ≤ 40% | 문 닫힘 · 측면 창 강조 |

### 클리어 / 실패

| | |
|--|--|
| 클리어 | 와제 HP 0 → 방패면 정지 · 통로 개방 |
| 실패 | 타임아웃 · 전멸 |

금지: 네메시스 대사 복제 · 오만 연출 · 장엄 폭발 과다.
