## 0. 한 줄

세스는 리아의 **계단**이다. 라이벌도, 비극 주연도, 대칭 인물도 아니다.  
“넘어야 할 첫 벽(가능 격파)”이며, 네메시스라는 **최종 벽**과 층을 나눈다.

---

## 1. 관계의 본질

| 축 | 리아 | 세스 |
|----|------|------|
| 존재 | 선택·집념으로 타는 아이 | 역할 수행자 · 도구 |
| 전투 의미 | 처음으로 **손으로 부수는** 등급 | 전선을 닫는 처리 |
| 감정 | 애착·상실·광기는 **카이·자기** 쪽 | 거의 없음 · 균열 ≤1/장면 |
| 패배/승리 | 대가·성장의 증거 | 「…보고, 끝.」 · 절규 없음 |
| 이후 | 세스를 **재감정화하지 않음** | 이미 처리된 계단 |

- 세스는 리아를 “라이벌”로 보지 않는다. **처리 대상**이다.  
- 리아는 세스를 “미워할 대상”으로 키우지 않는다. **막힌 전선**으로 만난다.  
- 카이 대칭 라이벌 연출 **금지**.

---

## 2. 서사 기능

```
생존자 (초반)
  → 계단(세스) 격파
  → 상실(카이)
  → 벽(네메시스)
  → …
```

| 기능 | 내용 |
|------|------|
| 계단 | 격파 가능 · 네메시스 미만 · “할 수 있다”의 첫 증명 |
| 대비 | 세스=역할 처리 / 네메시스=등급 판정 |
| 정리 | EP6 전후 클리어 후 **재등장·사연 확장 없음** (도구 소진) |

후반(EP14+)에서 세스 **재감정화 없음**. 크레일 등 동급 도구로만 위계 구조가 회수된다.

---

## 3. 상호 시선

### 세스 → 리아

- 평가: 처리해야 할 변수. 오만 과시 없음.  
- 말: 짧음. 보고 문장. 호칭·설교 없음.  
- 패배 시: 무전 단절 · 「…보고, 끝.」 · 감정 폭발 없음.

### 리아 → 세스

- 평가: 막힌 전선 · 손으로 넘을 벽.  
- 성장: 세스전에서 **손·집념**이 처음으로 등급을 움직인다.  
- 이후: 이름을 붙잡아 복수 서사로 만들지 않음. 다음 벽은 네메시스.

---

## 4. EP 비트 (권장)

| EP | 관계 표현 |
|----|-----------|
| 4–5 | 세스 존재·전선 암시 |
| 6 | 본전 · 격파 · 「…보고, 끝.」 |
| 6 직후 | 네메시스 원경 1컷 (세스≠최종) |
| 7+ | 세스 재감정·재대결 없음 |
| 16 | “역할 모듈” 회수 시 세스·크레일 **같은 층**으로만 언급 |

---

## 5. 금지

| 금지 | 이유 |
|------|------|
| 카이 대칭 라이벌 | 상실 축 오염 · 세스 주연화 |
| 세스 비극·사연 장문 | 도구 층 붕괴 |
| 세스 숭배·네메시스 대행 과잉 | 관계 층 혼선 |
| 격파 후 복수·집착 서사 | 계단 기능 소진 후 군더더기 |
| 세스=작은 네메시스 | 실루엣·태도·패배 대사로 구분 필수 |

---

## 6. 한 줄 정리

리아에게 세스는 **처음으로 부순 문**이고,  
세스에게 리아는 **처리하다 끊긴 보고**다.  
그 이상도 이하도 붙이지 않는다.
