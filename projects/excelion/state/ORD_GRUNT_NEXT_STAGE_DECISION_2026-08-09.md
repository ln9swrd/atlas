## 4. 다음 단계 선택지

### A. Visualization

텍스트를 **시각 산출**로 검증한다.

가능한 하위 (승인 시 하나만 지정):
- A1 흑실루엣만 (집단·단독)
- A2 컨셉 정지컷 (3TONE 방향 반영)
- A3 삼면도 착수

### B. 추가 텍스트 설계

시각화 없이 문서만 보강한다.

예:
- 최종 LOCK 문장만 추가
- HEAVY/GUN과의 대비 표 확장
- 스테이지 배치 **서술**(수치 확정 없이)

### C. HOLD

후속 작업 없음. 텍스트 패키지·Gate 유지.

## 5. 선택지별 진입 조건

### A. Visualization

| 항목 | 내용 |
|------|------|
| 필요 승인 | **Master** — 시각화 착수 명시 + 하위 유형(A1/A2/A3) 지정 |
| 추가 결정 | 산출 포맷 · 저장 경로 · 참조할 텍스트 범위 · (선택) 최종 LOCK 선행 여부 |
| 금지 (승인 범위 밖) | 미지정 하위 유형 실행 · Meshy/UE/M5를 승인 없이 포함 · 캐논·수치 확정 · 기존 4+Gate 문서 본문 임의 개서 |

진입 후도 **별도 승인** 없이 B로 회귀하거나 C로 바꾸지 않음. 범위 변경 시 재승인.

### B. 추가 텍스트 설계

| 항목 | 내용 |
|------|------|
| 필요 승인 | **Master** — 추가 텍스트 주제 1개 지정 |

| 금지 | 이미지·삼면도·Meshy·UE·M5·코드 · 신규 수치 확정 · 캐논 본문 변경 · 주제 미지정 다문서 난립 |

| 금지 | 자동으로 A/B 착수 · 임의 PR로 시각화/구현 진행 |

## 6. 권고안 (최종 결정은 Master)

**권고: C. HOLD** 를 기본으로 두고, 시각 검증이 당장 필요할 때만 **A1(흑실루엣만)** 을 최소 범위로 승인한다.

근거:
1. 텍스트 패키지 정합 완료 · CONFLICT 0 — 문서 추가의 낮음
2. DESIGN GATE가 이미 시각화/구현을 Master 승인 전까지 STOP으로 고정
3. 최종 LOCK·치수·Meshy/UE 경로는 미확정 — 조기 고비용 산출은 재작업 위험
4. A1은 실루엣 가설만 검증하고 3TONE·삼면도·파이프라인 결정을 미룸
5. B는 shortlist·정합이 끝난 뒤라 중복 문서 위험이 큼 — 주제 1개로 제한할 때만 유효

**이 권고는 강제 결정이 아니다.** Master가 A/B/C 중 하나를 명시하면 그 범위만 착수한다.

## 7. Master 응답 템플릿 (선택)

다음 중 하나만 지정하면 충분하다.

```text
DECISION: A1 | A2 | A3 | B | C
SCOPE: (한 줄)
NOTES: (선택)
```

예:
- `DECISION: C` — HOLD 유지
- `DECISION: A1` / `SCOPE: SWARM COLUMN 흑실루엣 집단·단독만`
- `DECISION: B` / `SCOPE: 최종 LOCK 문장 문서 1개`
