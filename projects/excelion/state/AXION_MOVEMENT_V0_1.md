## 승인된 설계

### 1. 기본 이동
- 이동 기준: 카메라 기준
- W: 카메라 전방
- S: 카메라 후방
- A: 카메라 기준 좌측
- D: 카메라 기준 우측
- 마우스: 시점 제어
- 약한 가속/감속

### 2. 회피 (짧은 대시)
- 별도 회피 입력
- 순간적인 이동
- 과도한 고속 이동은 지양
- 대시 중 방향 전환: 불가

#### 대시 방향 규칙
1. WASD 입력이 있는 경우 → 입력 방향으로 대시
2. WASD 입력이 없는 경우 → 캐릭터 정면 방향으로 대시

#### 대시 수치 (전부 미정)
- 대시 거리: 미정
- 대시 시간: 미정
- 쿨다운: 미정
- 무적시간: 미정
- 공중 대시: 미정
- → PIE에서 기본 구현 확인 후 별도 결정

### 3. 구현 순서
1. 기본 이동
2. 가속/감속
3. 대시
4. PIE 검증
