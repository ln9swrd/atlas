# DEVELOPMENT ROADMAP (개발 로드맵)

> Status : Draft
> Version : 0.1
> Last Updated : 2026-07-01

---

# 문서의 목적

이 문서는 EXCELION 프로젝트의 장기 개발 계획을 정의한다.

모든 개발은 단계별 목표를 달성한 후 다음 단계로 진행한다.

---

# 개발 철학

EXCELION은 기능을 많이 만드는 프로젝트가 아니다.

"작지만 완성도 높은 기능"을 차례대로 쌓아가는 프로젝트이다.

각 단계는 반드시 플레이 가능한 상태를 유지한다.

---

# Phase 0 : Foundation

목표

개발 환경 구축

완료 조건

* GitHub 저장소 구성
* Unreal 프로젝트 생성
* Blender 작업 환경 구성
* Excelion Forge 애드온 연결
* 프로젝트 문서 작성 완료

결과물

개발을 시작할 수 있는 환경

# Phase 1 : Core Movement

목표

구현 항목

* 회전
* 카메라
* 부스트
* 점프(필요 시)
* 착지
* 기본 애니메이션

조작만으로도 재미를 느낄 수 있다.

# Phase 2 : Combat

# 단계 이동 원칙

다음 단계로 넘어가기 전에 반드시 이전 단계를 완료한다.

단계를 건너뛰지 않는다.

---

# 성공 기준

성공은 기능 수가 아니라

플레이 경험으로 판단한다.

매 단계가 끝날 때마다

"지금도 재미있는가?"

를 확인한다.

---

# 장기 목표

EXCELION은 하나의 게임이 아니라

장기적으로 성장하는 메카 IP의 첫 번째 작품이다.
