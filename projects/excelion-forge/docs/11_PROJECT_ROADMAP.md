# PROJECT_ROADMAP (프로젝트 로드맵)

> Status : Draft
> Version : 0.1
> Last Updated : 2026-07-01

---

# 문서의 목적

이 문서는 EXCELION 프로젝트의 전체 개발 계획을 정의한다.

각 단계의 목표를 명확하게 구분하여 개발 범위를 통제한다.

---

# 개발 단계

EXCELION은 다음 순서로 개발한다.

Design Bible

↓

Prototype

↓

Vertical Slice

↓

Alpha

↓

Beta

↓

Steam Release

---

# Phase 0 : Design Bible

목표

프로젝트의 방향성을 확정한다.

완료 조건

* 핵심 문서 작성
* 개발 원칙 확정
* 게임 루프 확정

---

# Phase 1 : Prototype

목표

전투의 재미를 검증한다.

완료 조건

* 이동
* 락온
* 메가 캐논
* Heat / Resonance
* 보스전
* 미션 완료

출시하지 않는다.

---

# Phase 2 : Vertical Slice

목표

Steam에서 보여줄 수 있는 수준의 데모를 만든다.

포함 내용

* 미션 1개
* EXCELION Proto
* 보스 1기
* UI
* 사운드
* 연출

이 단계에서 게임의 최종 품질 기준을 확정한다.

---

# Phase 3 : Alpha

목표

게임 전체를 처음부터 끝까지 플레이할 수 있도록 만든다.

임시 리소스를 사용해도 된다.

모든 시스템이 연결되어 있어야 한다.

---

# Phase 4 : Beta

목표

콘텐츠를 완성한다.

버그 수정

최적화

밸런스 조정

사운드 보완

이펙트 보완

---

# Phase 5 : Release

목표

Steam 정식 출시

출시 이후

* 버그 수정
* 콘텐츠 업데이트
* DLC 검토

를 진행한다.

---

# 개발 원칙

다음 단계로 넘어가기 전에

이전 단계를 반드시 완료한다.

Prototype가 완성되지 않았다면

Vertical Slice를 시작하지 않는다.

---

# 성공 기준

각 단계는

'얼마나 많이 만들었는가'

가 아니라

'목표를 달성했는가'

로 판단한다.
