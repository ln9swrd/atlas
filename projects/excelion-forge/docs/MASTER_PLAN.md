# 프로젝트 목표

Excelion은 1인 개발 프로젝트이다.

궁극적인 목표는 Steam에 게임을 출시하고, 지속적인 수익을 창출할 수 있는 오리지널 메카 IP를 구축하는 것이다.

---

# 성공 기준

프로젝트의 성공은 다음 순서로 판단한다.

1. Prototype 완성
2. Vertical Slice 완성
3. Steam 출시
4. 첫 판매 발생
5. 지속적인 업데이트
6. DLC 또는 후속작 개발

---

# 개발 우선순위

항상 아래 순서를 따른다.

## 1순위

게임의 재미

---

## 2순위

---

## 3순위

## 4순위

# 절대 하지 않을 것

다음 항목은 Prototype 단계에서 구현하지 않는다.

* 오픈월드
* 멀티플레이
* PvP
* 제작 시스템
* 랜덤 장비 파밍
* 복잡한 인벤토리
* 방대한 스토리

---

# 강점 활용

프로젝트의 가장 큰 강점은 다음과 같다.

* 메카 디자인
* 3D 모델링
* 애니메이션
* 연출

모든 개발은 이 강점을 중심으로 진행한다.

---

# AI 활용

AI는 다음 영역에서 적극 활용한다.

* C++ 코드 작성
* Blueprint 설계
* 문서 작성
* 테스트 코드 작성
* 아이콘 초안
* 음성 초안
* 번역

창작의 방향성과 최종 품질은 개발자가 결정한다.

---

# 개발 원칙

새로운 기능을 추가하기 전에 항상 다음 질문을 한다.

"이 기능은 Steam 출시를 더 빠르게 만드는가?"

아니라면 보류한다.

---

# 품질 원칙

모든 기능은

완성 → 테스트 → Git Commit

순서로 진행한다.

미완성 기능을 여러 개 동시에 개발하지 않는다.

---

# 종료 조건

Excelion은 출시 후에도 계속 발전한다.

프로젝트는 게임 하나가 아니라,

장기적으로 성장하는 IP를 만드는 것을 목표로 한다.
