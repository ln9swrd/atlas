## 시나리오 1: 몬투 첫 조우

| 항목 | 내용 |
|------|------|
| 목표 | P1에서 약점 창 1회 이상 성공 · P3 폭발 1회 생존 |
| 예상 시간 | 3–5분 / 런 |
| 성공 기준 | 클리어 또는 HP 30% 이상에서 P3 진입 후 60s 생존 |
| 실패 원인 관찰 | 반응(압축·폭발) 비율 |
| 기록 | 창 성공 횟수 · 압축 피격 횟수 |

---

## 시나리오 2: 세스 씰 학습

| 항목 | 내용 |
|------|------|
| 목표 | P1 정답 씰 1회 · P2 페이크 회피 1회 |
| 예상 시간 | 4–7분 / 런 |
| 성공 기준 | 이중 씰까지 도달 · 또는 클리어 |
| 실패 원인 관찰 | 판단(잘못된 씰) 비율 |
| 기록 | 정답/오답 씰 · 봉인 발동 횟수 |

---

## 시나리오 3: 아누비스 왜곡 적응

| 항목 | 내용 |
|------|------|
| 목표 | P2 길이 혼재 대응 · P3 실선만 회피 |
| 예상 시간 | 3.5–5.5분 / 런 |
| 성공 기준 | 인지 왜곡 1회 통과 · 클리어 또는 P3 40s 생존 |
| 실패 원인 관찰 | 정보·판단 비율 |
| 기록 | 점선 오반응 횟수 · 왜곡 중 피격 |
