# AXION WalkFrontCorrection Report

## 1. 작업 개요
*   **목적**: 기존 `AXION_Walk_Cycle_Final` 액션의 Side View(측면 걷기) 움직임과 뼈대 구조를 100% 유지하면서, Front View(정면)에서 보았을 때 다리와 팔의 좌우 폭(X축)을 인간/로봇의 보행 각도에 맞게 보정.
*   **핵심 제약**: Bone Twist 방지, IK Flip 방지, 뼈대/제약 조건 구조(Hierarchy/Constraint/Pole Angle) 변경 절대 금지.

## 2. 좌표계 검증 (안전 장치)
스크립트를 통한 오프셋 주입 전, Blender 내 `axion.blend`의 실제 좌표계를 수학적으로 정밀 측정했습니다. (추측 배제)
*   `foot_ik.L`, `hand_ik.L` 등 왼쪽 제어기의 **Local +X는 World -X(왼쪽/바깥쪽)**를 향함.
*   따라서 왼쪽 다리/팔을 몸 안쪽(오른쪽)으로 당기려면 **음수(-X)** 값을 주어야 함.
*   `knee_pole.L/R`과 `elbow_pole.L/R` 역시 위치 이동에 따른 월드 축 변화를 측정 완료하여 교차(Cross)로 인한 역관절 방지.

## 3. 다리 보정 상세 (Legs Lateral Correction)
초기 모델링(Rest Pose)이 'A-Pose'처럼 매우 넓게 벌어져 있어, 기존 걷기에서 다리가 비정상적으로 넓게 벌어지던 현상을 완전히 수정했습니다.

*   **디딛는 발 (Planted Foot):** 
    *   `foot_ik.L/R`의 X값을 안쪽으로 강하게 당겨(`-150` ~ `-100`), 발바닥이 몸통의 무게중심(Center of Gravity) 선상을 딛도록 수정했습니다.
    *   결과적으로 허벅지(`thigh.L/R`)가 A자 형태에서 **11자에 가까운 자연스러운 보행 각도**로 떨어지게 되었습니다.
*   **스윙하는 발 (Passing Foot):**
    *   발이 교차할 때 서로 부딪히지 않도록, 디딛는 발보다는 바깥쪽으로 아주 살짝 호를 그리며(`-80` ~ `0`) 나가도록 X축 값을 차등 적용했습니다.
*   **무릎 방향:**
    *   무릎 폴 타겟(`knee_pole`)을 살짝 바깥쪽(`+50`)으로 유지하여 걷는 내내 로봇 특유의 당당한 폼(약간 팔자 느낌)을 유지하고 안짱다리가 되는 것을 방지했습니다.

## 4. 팔 보정 상세 (Arms Lateral Correction)
팔이 몸통과 완전히 겹치는 현상을 막고 자연스러운 스윙 아크(Arc)를 추가했습니다.

*   **스윙 (Arm Swing Arc):**
    *   팔이 뒤로 갈 때: 몸 바깥쪽으로 살짝 벌어짐 (`hand_ik` X = `+40`)
    *   팔이 앞으로 갈 때: 가슴 안쪽으로 살짝 모임 (`hand_ik` X = `-40`)
*   **팔꿈치 (Elbow Flare):**
    *   팔꿈치가 몸통을 파고들거나 뒤집히지 않도록 `elbow_pole`을 항상 몸 바깥쪽(`X = -150`)에 고정하여, 어깨→팔꿈치→손목으로 이어지는 삼각형 구도가 안정적으로 유지되도록 했습니다.

## 5. 상체 보정 (Torso Sway)
*   오른발/왼발로 무게중심이 넘어갈 때, 골반(`root`)이 디딛는 다리 방향으로 미세하게(`X = 15` ~ `25`) 이동하는 Sway(좌우 체중 이동)를 추가하여 기계적인 딱딱함을 줄였습니다.

## 6. 검증 결과
*   **Side View**: 기존 보폭, 무릎 굽힘, 발 이동 타이밍 100% 유지 확인.
*   **Front View**: 벌어져 있던 다리가 보행선으로 모이고, 팔이 입체적으로 스윙함.
*   **안전성**: 중간 프레임에서 무릎/팔꿈치가 꺾이거나 뒤집히는(IK Flip) 현상 발견되지 않음. 이전 작업에서 맞춘 Pole Angle이 완벽하게 작동하여 Bone Twist 재발 없음.
