# 게임 **엑셀리온(Excellion)** 프로젝트 정리 (Markdown)

```
# 엑셀리온 (Excellion) 프로젝트 정리

## 프로젝트 목표
- 오리지널 메카 세계관 구축
- 슈퍼로봇과 리얼로봇의 장점을 결합한 디자인
- 3D 프린팅과 게임 제작을 동시에 고려한 설계
- 파라메트릭 모델링을 활용하여 다양한 기체를 빠르게 제작

---

# 디자인 방향

## 장르
- 모던 슈퍼로봇
- SF + 생체기계(Biomechanical)
- 일본 슈퍼로봇 감성과 현대적인 메카닉 디자인의 융합

## 기본 특징

- 약 25m급 메카
- 유선형 실루엣
- 지나치게 복잡하지 않은 외형
- 기계적 구조 속에 생물적인 흐름 표현

---

# 개발 방식

## 파라메트릭 제작

목표

- 기본 메쉬를 스크립트로 생성
- 필요한 부분만 수작업 수정
- 파라미터로 비율 조정

예상 작업 흐름

1. 스크립트 생성
2. 기본 메쉬 출력
3. 디테일 수정
4. 파라미터 저장
5. 다른 기체로 재사용

장점

- 양산형 제작 가능
- 보스 기체 제작 가능
- 잡몹 제작 가능
- 개발 속도 향상

---

# 메카 디자인 철학

## 슈퍼로봇 요소

- 강한 존재감
- 영웅적인 실루엣
- 과장된 비율
- 상징적인 무장

## 리얼로봇 요소

- 설득력 있는 구조
- 내부 프레임
- 기계적 디테일
- 기능 중심 설계

---

# 디자인 피드백

## 선호

- 완만한 유선형
- 지나친 서양풍 지양
- 어깨는 단순하고 힘 있는 형태
- 드론 또는 핀 판넬 계열 무장
- 사출과 회수가 가능한 보조 무장

---

# 제작 목표

- 플레이어 기체
- 적 양산기
- 중형 적
- 보스 기체

모두 동일한 파라메트릭 시스템으로 제작

---

# 향후 계획

- 파라메트릭 메카 생성기 구축
- 기본 골격 자동 생성
- 다양한 무장 모듈 제작
- 내부 프레임 설계
- 3D 프린팅 대응
- 게임용 모델 최적화

---

# 핵심 키워드

- Modern Super Robot
- Biomechanical
- Parametric Design
- Modular System
- 3D Printing
- Hero Mecha
- Mass Production Units
- Boss Mecha
```
