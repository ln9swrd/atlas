# 069. Atlas Context 상태관리

## 핵심

- 프로젝트별 `docs/` 공통 구조: README, VISION, PURPOSE, ARCHITECTURE, DESIGN, ROADMAP, CHANGELOG, DECISIONS.

- 루트에 `docs/templates/PROJECT_TEMPLATE/` + **PROJECT_CREATION_RULES.md** 권장.
- 목적: 새 프로젝트 생성 시 문서 골격 자동화, Agent가 docs만 읽고 맥락 파악 가능.
