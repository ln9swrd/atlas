# 038. Atlas 대화기록 요약 및 지식추출

## 핵심

- 대화 = Decision Log + 설계 + 운영 지식. 프로젝트별 `docs/{atlas,exelion,forge,coin-s}/`.
- 흐름: raw conversation → AI 분석 → project docs → architecture/decision log.
- 최상위 원칙: **공존은 시작이고 끝. 유일무이한 기준.**
- 효율·성능·수익도 공존에 도움이 되는가로 거른다.
- Alpha가 큰 이유: 기능이 아니라 비전·헌장·Agent·상태 관리를 포함. 다음 = 실제 성공 사례로 가치 증명.
