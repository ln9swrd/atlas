# Exelion Forge

## 프로젝트 개요

Exelion Forge는 Exelion 프로젝트의 개발을 지원하는 제작 시스템이다.

최종 목표는 게임을 손으로 만드는 것이 아니라,
AI와 자동화 도구를 이용하여 게임 제작 속도를 극대화하는 것이다.

Forge는 모델링, 애니메이션, 데이터 생성 등의 제작 파이프라인을 담당한다.

---

# 목표

- AI 기반 게임 제작 파이프라인 구축
- Blender 자동화
- 파라메트릭 캐릭터 생성
- 애니메이션 자동 생성
- 재사용 가능한 에셋 제작
- 반복 작업 최소화

---

# 핵심 아이디어

게임을 직접 하나씩 제작하지 않는다.

```
파라미터
↓

생성기

↓

캐릭터
↓

애니메이션
↓

게임
```

Forge는 이 생성기를 만드는 프로젝트이다.

---

# 주요 기능

## 1. 캐릭터 생성기

목표

- Blender Script 기반 생성
- 파라미터 수정 가능
- 사람이 디테일만 보완

예시

- 키
- 체형
- 비율
- 장갑 형태
- 다리 길이
- 장식

등을 수정하여 새로운 캐릭터 생성

---

## 2. Blender 자동화

목표

반복 모델링 작업을 자동화한다.

예상 기능

- Mesh 생성
- Modifier 적용
- Naming
- Export
- Asset 생성

---

## 3. 애니메이션 생성

목표

AI를 이용하여 기본 모션 생성

후보 기술

- 공개 모션 데이터
- Prompt 기반 생성
- Motion Retarget

---

## 4. 파라메트릭 제작

하나의 모델을 수정하여

- 적
- NPC
- 플레이어

등을 빠르게 생산한다.

---

## 개발 철학

### 사람이 하는 일

- 디테일 수정

### AI가 하는 일

- 생성

- 자동 수정
- 스크립트 작성

Atlas

- 실제 콘텐츠 생성

- 애니메이션 생성
- 에셋 제작

그 내용까지 포함하면 `README.md` 수준이 아니라 다음과 같은 문서 세트로 확장할 수 있습니다.

- `PIPELINE.md` — 제작 파이프라인
