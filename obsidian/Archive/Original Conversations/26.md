---

## 3단계: 가장 먼저 구현할 것

중요한 순서가 있습니다.

처음부터 Agent나 Reasoning을 만들면 안 됩니다.

순서:

```
1. Runtime Core
        ↓
2. Configuration
        ↓
3. Logger
        ↓
4. Memory
        ↓
5. Knowledge
        ↓
6. Context
        ↓
7. Ollama Connector
        ↓
8. Agent
        ↓
9. Reasoning
        ↓
10. Improvement
```

입니다.

---

## 왜 이 순서인가?

ATLAS의 핵심은 LLM이 아닙니다.

LLM은 교체 가능한 부품입니다.

핵심은:

```
경험 저장
+
지식 관리
+
맥락 구성
+
판단 과정
+
개선 기록
```

입니다.
