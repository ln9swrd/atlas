# Atlas Foundation

## 1. Purpose

Atlas is an AI-powered Development Operating System designed to make complex creative and software projects executable through structured context, planning, execution, and validation.

Atlas exists to transform development from an informal process into a repeatable operating system.

---

# 2. Vision

The long-term vision of Atlas is:

> Enable sustainable creation of products and intellectual properties through collaboration between humans, AI agents, and automated development systems.

Atlas is not a single project tool.

It is a foundation for multiple development workflows.

---

# 3. Core Philosophy

## Evidence Over Assumption

Atlas prioritizes verified information over prediction.

Every important state transition should be supported by:

* Execution evidence
* Validation result
* Recorded state change

---

## Explicit State Management

Projects must always have a clear state.

Atlas separates:

* Lifecycle stage
* Operational status
* Execution status

This prevents decisions based on outdated assumptions.

---

## Infrastructure and Products Separation

Atlas infrastructure and product development are independent layers.

Structure:

```text id="q4x9uw"
Atlas

↓

Applications

↓

Projects
```

Example:

```text id="3x6s3p"
Atlas DevOS

↓

Forge

↓

Excelion
```

---

# 4. System Model

Atlas consists of four major concepts.

## Context

Understanding the current situation.

Examples:

* Environment
* Project
* Time
* Resources
* User goal

---

## Decision

Selecting the most appropriate next action.

Implemented through:

* Rules
* Priority Engine
* Recommendation Engine

---

## Execution

Performing the selected action.

Handled by:

* Runner
* Executor
* Plugins

---

## Validation

Confirming the result.

Handled through:

* Evidence collection
* Tests
* Reviews

---

# 5. Component Relationship

## Atlas

The operating system layer.

Responsibilities:

* Runtime
* State
* Rules
* Execution coordination

---

## Sera

The intelligence layer.

Responsibilities:

* Design reasoning
* Planning assistance
* Architecture support
* Creative analysis

Sera operates as the runtime intelligence agent of Atlas.

---

## Forge

The production application layer.

Responsibilities:

* Asset creation workflows
* Development automation
* Validation processes

Forge is the first application built on Atlas.

---

## Excelion

The first product project.

Purpose:

* Validate Atlas workflow
* Validate Forge pipeline
* Produce a real game/IP product

# 8. Expansion Principle

New capabilities should:

1. Fit into the lowest appropriate layer.
2. Avoid unnecessary coupling.
3. Preserve existing contracts.
4. Produce measurable evidence.
