# Forge Runtime Priority

## Current Objective
The immediate priority is to implement and validate the Forge runtime on top of Atlas.

## Scope
Focus on:
- Forge application runtime
- Atlas integration
- Blender/Unreal connector interfaces
- Event-driven workflow
- Mission execution pipeline
- End-to-end validation

## Constraint
Do not spend time creating or adjusting real 3D models yet.
Use placeholder or mock assets where necessary.

## Principle
Real production assets will be integrated later after the runtime and workflow are validated.
