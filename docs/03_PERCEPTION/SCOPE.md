# Perception Scope

## In scope

| Layer | Examples |
|-------|----------|
| **Code** | Repository tree, source files, configs, tests under Git |
| **Runtime / logs** | Terminal output, test logs, build logs committed or attached as text |
| **Screen** | Screenshots of IDE, tools, game UI stored in repo or linked assets |
| **Image** | Concept art, mesh previews, reference images in repo |

## Out of scope (camera = 0)

- Webcam / physical camera streams
- Real-time real-world video capture
- Always-on environment cameras

## Rebuild meaning of “recognition”

For this documentation phase: **index and reference** code and visual artifacts that live in Git — not implementing vision models.
