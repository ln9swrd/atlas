# 053 Exelion Forge 스탠드얼론 아키텍처

## 정의
Exelion Forge = Exelion 게임 개발 지원 제작 시스템.
손으로 만드는 것이 아니라 AI·자동화로 제작 속도 극대화.

## 핵심 아이디어
파라미터 → 생성기 → 캐릭터 → 애니메이션 → 게임
Forge = 이 생성기를 만드는 프로젝트.

## 주요 기능
1. **캐릭터 생성기** — Blender Script 기반, 파라미터(키/체형/비율/장갑 등) 수정 가능
2. **Blender 자동화** — Mesh/Modifier/Naming/Export 반복 작업 자동화
3. **애니메이션 생성** — Prompt 기반 / Motion Retarget / 공개 모션 데이터
4. **파라메트릭 제작** — 하나의 모델로 적/NPC/플레이어 빠른 생산

## 역할 분담
- 사람: 디자인, 디테일 수정, 최종 품질 확인
- AI: 생성, 반복 작업, 자동 수정, 스크립트 작성

## Atlas 관계
Atlas = 작업·프로젝트·우선순위 관리 / Forge = 실제 콘텐츠 생성

## 장기 목표
"게임을 만드는 AI 제작 공장". 사람은 방향 제시, Forge가 대부분 제작 수행.
