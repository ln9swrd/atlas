# Exelion Project Summary

## 목표
AI를 활용한 1인 개발로 Steam 유료 판매 가능한 오리지널 IP 제작.

## 장르·플레이
- Mission Based 3D Action RPG (초기 Tower Defense에서 전환)
- 거점 공략 · 다수 적 섬멸 · 거대 보스전 · 성장 · 스킬 · 미션 선택형
- 맵·몬스터·시스템 재활용 우선
- 그래픽보다 "재미있는 액션" 우선

## 전투 방향
슈퍼로봇 느낌의 강한 액션 + 건담식 디테일한 움직임.
임팩트 · 속도감 · 타격감 · 연계 · 스킬.

## 로봇 디자인 (Brave)
- 여성형 슈퍼로봇, 과도한 노출보다 강인함 우선
- 키워드: 90년대 감성, Retro, Imperial, FSS MH, 곡선 중심, 초기형 단순 → 성장하며 장식 증가
- 참고: Gunbuster, Getter Robo, Gurren Lagann, Five Star Stories
- 성장 라인: 초기 → 개량 → 강화 → Exelion → Exelion Empress

## 세계관
- 적 세력: Order (질서·통제를 추구하다 목적을 잃은 문명)
- 키워드: 루프, 문명, 레무리아, 아틀란티스, 수메르
- Season 1: 지구 → Season 2: 태양계(달·화성) → 더 거대한 존재

## 개발 순서
1. 기본 전투 → 2. 플레이 가능 캐릭터 → 3. 적 AI → 4. 미션 → 5. 성장 → 6. 보스 → 7. 스토리 → 8. 콘텐츠 확장

## 기술 스택
- 엔진: Unreal Engine
- 모델링·리깅·애니: Blender
- AI: 코드·리뷰·모델 생성·리깅 보조·문서 관리

## Exelion Forge
파라미터 기반 캐릭터 생성기. Blender Script → 기본 메쉬 → 파라미터 수정 → 디테일 → 리깅 → 애니 → 게임 적용.

## 핵심 철학
> AI가 게임을 만드는 것이 아니라, 개발자가 더 좋은 게임을 만들도록 AI가 반복 작업을 대신한다.
