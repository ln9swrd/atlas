# 054 프롬프트 기반 포즈생성 및 공개자료활용

## 원칙
포즈 자체는 저작권 보호가 약한 경우가 많으나, 특정 작품 연출 복제는 문제 가능.
공개 인체 포즈 데이터셋·모션캡처·사진 재구성·애니메이션 원리(무게중심, Line of Action, 실루엣, 균형) 활용.

## Exelion 권장 방식
프롬프트에 **물리적 상태와 의도**를 명시.
예: "거대한 슈퍼로봇이 80톤 검을 아래에서 위로 올려 베기 직전. 무게 왼발 70%, 오른발 뒤꿈치만, 허리 크게 비틀림. 실루엣 한눈에 읽히며 영웅적."

## 포즈 라이브러리 구축
카테고리: 공격 / 방어 / 비행 / 착지 / 대기 / 피격 / 필살기 / 승리 포즈
각 30~50개 기준 포즈 → AI가 변형 생성.
Forge "프롬프트 → 자동 포즈 생성" 기반 자료.
