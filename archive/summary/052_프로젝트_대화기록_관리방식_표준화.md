# 052 프로젝트 대화기록 관리방식 표준화

## 목적
대화에서 발생한 지식을 Atlas가 관리 가능한 문서 자산으로 변환.

## 변환 흐름
Conversation → Summary → Decision/Design Document → Project Documentation → Implementation

## 원칙
1. 대화 전체를 저장하지 않는다.
2. 중요한 결정과 이유를 저장한다.
3. 프로젝트 간 의존성은 Atlas Registry에서 관리한다.
4. 변경 사항은 ADR 형태로 기록한다.
5. AI Agent가 문서를 읽고 작업 가능한 상태를 유지한다.

## 저장 위치
- **Atlas Docs**: AI Agent 구조, workflow, 자동화, 공통 규칙 → `Atlas/docs/`
- **Project Docs**: 게임 기획, 코드, 모델링, 프로젝트별 결정 → `Atlas/projects/{project}/docs/`

## 문서 ID 체계 권장
ADR-0001, EXELION-DESIGN-001, COINS-SYSTEM-001, FORGE-PIPELINE-001 등.
