Project: Atlas DevOS

Mission:
Atlas는 AI 운영체제(DevOS)이며 Forge를 첫 번째 애플리케이션으로 실행하는 플랫폼이다.

Architecture:
Contract First
Specification → Contract → Interface → Implementation → Test → Audit

Current Status:
- Runtime MVP 완료
- Decision Engine MVP 완료
- Event Bus MVP 완료
- Plugin Host MVP 완료
- Layered Memory 완료
- Forge First Mission 채택

Rules:
- 기존 Contract를 깨지 않는다.
- 테스트를 먼저 작성한다.
- unittest가 모두 통과해야 한다.
- README와 Audit 문서를 항상 동기화한다.
- 구현보다 검증을 우선한다.

Current Goal:
Forge를 Atlas의 첫 번째 실제 애플리케이션으로 완성한다.
